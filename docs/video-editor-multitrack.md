# 多轨剪辑工作台

## 操作

- 默认显示 3 条画面轨，点击「新增画面轨」可增加到 8 条。
- 左侧选中目标画面轨后，素材「＋」追加到该轨道末尾；拖入素材可指定轨道和时间。
- 时间线片段可以上下拖动换轨，左右拖动定位。允许留空；同轨禁止重叠，不同轨可以重叠。
- 时间线越上方的画面轨，画面叠放层级越高。画面 1 是底层。
- 选中片段，在右侧调整轨道、缩放、水平/垂直位置；「右下画中画」提供快速预设。
- 画面缩放为输出画布的比例，素材在该区域内保持宽高比。位置表示画面中心百分比。
- 原视频声音与独立音频按各自起点混音。分离音频后原片段静音；可以对齐开头、结尾或原视频素材位置。
- 所有画面层都没有素材的时段导出黑场，音频超过画面末尾时保留音频及黑场。
- 轨道、起点、缩放、位置随画布节点工程保存；旧单轨工程按底层加载，不重新排列素材。

## 实现与限制

一个共享时间标尺、多条画面轨及独立音频。最多 32 个画面片段、8 个独立音频片段，10 分钟，720p/1080p、24/30fps。

接口仍为 POST /api/app/video/edit，保留鉴权、任务日志和临时资源安全校验。
新客户端发送 free_timeline=true、multi_track=true；画面片段增加 track (0–7)、scale (0.1–1)、x/y (0–1)。
未传参数的旧客户端使用原来的单轨导出路径。多轨请求用 FFmpeg overlay 混合图片/视频，amix 混音。
透明 PNG 保留透明度；上层片段结束后露出下层，不冻结最后一帧。

- 前端模型及工作台测试：22 项，覆盖跨轨拖动、叠放、复制、保存、撤销、音频对齐等。
- FFmpeg 测试：6 项，包含真实三层合成的像素取样、透明 PNG、空隙、各路音频频率验证。
- 浏览器：两路视频同步播放与自然结束、画中画、增加轨道后关闭重开。
- TypeScript 检查和正式构建通过。

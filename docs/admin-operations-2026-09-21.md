# 后台运营功能与交互验收

## 目标与主要问题

把后台整理为可识别、可确认、可追溯的运营界面；原页面最严重的问题是成员操作缺少确认边界，点击图标可能直接改变权限或数据。

依据用户提供的三张参考图，使用 aesthetic-audit 审查信息层级和误操作风险；保持项目已有深色视觉语言，不复制参考产品的品牌或与本项目无关的配置项。

## 审查结论与处理

| 级别 | 现象与影响 | 原因与落地处理 |
| --- | --- | --- |
| P0 | 成员角色、状态等操作单击即执行，容易造成权限事故 | 统一“管理”入口；先展示成员身份，再进入明确的确认表单；删除要求输入邮箱；提交期间锁定重复操作与关闭。后台阻止自身降权/停用/删除，事务内重新检查操作者权限。 |
| P0 | 存储切换涉及全站媒体与云密钥，误保存影响后续上传 | 提供本地、OSS、COS 选择与独立保存确认；密钥加密入库、响应不回显、留空保留；版本号防止覆盖他人设置；不搬迁或删除旧文件。 |
| P1 | 成员列表缺少查找路径，图标操作难理解 | 增加姓名/邮箱搜索、角色/状态筛选、15 条分页、常显文字操作按钮；长姓名与邮箱截断并保留完整 title。 |
| P1 | 无服务器资源视图，运营无法区分容量与应用开销 | 展示 CPU、系统内存、媒体目录磁盘，以及 Go 堆内存、运行时内存、协程数、GC 次数和运行时间；显示实例及采样时间。 |
| P1 | 网络失败可能使用户误把旧数据当成当前值 | 加载、空、错误、重试、提交中、成功分别反馈；资源接口失败保留上次结果但标记过期；无法采集的值显示“—”，不伪装成 0%。 |
| P2 | 控件、间距和危险操作层级不统一 | 共用深色面板、按钮与对话框；危险删除独立成区；桌面表格可横向滚动，窄屏表单与指标卡改为单列。 |

## 视觉 Tokens

- 字体：沿用项目字体；正文/表单 13–14px，辅助信息 12px，面板标题 18px，对话框标题 20px，指标数字 28px（窄屏 24px）。
- 间距：主节奏 8/12/16/20/24px；对话框内边距桌面 28px、窄屏 20px；按钮最小高度 36px。
- 网格：指标桌面三列；存储配置与生效摘要 2:1；1050px 以下存储区单列，600px 以下指标与表单单列；成员表格最小 800px，容器横向滚动。
- 色彩：面板 `#1c1c1c`，输入框 `#262626`，边界 `#383838`，主字 `#f3f3f3`，辅助字 `#aaa`；成功绿、警告黄、危险红只用于状态，不作为装饰。
- 圆角：按钮/输入框 8px，次级卡片 12px，主面板/对话框 16px。
- 阴影：常规面板不加阴影；弹窗 `0 20px 60px #0005`，遮罩 `#0009` 配合 3px 背景虚化。
- 无障碍：对话框标题/说明语义、焦点约束与关闭后归还；输入标签、筛选标签、提交禁用、错误 alert、成功 status、资源条 progressbar。

## 已实施的六项快速改进

1. 用常显“管理”替代直接执行的行内图标动作。
2. 角色及状态更改明确说明影响；删除提高确认门槛。
3. 积分修改默认增量为 0，必填原因并预览余额；账户与流水同一事务，失败全部回滚。
4. 存储配置显示当前生效来源、版本及时间；选中存储卡片不立即写入。
5. 密钥不回显；旧存储读取配置加密保留，切换只影响后续新写入。
6. 资源页区分系统与进程，显示采样时间；每 10 秒自动刷新，页面隐藏暂停周期请求。

## 代码位置与接口

- `src/app/components/admin/AdminMembersPage.tsx`：成员列表及安全确认流程。
- `src/app/components/admin/AdminActionDialog.tsx`、`admin-operations.css`：共用弹窗、控件和响应式样式。
- `src/app/components/admin/AdminStoragePage.tsx`、`AdminResourcesPage.tsx`：新增后台页面。
- `src/app/api/adminSystem.ts`、`src/app/routes.tsx`、`admin-navigation.ts`：请求、受保护路由、导航。
- `backend/internal/platform/adminsystem/`：加密配置、数据库版本并发控制、运行时同步及真实系统指标。
- `backend/internal/platform/assetstore/config.go`、`store.go`：不可变存储客户端热切换与历史读取配置。
- `backend/internal/identity/interfaces/admin_member_safety.go`、`admin_handler.go`：账号保护与事务性积分操作。
- `backend/db/migrations/047_media_storage_settings.sql`：单行、带版本号的加密存储配置表。
- 管理员接口：`GET/PUT /api/admin/storage`、`GET /api/admin/system/resources`；普通成员与未登录用户无权访问，响应禁用缓存；写操作接入已有后台审计，密钥和请求体不写审计日志。

数据库已有存储配置后优先于环境变量，所有实例必须使用相同的服务器加密密钥；正常情况下其他实例约 5 秒同步，数据库故障期间保留上次工作配置。历史云存储凭证也在加密配置内，必须持续有效，历史对象才能继续签名读取。

保存仅验证格式，不代表云端鉴权/连通性成功；沿用项目原有 public-read 云存储写入方式。此版本不提供 Cloudinary、不迁移旧文件、不显示云端容量、不增加限流阈值或清理/强制 GC 按钮。磁盘为媒体目录所在卷；容器中的 OS 指标可能来自宿主机，不等于容器配额，多实例仅显示当前响应实例。

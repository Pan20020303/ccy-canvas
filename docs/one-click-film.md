# 一键成片工作台

入口：主页 → 工作室 → 一键成片。`/studio/film` 先展示项目选择页，支持创建单集、搜索、状态筛选和更新时间排序；选择项目后进入 `/studio/film/:projectId`。两个路径都受登录保护。开发环境 `/__preview/film` 仅用于工作台页面预览，不会绕过生成、上传或导出接口的鉴权。

## 六步流程

1. 剧本编辑：粘贴正文、导入 TXT/MD/DOCX/PDF、文字模型编写、撤销/重做、替换和历史恢复。单集上限 10,000 字。
2. 视频设定：竖屏/横屏/方形、全能参考/先图后视频/四宫格关键帧、24 个风格提示词预设、自定义风格图，以及后台实际可用的文字/图片/视频模型。风格封面复用平台现有视觉素材，是示意图而非生成效果承诺。
3. 场景角色道具：文字模型提取真实剧本内容；也可手动添加。素材工作台支持图片生成、基于当前图片修改、上传、参考图片和结果历史。
4. 分镜脚本：基于实际资产 ID 拆镜；支持手动添加与编辑、景别/时长和资产关联。当前项目最多 32 镜。
5. 分镜视频：使用后台模型模板的参考方式、分辨率、时长、音频和输出格式；支持单镜生成、批量提交、上传既有视频、历史选择。视频与静态图提示词独立保存。
6. 视频预览：将已有图片/视频按镜头顺序放入时间轴，视频读取真实时长。复用现有剪辑工作台完成裁剪、配音、音乐和混音，通过现有 FFmpeg 接口合成并下载。字幕行显示真实空状态，未实现自动识别字幕。

## 数据与任务

- 顶部“制作设置”支持为“场景角色道具提取”和“分镜脚本”分别选择文字模型、提示词技能，也可跟随默认文字模型/使用内置规则。设置随各项目保存到数据库；旧草稿自动补默认值，不覆盖已有素材。
- “导入分镜技能”可上传或粘贴 Markdown，完整正文保存为当前账号的个人提示词技能，并在设置中选中；点击“保存设置”才应用项目绑定。相同名称和内容复用原技能，同名不同内容不会直接覆盖。生成分镜时分别保存静态 `imagePrompt` 与自然语言 `videoPrompt`，不会把工作台 JSON 直接发给视频模型。
- 模型来自已启用的真实渠道；技能来自当前账号可见且已启用的 `prompt` 技能，读取 `spec.system_prompt` 和 `content_md`（兼容 `user_template`）。HTTP/code 技能不在此处执行。技能指导生成方法，最终 JSON 仍遵循一键成片数据结构。
- 每次生成前重新验证模型/所选技能，失效时提示重新选择而非静默换模型。明确失败的提取/分镜重试使用当前设置和新的请求 ID；尚未确认的提交仍查询或复用原请求，不修改正在运行的任务。
- 后端不再将空正文标为文字生成成功，输出长度耗尽时给出明确提示；此类已完成但无正文的请求不自动重放。DeepSeek `deepseek-flash` / `deepseek-v4-pro` 的提取与分镜任务使用官方 `thinking.type=disabled`，避免有限输出预算只用于推理；不改变普通画布或其他模型的请求（[官方说明](https://api-docs.deepseek.com/guides/thinking_mode/)）。

- 完整项目按账号隔离存储于 PostgreSQL `film_projects`：最后步骤、剧本、历史、设置、资产/素材引用、分镜、生成任务、剪辑时间轴和导出信息。列表从数据库读取，打开项目从数据库恢复。上传的媒体仍使用现有媒体存储，数据库保存引用。每次编辑防抖自动保存，仅收到服务器确认才显示“已保存到数据库”。
- 浏览器仅保留尚未同步修改的恢复副本；断网或刷新后按原版本和幂等请求恢复。保存请求串行执行，多页面冲突返回 409，不自动覆盖较新版本；可以导出本机备份，或“备份并载入云端”。仍有未同步修改时刷新/关闭会提示。JSON 备份暂不提供导入界面。
- 首次进入列表自动迁移原来的单一本机草稿，使用账号和原草稿 ID 去重，重试不会覆盖云端项目，原本机草稿仍保留。新建项目不覆盖旧项目，工作台返回键回到项目列表。
- 创建项目时同时创建用于任务归属的后台项目；迁移复用原有且属于当前用户的任务项目。普通画布列表不混入成片项目。生成复用 `/api/app/generate`，没有伪造进度、作品、余额或固定费用。
- 每次提交先将唯一 `request_id` 和 `node_id` 保存到数据库，保存失败不发起付费生成。页面离开不会主动取消请求；后台排队任务继续执行，回来按任务 ID/节点 ID 查询结果并保存到对应项目。完整的后台持续运行依赖现有服务的持久队列配置。
- 网络错误保留“待确认”状态；重试先查后台，再使用相同幂等键重发，避免不确定提交重复计费。明确失败任务才创建新请求。
- 剧本变化后不自动套用旧任务结果；重复提取保留现有资产 ID、图片和历史；编辑分镜时保留并发完成的视频结果。
- 上传复用 `/api/app/upload` 对应的项目上传封装；视频导出复用 `/api/app/video/edit`。模型额度/鉴权/上游报错在页面显示，不用演示媒体冒充生成结果。

## 验证

### 任务进度与结果恢复

- 提取与分镜生成自动展开右侧步骤面板。阶段来自真实提交/排队/运行/返回/解析事件，不模拟模型没有提供的百分比。步骤、最近同步时间、原始返回、解析数量和已应用标记随项目入库；轮询异常只标记断线，不把后台任务判为失败，在线和页面重新可见时立即查询原任务。
- 非空但截断的 JSON 只恢复数组中已完整闭合且能解析的对象。部分结果明确标记“部分恢复”，保留原始返回下载，不编造尾部。旧失败任务的“恢复已有结果”只读取任务缓存，不发起生成；应用标记和分镜同一次保存，防止刷新重复导入。原剧本改变时仍阻止旧结果覆盖。
- 提取/分镜提示词增加整份输出长度预算，避免长技能逐镜重复导致输出耗尽；仍保留技能方法、自然语言视频提示词和素材关联。部分恢复不代表整部剧本已经完成。

### 分镜素材与参数

- 图片/视频制作底部“输出”打开比例、分辨率、时长、输出格式/质量的选择面板，选项取自实际模型模板。每个资产/镜头独立保存图片与视频参数，不改其他镜头或全局设定。
- 参考图在输入区上方无外框平铺并换行，按人物/场景/道具/其他参考分层；上传入口仅用少量叠放缩略图作提示，不把真实素材堆叠遮挡。未制作的绑定资产显示“待上传参考图”，完成后按资产 ID 自动带入当前镜头。
- 输入 `@` 打开素材搜索，可鼠标选择或方向键/回车选择。行内显示缩略图和引用标签；项目保存稳定的素材 ID，提交时转换成实际图片/视频/音频序号，删除前面一张不会引用错位。原始自由文本始终作为文本渲染，不插入 HTML。
- 参考素材、排除项、自然语言提示词按镜头隔离；已有手工参考列表不会擅自覆盖。单镜与批量生成共用绑定和参数转换；提供批量参考图、批量分镜图与批量视频，整批先校验再提交，各自进入异步任务记录。测试不会发起真实付费生成。

### 多浏览器同步

- 编辑页面每 3 秒读取项目最新版本，不依赖本机是否有运行任务；窗口重新获得焦点、恢复可见或联网时立即同步。先拉取项目再查任务，避免另一个浏览器已经导入的结果重复应用。读取远端更新不会改变当前正在看的步骤，也不会无变化地回写数据库。
- 保存遇到版本冲突时，使用上次确认版本作为共同基础，合并不同字段/镜头的独立修改后重试。生成的资产/分镜 ID 由任务 ID 和序号确定，两个浏览器同时收到同一结果不会新增两份。相同字段的冲突、删除与编辑冲突仍保留本机备份并要求选择版本，不做强制覆盖。
- 离线恢复副本保存共同基础和冲突标记；刷新不会把已冲突的旧副本重新当作最新版本上传。历史副本没有共同基础时不猜测合并。检查两个浏览器是否同一账号、服务地址和项目，并区分“生成完成”和“已保存到数据库”。

# 智能体批量授权与图片队列

- 手动执行：一次确认授权当前用户轮次的同服务类型、同模型生成（包括后续流式到达的节点）。新轮次/另一模型必须重新确认。不会修改全局“生成前确认”偏好。
- 自动执行：遵循已有自动模式；两种模式均绕过已经重复的画布逐节点确认。
- 生成不能放在 React state updater 中，避免 StrictMode 重复调用。每轮按 node ID 去重，重复点击不重复提交。
- 前端提交到持久队列的并发为 3；这不是上游生成并发。后台实际任务由 Asynq + Redis 共享容量控制，页面关闭后已入队任务继续。
- Seedream / doubao-image：跨版本、供应商配置、用户和后端进程，共享最多 10 个输出槽位，单请求 n 张占 n 个槽位。n > 10 在扣费前拒绝，不能把 50 张静默截成 10 张。智能体创建 50 个独立节点后逐个入队，保留每个提示词和日志。
- 其他远程图片：最多 3 个任务；本地图片：最多 1 个任务。视频/音频保持现有调度。
- 满额时，不标为 running、不调用上游、不计失败、不消耗重试预算，3 秒后重新尝试调度。真正的媒体生成失败维持现有“不自动重发付费请求”的规则。
- Redis 原子租约使用 Redis 时间，租约超过 worker 硬截止时间 1 分钟。正常结束立即释放；进程崩溃/取消保留至期限，防止远端仍在执行时过早补位。Redis 不可用时暂停调度，不放开并发。
- 图片排队上限 24 小时；实际执行开始时间记录在 request_payload._execution_started_at，运行超时不再从提交时间起算。
- 当前并发限制依赖启用 Redis 的持久队列路径；未配置 Redis 的旧版 inline 路径不使用此共享限制。

验证：`npx vitest run`；`go test ./internal/tasks ./internal/modelcatalog/...`。
设置 `CCY_CAPACITY_TEST_REDIS=127.0.0.1:56379` 后，Redis 集成测试模拟 50 任务跨 worker 竞争，只读写随机测试前缀，不调用模型。

# 橙次元首页与账户中心改造

日期：2026-09-14。根据用户本轮提供的四张截图实施，未更改登录凭据、权限、后端计费规则、画布编辑器和 Agent 面板。

## 页面入口

- `/home`：创作首页。
- `/home?view=canvases`：无限画布列表。
- `/home?view=gallery`：作品广场。
- 左下“我的账户”或右上头像：打开账户中心弹层，关闭后保留原页面。
- 原有 `/admin`、`/app`、`/automation` 入口不变，管理员登录后的默认目的地不变。

## 实际交互与数据

### 首页

- 左栏展开 / 收起；折叠后通过图标及提示识别入口，手机端展开时覆盖内容并有收起遮罩，导航后自动收起。
- 最近画布读取现有项目数据，按更新时间排序；支持全部、个人、协作与名称搜索，卡片进入原画布。
- 创意快捷词仅填入输入框。提交创意会创建画布并保存为文本节点，不自动发起生成和扣费。创建失败保留输入；保存失败明确提醒。
- 新建画布保留原自由 / 全自动模式选择；工作室包含现有创作能力入口。
- 推荐横幅每 7 秒自动切换，支持前后按钮、圆点、暂停，页面隐藏 / 交互 / 系统减少动态效果时停止自动切换。
- 作品区显示真实公开模板和三组橙次元现有灵感素材，明确区分数据来源；支持分类、搜索、模板复制与图片 / 视频预览。
- 目前本机未发布公开模板，因此不是参考图里满屏的用户作品。未填充虚构作者、播放量、点赞或用户作品。原有项目缺少封面时使用中性占位图，不替换为无关作品。

### 无限画布

原首页项目管理逻辑移入 `CanvasLibrary.tsx`，保留新建、切换、文件夹、重命名、封面上传、复制、移动、模板标记和删除确认。

- 使用密集卡片布局，每页最多 24 个项目。
- 已登录但项目为空时不回退到过时的本地项目数据。
- 创建 / 重命名 / 文件夹 / 复制 / 封面 / 删除失败会提示；创建失败不再伪造一个本地成功项目。
- 文件夹二级菜单支持点击，使用内嵌菜单避免窄屏溢出。
- 卡片光效在封面内裁剪，不让不可见装饰引起横向滚动。

### 账户中心

- 个人资料、邮箱、UID、头像、余额、每日额度和今日消耗来自真实账户。
- 编辑资料复用原个人资料编辑器，保留头像和详细资料编辑能力。
- 积分账单接原接口，每页 30 条，含加载、空态、错误重试和翻页。
- 用量统计展示当前账户汇总，不编造趋势或订阅积分。
- 站内消息读取平台公告。
- 我的作品跳转本人画布；体验设置可切换中英文与主题；CLI / 帮助介绍实际已有能力。
- 退出账号沿用原认证退出流程。
- 弹层采用现有 Radix Dialog，支持焦点管理、Escape 和关闭按钮。

核对账单时修正展示类型遗漏：项目划转显示为扣减，项目退款显示为增加，管理员负向调整保持负号；技术性项目 ID 不出现在主说明。仅修正展示，不更改余额与账单原始数据。

## 暂不实现

会员付费、充值、赚积分、社群课程、礼品卡、优惠券、宝箱、点赞、发票、登录设备、竞技场、数字人等缺少相应业务服务，入口禁用并标注或提示尚未开放。

不提供虚假的分享链接、多选管理、外部联系方式。当前“作品广场”是公开模板与灵感素材入口，不声称已具备完整用户视频社区。

- 43 项相关测试、TypeScript 类型检查、生产构建均通过。
- 组件测试覆盖侧栏偏好、画布筛选 / 搜索、页面切换、创意保存与失败恢复、模板复制、预览、账户资料、账单重试、公告、退出、创建模式、文件夹与重复项目 API、减少动态效果及积分方向。
- 登录组件原有 19 项测试纳入回归。
- 浏览器使用本机真实已登录会话检查页面和账单，不进行充值、付费生成或删除用户内容；测试中的创建、复制与退出使用隔离的模拟接口。
- 已检查 1920 × 945 桌面、1366 × 768 笔记本和 390 × 844 手机尺寸；笔记本搜索只剩一个画布时仍正常显示。手机画布列表的文档宽度和可视宽度一致，无横向溢出。

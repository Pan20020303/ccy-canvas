# 模特试衣库改版

## 本次范围

- 工作室移除“全自动创作”“图片 / 视频画布”，替换为“模特试衣库”。“数字人”原有未开放状态不变。
- 首页和无限画布列表的新建操作直接创建普通画布，不再出现模式选择。
- 旧 `/automation` 地址转到普通画布；已有画布、历史自动工作流存档不删除。旧开发预览入口转到试衣库。
- 新入口：`/home?view=tryon`，保留首页侧栏折叠、橙色标志、账户入口和黑灰视觉体系。

## 布局与交互

采用参考图的左侧创作区、右侧素材区结构，不采用 OpenArt 品牌、紫色／绿色配色、订阅横幅或虚构有效期。

左侧包含后台启用的图像模型选择、人物／模特选择、服装选择、附加参考图、提示词、细节增强开关、输出比例／尺寸、画质、1–8 张生成数量及预计积分。模型参数使用现有模型配置，未开放的参数不伪造为可用选项。细节增强是在提示词中追加服装贴合、比例和光影要求，不额外调用模型。

点击参考素材入口打开对话框：人物与模特／服装与图片切换，素材来源与用途筛选、搜索、多选、已选用途调整、移除及图片上传。人物沿用原素材库人物分类，模特用途可通过上传或预览中的“素材用途”指定。上传支持 JPG、PNG、WebP，每张最多 20 MB；参考总数同时受页面上限 16 张与模型上限约束。

右侧功能：

| 工具 | 实际行为 |
| --- | --- |
| 排序 | 最新、最早、名称 |
| 标签 | 预览中增删标签，标签面板筛选 |
| 文件夹 | 新建、查看、确认删除；预览中移动素材；删除文件夹不删除素材 |
| 模板 | 三套文字场景预设，保存／应用／移除个人试衣设置 |
| 缩略图滑块 | 调整网格卡片和列表缩略图大小 |
| 媒体类型 | 图片、视频、音频、全部；默认图片 |
| 收藏 | 收藏／取消，仅看收藏 |
| 布局 | 网格／列表切换 |
| 筛选 | 来源、最近 7／30 天、重置 |
| 搜索 | 素材名称与标签匹配，清除与空状态 |
| 预览 | 图片、视频、音频预览，下载，归档，作为试衣参考 |

在较小桌面上创作区独立滚动，生成按钮保持在底部。900 px 以下上下排列；人物选择弹窗在手机上保留可见的确认栏，支持 Escape 关闭和焦点返回。

## 数据与生成边界

- 素材读取现有账户素材与生成历史，按 URL 去重；使用真实素材，不填充虚构模特库。
- 图片、文件夹和生成结果复用现有上传、素材库及文件夹 API，同步到账户。
- 收藏、标签、素材用途、个人试衣模板、展示偏好按用户 ID 保存在当前浏览器；界面明确提示不跨设备同步。未扩展数据库模型。
- 只有点击生成按钮才提交收费请求。参考图片明确标注人物／模特、服装与附加参考的顺序和用途，缺少人物或服装时在本地阻止请求。
- 每张生成有独立请求 ID，同一次提交防重复点击。批量中任一提交失败，不继续提交剩余图片，不自动重发收费请求。
- 排队任务在返回本页面后恢复查询，完成后保存到素材库。生成成功但保存失败可单独重试保存，不重复生成。
- 网络错误导致状态不明时提示先查询任务状态，暂时阻止继续提交，避免误重试扣费。若一直查不到任务，需要先由管理员核查，不宣称生成失败或未扣费。
- 切换账号／离开页面后，未提交的后续批次停止；在途结果保存在原账户的本地任务记录，不向新的登录账户写入。
- 实际试衣质量、参考图数量和支持能力仍取决于后台配置的图像模型；未承诺所有图像供应商均支持换衣。

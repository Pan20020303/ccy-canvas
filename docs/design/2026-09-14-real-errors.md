# 真实错误展示

本次范围：Agent 对话、后台 Agent 调度时间线、图片 / 视频生成节点的错误信息。未修改用户的模型渠道、密钥和积分配置。

## 原因

- 模型服务错误原先被统一包装成 INTERNAL 或固定“模型服务暂时不可用”。
- Agent 的 HTTP / 流式错误有些是普通异常，公开输出时会丢失实际原因；HTTP 200 的 error 帧此前会被忽略。
- 节点再次把服务端文字压成 E1012 一类固定提示。

## 改动

- 公共错误转换保留真实上游 HTTP 状态，以及结构化错误中的 message、code、param。授权失败不会误触发平台账号退出。
- 区分认证、权限、模型 / 接口不存在、参数不支持、服务商额度不足、限流、超时、连接 / DNS / TLS 失败和响应格式异常。
- 不把 HTTP 200 内的业务失败伪装成 HTTP 500；没有错误原因时明确说明服务商未提供详情。
- 视频异步查询、无任务编号 / 结果地址、Agent SSE error 帧、非流式 error 响应和空响应均能形成真实失败。
- 已知的公开错误穿过旧 INTERNAL 包装时保留原因；未知数据库、文件系统等内部异常仍不公开私有内容。
- 前端展示具体原因；节点原 E 编号改为“分类编号”，避免误认成上游错误码。已有任务编号时一同展示。
- Agent 创建任务失败使用统一错误信封；事件流 / 状态恢复保留原因和任务编号。401/403/404 观察错误不会无限重连或清除仍可能运行的任务。
- 后台仅展示新事件中标记为公开错误的安全消息；仍隐藏工具参数、正文结果、原始响应、密钥等。
- 旧任务已经丢失的原因不回填、不编造；界面说明未记录详细原因。

## 安全与边界

只提取结构化诊断字段，不展示整个供应商响应。脱敏鉴权、密钥、令牌、签名 URL、账户地址及私有路径，并限制文本长度；私有诊断保留在服务端错误链中，不发送到页面。

本次解决错误可见性，不保证服务商恢复可用；真实失败仍需要按原因修正配置或输入。没有服务商详细原因的历史记录无法凭空还原。

## 验证

- 全量 Go 测试通过，后续小修改再次运行公共错误、Agent 和模型生成相关测试。
- TypeScript 检查通过；相关前端 6 个文件、89 项测试通过，包括任务事件 / 状态恢复、创建失败、节点与对话组件、脱敏、旧记录和画布回归。
- 所有上游失败验证使用本地模拟响应，无付费生成、无生产测试任务或积分变动。
- 浏览器验收连接在导航 / 聚焦时连续超时，未完成实时截图验收。组件渲染测试已通过。独立视觉样例位于 validation/real-error-preview.html（明确标记模拟，不是生产错误记录）。
- 本地服务仅在确认 Agent 与媒体任务均为空闲后更新。无需数据库迁移，不修改历史记录。

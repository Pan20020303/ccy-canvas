# 画布视口记忆与技能界面

## 行为

- 按用户和画布分别在当前浏览器保存平移位置与缩放比例，移动结束、页面隐藏及退出时及时保存。
- 首次打开未保存视口的画布自动适配内容，最大初始缩放为 100%；已有保存位置时不再自动适配节点。
- 技能快速选择器支持搜索全部可调用技能、键盘选择与移除；设置入口打开完整技能库。
- 技能库采用探索／我的技能侧栏、分类筛选、排序、双列列表和分页；点击条目进入介绍页，使用技能后回到当前对话。
- 详情页显示真实介绍、示例预览、版本信息和提示词；选中技能以图标、命令名称和移除按钮组成紧凑引用标签。

## 数据边界

- 技能来源仍为现有技能 API；发送消息仍使用真实 skill_id。搜索、分类与数量由 API 结果计算。
- 不虚构购买价格、订阅人数、使用次数；接口未提供这些字段，因此不显示购买交易按钮。
- 可选扩展字段：spec.examples（type、url、title、poster）、spec.version、spec.version_notes、spec.version_history（version、date、notes）。缺少元数据时明确显示未提供。
- Markdown 导入保留 icon、version、version_notes；导入成功以服务器返回记录为准。
- 不恢复修复前从未保存过的历史视口；存储不可用或损坏时安全回退。

## 设计依据

直接对照用户提供的技能库、详情页及引用标签截图。TapCanvas 视觉工作流不可用后，用户明确同意直接对照截图实现。

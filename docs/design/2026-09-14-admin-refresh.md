# 橙次元管理后台改版

日期：2026-09-14。延续本次首页改版的中性黑灰风格，保留橙色品牌标识。只调整后台呈现与导航，不修改权限、登录、业务接口和数据。

## 菜单层级

概览保留为独立入口。其余 12 个入口归入四组，每个路由只出现一次。

| 一级菜单 | 二级菜单 | 原有路由 |
| --- | --- | --- |
| 平台运营 | 成员管理、积分流水、邀请码、公告管理 | `/admin/members`、`/admin/credits`、`/admin/invitations`、`/admin/announcements` |
| 模型与提示词 | 模型服务、提示词管理、提示词模板 | `/admin`、`/admin/prompts`、`/admin/prompt-templates` |
| Agent 管理 | Agent 配置、技能管理、Agent 记忆 | `/admin/agents`、`/admin/skills`、`/admin/memory` |
| 运行监控 | 智能体记录、日志 | `/admin/agent-runs`、`/admin/logs` |

- 一级菜单可独立展开 / 收起；子项缩进、引导线与选中标识区分层级。
- 侧栏 216px / 64px 切换；收起后点击分组图标直接展开对应分组。
- 桌面侧栏和分组偏好保存在本机；损坏或不可用的存储不会阻断导航。
- 进入子页面自动展开所属分组，精确匹配当前项，不让 `/admin` 在所有子路由中同时高亮。
- 顶部面包屑显示当前分组及页面；保留返回工作区 `/app`，新增返回首页 `/home`。
- 窄屏默认图标栏，展开覆盖主区；有遮罩、Escape 关闭和焦点约束，选择页面后自动收起，不覆盖桌面折叠偏好。

## 视觉与布局

- 底色 `#121212`、侧栏 `#1e1e1e`、卡片 `#1c1c1c`、边框 `#303030`、选中项 `#383838`。
- 使用首页的橙色 Logo，去掉大面积橙色 / 蓝色光晕和装饰性安全宣传卡。
- 精简标题区，统一 25px 标题、13px 说明、16px 卡片圆角及白色主要操作按钮。
- 错误、告警、启用状态、模型类型等有实际含义的颜色保留。
- 表格表头、卡片、工具栏统一黑灰层次；宽表格在容器内部滚动。
- 模型管理在窄屏改为上下布局，汇总统计为紧凑三列；不删减模型及渠道操作。
- 概览图表不再以固定宽高比撑宽手机页面，记忆配置底部按钮可换行。
- 公告列表增加条数、公告图标和清晰的删除入口，长文本可换行。
- 公告及告警窗口支持焦点约束、Escape 关闭、关闭后恢复焦点；发布中的公告不允许重复关闭提交。
- 新样式限定在 `.admin-workbench`，不影响首页、登录、画布；后台保持深色，前台主题偏好不变。

## 功能边界

公告、成员、积分、邀请码、模型、Agent、提示词、技能、记忆、调用记录和日志继续使用已有后端。未更改后台鉴权、计费、账户密码、模型开关或任务执行逻辑。浏览器验收没有发布 / 删除公告、调整积分、保存配置或发起付费测试。

此次不重做复杂编辑器的业务结构、报表指标算法和后台接口，后续按具体需求另行调整。

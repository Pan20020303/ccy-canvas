# 自定义画布设置

依据 2026-09-14 提供的九张截图，采用底部居中浮层、九个分类导航、连续滚动参数卡片。保留橙次元品牌与现有画布，默认深色，可选择酒红等主题；没有强制把所有账号改成参考图的酒红色。

## 入口与保存

- 画布底部齿轮打开“自定义画布”；支持恢复默认、展开、Esc 关闭。
- “高级设置”保留原有技能、智能体、快捷键及生成前确认。恢复画布默认值不会重置模型、技能、生成确认偏好或画布内容。
- `canvas-preferences.ts` 对字段类型、数值范围、枚举和颜色进行校验，保存在独立小键 `ccy-canvas-preferences@用户ID`，不与大型画布快照竞争存储空间。
- 当前为**按账号隔离的本浏览器偏好**，不是服务器跨设备同步。旧版网格吸附、小地图偏好从对应账号的已有快照迁移；新账号和损坏数据回到默认值，不继承上一个账号的设置。
- 写入失败时参数仍即时生效，但面板明确显示保存失败并提供重试。

## 参数与实际行为

| 分类 | 接入方式 |
| --- | --- |
| 交互操作 | 平移灵敏度控制滚轮平移速度，滚轮可改缩放；空白处菜单可选右键/双击；网格吸附与对齐辅助线独立控制；拖动选择由 React Flow 接管；定位动画根据当前真实节点数降为即时定位。 |
| 延迟提交 | 图片/全景/视频在原有生成确认之后进入可取消倒计时，倒计时结束才调用模型；重复提交替换旧等待。切换账号、项目或离开画布取消等待；节点删除或生成参数变化不再提交。默认关闭，不影响旧流程。 |
| 引用与预览 | 名称/数字影响新插入的节点 @ 标签与 Agent 画布引用选择，真实引用仍按节点 ID 解析；联动预览关闭后仅预览双击节点；悬停播放控制真实视频播放；低于 35% 缩放可显示按媒体类型区分的色块，选中后恢复详情。 |
| 生成通知 | 订阅当前画布真实节点的任务运行→完成/失败，不用演示统计或伪造任务；有旧结果的失败重试也按失败通知。新任务记录发起账号，未知发起者不假定为本人。支持仅离开窗口/始终、本人任务、成功/失败、提示音与系统通知。 |
| 浏览器权限 | 只有明确点击系统通知开关才申请通知权限；被拒绝不显示已开启。提示音使用本地 Web Audio 合成，点击音色试听；浏览器自动播放限制仍可能阻止后台声音，站内提醒不依赖声音。 |
| 连线设置 | 自定义 FlowEdge 的真实描边宽度、可命中范围、悬停高亮和运行中动画；焦点过滤按当前选择的节点/连线计算。新增连线的拖动预览也使用选定颜色与线宽。 |
| 网格与显示 | 背景网格和节点吸附共享同一间距；控制点大小、小地图和氛围光。原小地图/吸附按钮与新设置双向同步。F 定位、M 小地图、J 辅助线、L 网格吸附、句号网格显示遵循快捷键配置。 |
| 节点与布局 | 水平/垂直间距用于实际选中节点、分组排列和全画布整理；列宽读取已测量的真实节点宽度，防止宽节点重叠。边距用于新分组/整理分组，操作保留撤销；改变滑块本身不移动画布节点。 |
| 标签与工具栏 | 组标签可缩放；节点上方操作栏、下方提示词栏与底部工具栏可调大小。组遮挡只盖住经过无关分组的连线，保留分组自身的入线、出线及内部连接。 |
| 自定义背景 | 从当前画布已有图片/图片参考节点选择，忽略空节点、视频与上传中的素材。实时不透明度、模糊、铺满/适应/平铺；平铺大小以 400px 为 100%。来源删除或不在当前画布时不显示，真实加载失败明确提示，不上传、不生成。 |
| 主题与配色 | 主题使用同一组变量作用于画布底色与设置浮层；连线使用真实预设或自定义色；简化配色在极简缩放模式生效。 |

## 验证

- 完成 TypeScript 检查和生产构建；五组相关测试共 **128 项通过**（新设置 26、媒体预览 20、原画布状态 60、顶部菜单 12、错误提示 10）。构建仍有原项目的大体积分块警告，无构建错误。
- 新增参数校验、账号隔离/迁移、存储失败、面板交互、真实背景选择、权限拒绝、实际排列、线宽/颜色/命中/遮挡、真实通知及延迟提交测试。
- 媒体预览补充关闭联动时仅显示当前节点的回归用例。
- 测试使用隔离的内存画布和模拟接口，不提交真实生成任务、不消耗积分、不修改用户服务端画布。
- 本轮浏览器自动化连接在读取现有画布时超时（`Emulation.setFocusEmulationEnabled`），因此尚未完成真实浏览器截图及鼠标验收；不能将自动化组件测试称为已完成视觉验收。

## 人工验收清单

1. 打开画布齿轮，逐个点击九类导航，检查连续滚动及高亮跟随；展开/收起、Esc、恢复默认和高级设置返回。
2. 修改主题、网格、线宽/颜色、缩放行为，确认画布即时变化；刷新后同账号保留，另一账号不继承。
3. 从当前真实图片选背景，调透明度/模糊/显示方式，再删除来源检查背景消失；切换回原图重新选择。
4. 用宽窄不同的测试节点调整横/纵间距并整理，检查无重叠、撤销恢复。
5. 仅在用户确实需要生成时验证倒计时取消与真实成功/失败通知；不为了验收自动执行付费生成。

# 画布左右上角导航改版

参考：本轮提供的 `codex-clipboard-edbf7a7b-e826-425c-9c47-e0bac404d0c9.png`。

## 已落地

- 左上角改为 38px 紧凑胶囊：橙次元橙色标识、当前画布名称、展开箭头、真实保存状态。
- 画布菜单约 302px 宽，采用深灰浮层、8px 搜索框、三段分类、34px 缩略图、46px 列表行和底部新建按钮；不是全屏项目页。
- 搜索覆盖真实画布及文件夹名称；支持全部、个人、协作筛选，文件夹展开，当前画布勾选，以及无结果/加载/刷新失败提示。
- 打开菜单只刷新项目元数据，不重新载入或替换当前画布。未能读取的文件夹不会导致对应画布从列表中消失。
- 右上角顺序为更多、协作、积分/会员、头像；圆形及胶囊按钮统一为 36px。
- 更多包含保存、管理画布、设置、返回首页，并保留真实公告和生成任务；支持 Escape 和外部点击关闭。
- 头像打开现有账户中心；积分使用真实余额并连接明细。协作模式保留成员权限、项目积分及协作管理，不额外重复显示个人积分。
- 顶栏随 Agent 面板实际宽度让位；窄宽度缩短名称、折叠会员文字，必要时换行。小屏 Agent 全屏展开时隐藏底层顶栏。

## 导航保护

- 切换、新建或离开前先保存；保存失败、保存期间继续编辑或画布未加载完成时留在原处并明确提示。
- Agent 或前台媒体生成仍运行时，提示用户先停止/等待，避免旧任务应用到另一画布。
- 目标加载失败后恢复原画布及其编辑状态，不把失败当成空画布。
- 只读协作者不发送保存请求；新建失败不伪造本地成功。

## 与参考的有意差异

- 保留橙次元橙色标识，不使用参考品牌的白色吉祥物。
- 使用用户自己的画布、文件夹、封面、头像和余额，不复制参考中的示例数据。
- 会员订阅未接入，点击入口只打开账户权益说明，明确标注未开放；不模拟支付或开通成功。
- 本轮不调整节点、画布背景、底部工具栏或 Agent 工作方式。

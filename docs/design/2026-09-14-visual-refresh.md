## 2. 共用视觉方向

整体采用中性黑灰：大面积接近黑色的底、稍亮一档的侧栏和卡片、细灰描边、白色主操作。彩色集中在作品图和真实业务状态。

以下尺寸是基于截图的设计目标，并非已抓取参考站点的精确样式。

| Token | 建议值 | 应用 |
| --- | --- | --- |
| 页面底色 | #121212；登录 #060606 | 页面大背景 |
| 导航/卡片 | #1e1e1e | 左栏、项目卡 |
| 输入/浮层 | #252525 | 搜索、输入条、菜单 |

| 主操作 | 白底 + #080808 文字 | 登录、新建画布 |
| 次操作 | 暗底 + 白/灰文字 | 搜索、筛选、文件夹 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 | 跨页面统一 |

| 大容器圆角 | 24–28px | 首页创作区 |
| 胶囊圆角 | 999px | 登录输入、切换、主按钮 |

点阵只出现在首页/列表的背景空白区域，建议间距 26px，点半径约 1px，白色透明度 8%。登录页没有点阵。编辑画布本身的网格、节点、连线不在本轮改动范围，不能把列表页背景直接套到编辑器。

字体使用系统中文无衬线字体；标题 24–32px，普通控件 13–14px，说明 11–12px。避免将整页变成大字号展示页。作品画面承担视觉吸引力，工具文字保持克制。

## 3. 已实现：登录 / 注册

### 3.1 布局

- 桌面左侧自适应铺满，右侧宽度 clamp(400px, 24vw, 480px)；1920px 下约为 76:24。
- 右侧表单最大宽 380px，品牌标识横排，标题「欢迎登录」与副标题「继续你的创作之旅」居中。
- 黑色面板直接作为页面一部分；输入和按钮使用 46–51px 高的胶囊外观。
- 左侧画面向右渐隐，平滑融入表单底色；没有独立的毛玻璃卡片。
- 761–959px 为窄双栏；760px 及以下变成顶部画面、下方完整表单。
- 小屏/矮屏可纵向滚动，表单不裁切；手机输入字号 16px，避免聚焦时自动放大。

### 3.2 三组动态画面

| 场景 | 当前素材类型 | 动效 |
| --- | --- | --- |
| 星际远航 | 本轮生成的科幻图片 | 缓慢推镜、轻微氛围层 |
| 云上之境 | 本轮生成的国风幻想图片 | 缓慢推镜、轻微氛围层 |
| 次元新生 | 项目原有品牌视频 | 静音循环播放，保留封面回退 |

前两组是图片动效，不是真实逐帧视频。截图没有附带参考站的视频，因此不声称已复刻原站视频内容。正式视频可直接接入场景配置的 video 字段。

交互规则：

- 每 10 秒自动切换，最后一组回到第一组。
- 左侧纵向圆点可以直接选择，底部有前后切换与播放/暂停。
- 方向键、Home、End 可在轮播区域选择；触屏支持左右滑动。
- 鼠标停在轮播控件上或键盘焦点进入轮播时，自动换页暂缓；离开后继续剩余时间。
- 用户点击暂停后，镜头动效、氛围层、视频与自动轮换均停止。
- 页面隐藏时暂停；系统开启减少动态效果时使用静态封面，不自动轮播。
- 切换场景不修改邮箱/密码输入；右上角关闭只收起面板，随后可通过「登录 / 注册」恢复，输入值保留。
- 视频只在选中时加载；播放被浏览器阻止或视频错误时保留封面，登录表单继续可用。

### 3.3 真实登录能力

保留现有邮箱密码登录、Google 登录入口、注册与可选邀请码，并继续使用现有接口和管理员/成员登录后的跳转。

参考图的手机号 + 验证码形式需要短信认证接口、发送限制、验证码失效与账号绑定等配套能力；当前后端没有该流程，所以本轮保留邮箱密码字段，用相同尺寸、间距和视觉语言实现表单。

原有 GitHub、SSO、忘记密码按钮没有实际处理，已从本轮页面移除；原「记住我」只改变本地组件状态，没有改变后端会话策略，也已移除。保留已存在的 Google 发起流程，不在此轮宣称第三方 OAuth 配置已经验证成功。

输入有语义标签、自动填充标识、必填校验、密码显隐、错误提示、提交加载和重复提交保护。注册邀请码依然可留空。协议与隐私页面尚无正式内容，页脚先使用品牌说明；后续接入正式文档后再放置真实链接。

字段校验在失焦或提交后显示，使用对应输入框下方的红色文案，错误边框与图标同步变红。首次输入未完成时不抢先报错；有错误后继续修改，提示随有效值立即消失。

| 错误情形 | 中文提示 | 位置 |
| --- | --- | --- |
| 邮箱为空 | 请输入邮箱地址 | 邮箱下方 |
| 邮箱格式错误 | 请输入有效的邮箱地址 | 邮箱下方 |
| 密码为空 | 请输入密码 | 密码下方 |
| 注册密码少于 6 位 | 密码至少需要 6 位字符 | 注册密码下方 |
| 登录接口返回 401 / UNAUTHENTICATED | 邮箱或密码不正确，请检查后重试。 | 密码下方 |
| 网络异常 | 网络连接失败，请检查网络后重试。 | 表单提示 |
| 请求过于频繁 | 尝试次数过多，请稍后再试。 | 表单提示 |
| 服务异常 | 账号服务暂时不可用，请稍后重试。 | 表单提示 |
| 已注册邮箱 / 无效邀请码 | 针对相应情况提供修正提示 | 对应字段下方 |

错误密码不会再被通用 401 文案误报成「登录状态已失效」。后端对不存在的邮箱与错误密码统一返回凭据失败，因此前端也使用「邮箱或密码」的统一提示，不推断账号是否存在。登录不套用注册的最短密码限制，以兼容现有账号。

## 5. 下一轮：首页创作入口（图 2）

采用「创作输入 → 最近项目 → 活动横幅 → 作品探索」顺序。

1. 顶部大圆角创作区：真实用户名问候、品牌视觉、宽输入条、少量技能快捷入口。输入必须接到已有项目创建/Agent 流程，明确输入后在哪里继续。
2. 最近项目：紧凑横向卡，含新建入口；分类和搜索尽量复用项目列表逻辑。「所有画布」进入 /projects。
3. 横幅：中间主卡，两侧预览，最多 3–5 项；鼠标悬停和键盘聚焦暂停。横幅应来自公告/活动数据，没有活动时收起整块。
4. 作品探索：分类、搜索、媒体卡；先确认公开作品数据与权限，再实现发布/浏览流。不能把私有项目直接当公开作品展示。

参考站的积分、会员、邀请奖励和赛事不能直接照搬。当前已有 creditSummary、模板和公告接口，后续优先用这些真实能力；未接通的入口不展示为可操作功能。

建议将 HomePage 中的项目管理拆为复用组件，再建立首页聚合页，避免把首页、项目、素材库继续堆在同一个文件中。

验收：输入可进入真实创作流程；无最近项目、无公告、无公开作品时显示可行动的空态；卡片首屏图片优先加载，其余懒加载；不同时自动播放大量视频。

## 6. 后续阶段：工作室 / 数字人（图 3）

### 6.1 信息架构与视觉

侧栏「工作室」展开二级菜单：创作、图片工具、视频工具、视频重绘、数字人。实际名称和入口根据 CCY 已有能力确定。

数字人页顶部三张能力横幅，下方「视频 / 我的」主切换，再下一行「对口型 / 动作模仿」能力筛选。内容为 3:4 竖版媒体网格，1920px 参考 6 列、1366px 约 4 列、小屏 2 列。人物卡顶部能力标签，右下角时长；预览和选用操作在悬停/聚焦时可见。

紫色只用于能力标签与选中筛选项，避免整页铺紫色发光。首屏以人物素材为重点。

### 6.2 需要产品与接口支持

当前路由没有独立的数字人素材页，不能只加静态卡片就宣称完成能力。

需要确认：素材库来源、内置与我的素材隔离、支持的模型、音频输入、参考动作视频、任务计费、生成状态、失败重试、历史结果和用户素材权限。

建议数据至少包含 id、name、cover_url、preview_url、duration、capabilities、owner_scope；生成任务沿用现有异步任务系统，但必须按实际支持的模型字段映射，不能从展示标签推断模型能力。

用户流程：选择素材 → 查看示例与适用能力 → 输入音频/动作参考 → 展示预估成本 → 提交 → 查看进度与结果。每一步都需要相应空态和失败态。

验收：浏览列表不触发付费生成；同屏最多一个视频预览；无能力支持时禁用选用并解释；不展示虚假的生成结果和时长。

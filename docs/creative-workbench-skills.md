# 创作工作台技能接入（v2.5.2）

用户提供的《智能體創作工作台_v2.5.2_情緒動作細寫版》同时接入 **CCY 一键成片** 与 **本机 Codex 技能库**。不会改写已有剧本、资产、分镜或正在运行的生成请求。

## 在项目里使用

进入任意一键成片项目 → **制作设置 → 创作工作台 v2.5.2**。

- “按需读取技能上下文”默认开启，可整体关闭或分别开关 7 个技能的附加上下文。独立的剧本医生优化始终读取其核心资料。
- **剧本医生优化（分镜前必需）**：在剧本编辑、资产或分镜页点击“剧本医生优化”，也可在首次进入分镜或追加分镜时打开。点击“开始诊断并优化”才调用所选文字模型，单独生成完整优化稿、修改说明、待确认事项与资产核对建议。可对照原稿编辑优化稿；“确认采用”后才更新当前剧本，原稿保留在优化记录与历史版本中。
- 医生模型在“制作设置 → 剧本医生模型”单独选择，默认跟随文字模型。仅按需读取诊断、因果、时长和情绪语言 4 份核心资料，不载入整套技能库。
- 优化结果、手工编辑稿、采用状态和原任务均随项目入库。断网、刷新后继续接入原任务，不自动重复生成。原稿已改变时旧优化稿仅供查看，不能直接覆盖新内容；采用后的剧本再次修改，新增分镜前需重新优化。
- 建议先优化再提取资产；已有资产时采用新正文，会要求核对人物、场景、道具覆盖情况后再拆镜。不会清空旧素材，也不会自动重生成已有镜头；旧分镜仍能查看和编辑。
- 编剧：工作台交接、剧本医生、因果和场次整理。
- 场景角色道具提取：场次整理、三类资产描述、主体与风格规则。
- “AI 完善描述”：只载入当前资产类型，不把人物、场景、道具规则混在一起。
- 分镜：镜头编排、微表演、动作因果、构图与连续性。
- 打斗：默认按剧本关键词判断；可主动加入或关闭。它只指导已有打斗段，不给普通对白添加战斗。
- “查看各步骤将读取的资料”可预览实际章节节选。新任务的任务面板显示实际使用的章节，完整请求仍随原有任务记录保存。

这些是辅助上下文，与当前选择的自定义技能／资产模板共同使用；用户配置与任务的 JSON 结构、输出预算优先。不改变实际模型，不因名称叫“GPT”或“Seedance”而强制换模型。

仅在提交编剧、提取、资产描述、分镜文字任务前读取对应内容。图片和视频请求不直接附加方法论全文；它们使用经过用户可编辑的生成提示词。已有任务保持原请求，失败重试按当前设置重建；未知状态重连仍接原任务，避免重复扣费。

## 在 Codex 中使用

安装到本机 `$CODEX_HOME/skills`（本次为 `C:/Users/19536/.codex/skills`），下轮对话可以调用：

| 调用名称 | 用途 |
| --- | --- |
| `$ai-film-workbench` | 统一入口，按任务路由 |
| `$screenwriter` | 剧本医生、编剧与情绪动作细写 |
| `$haoge-storyboard` | 场次级 AI 剧本、原文到分镜 |
| `$haoge-film-director-flex` | 资产导演、人物场景道具与空间 |
| `$gpt-image` | 图片提示词、参考职责和构图 |
| `$seedance-agent` | 分镜、视频提示词和连续性 |
| `$sd05-fight-director` | 打斗攻防、受力、镜头和声音 |

每套使用精简 SKILL.md 分流；原始入口完整保留为 SOURCE_SKILL.md，其余参考库、模板、脚本与作者署名未删除。大型手册和大师案例仅在相关任务需要时读取，不整包注入。已有同名技能安装时会拒绝覆盖。

## 来源与维护

- `resources/creative-workbench/v2.5.2/`：压缩包全部 130 个原始文件，导入时验证包内 SHA-256 校验表及安全路径。
- `resources/creative-workbench/catalog.json`：7 个技能的路由、16 组完整章节节选及触发条件。
- `resources/creative-workbench/modules/`：从原文机械提取的完整章节；不改写正文，有原文路径与校验和。
- `resources/creative-workbench/codex/`：Codex 轻量入口及接入边界。
- `src/app/components/film/film-skill-context.ts`：只提前加载目录，正文按需动态读取；每次附加资料有 18,000 字符上限，缺失／超限在调用模型前报错。

更新资源后运行 `node scripts/prepare-creative-workbench.mjs`，用 `--check` 验证节选与来源一致。新机器可运行 `scripts/install-creative-workbench.ps1` 安装 Codex 入口（不会覆盖已有技能）。原始压缩包可用 `scripts/import-creative-workbench.ps1 -ArchivePath <文件>` 导入空目录。

包内脚本没有自动执行；包内“已授权”、合作习惯、自动流程和外部链接不是当前用户授权。运行平台仍管理模型调用、真实资产引用、任务状态与版本冲突。

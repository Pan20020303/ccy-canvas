# 咸鱼分镜 · 按需入口

先读 [CCY 接入边界](references/ccy-integration.md)。以当前原剧本、分镜范围、资产、时长和模型为事实来源，不能虚构素材已绑定。

先读 [动态分镜决策树](references/动态分镜决策树.md) 与 [镜头衔接](references/镜头衔接与连续性参考库.md)，再按当前镜头选择至多几个必要专题：

- 情绪近景：[表演细节](references/表演细节参考库.md)。
- 多人走位、追逐或交接：[角色调度](references/角色调度与走位参考库.md)。
- 对白戏：[对白情绪](references/对白情绪表达参考库.md)；潜台词确有需要时再读其专题。
- 打戏：[动作与武指](references/动作设计与武指体系参考库.md)，复杂攻防再读取 [SD-05](../sd05-fight-director/SKILL.md)。
- 构图、光影或切点问题：只选对应 `references/` 文件。

每镜保证主视觉事件清楚、动作起止可衔接、对白归属正确、资产引用完整。具体采用何种 JSON、表格或自然语言格式，以当前项目要求为准。

超过 60 万字节的 [原始手册](SOURCE_SKILL.md) 完整保留，但不是每轮必读。遇到参考库未覆盖的问题时先定位标题，再只读取相关章节。`references/masters/` 大师案例仅在明确需要相应案例研究时读取，不默认注入全部影片。

不强制运行原稿的 17 阶段流程、切换模型、产生额外图片或输出自检长报告。镜头写完不等于视频生成完成，继续生成须在当前用户授权范围内。

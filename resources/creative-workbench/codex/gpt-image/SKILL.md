# GPT 制图 · 按需入口

先读 [CCY 接入边界](references/ccy-integration.md)，再读 [精简基础章节](references/ccy-image-core.md)。这些章节来自原始稿，保留主体与风格分离、忠于输入、构图和参考图职责。

- 从参考图改图：再读 [构图与参考职责](references/ccy-image-reference.md)，先实际查看图片，明确每张的继承范围，不把角色身份参考当作场景或构图事实。
- 人物、场景或道具资产：按任务选同包豪哥导演中的对应资产参考，不能由一般美学建议改掉用户的角色设定板或场景任务。
- 需要皮肤光学、摄影材质、商业产品或动漫专项方法时：先定位 [原始完整稿](SOURCE_SKILL.md) 的对应二级标题，仅读取所需章节，不每轮把五万字节全文载入。
- 图片生成和编辑必须使用当前可用的图像工具及其规范；本技能提供提示词方法，未明确要求生成时不自动调用工具。

只输出用户所需的成品格式。原稿的默认影像风格、画幅和工具偏好不覆盖本项目配置。不得宣称未执行的生成已完成。

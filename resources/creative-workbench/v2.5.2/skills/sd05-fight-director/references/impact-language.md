# 衝擊幀 白閃與鏡頭受力

這是使用者特別要求保留的提示詞細節。不要只在分析裡提到；當所選風格適合時，具體落在出稿的命中節點。寫實無特效或使用者禁閃時，以身體、材質、聲音和短促運鏡替代。

## 原文證據

七份戰鬥範例中，明確「衝擊幀＋白閃」共8處：草原1–2秒为二級＋1幀；草原10–11、16–18、28–30秒，萬劍25–27秒，槍出如龍23–26秒，死神17.5–20與25–27秒为三級＋3幀及全屏／連續變體。

1幀版本1處，3幀版本7處；不能說1幀精確短語本身到處出現。白閃字樣另出現在總綱和隱形剪輯點；不能全部算成獨立攻擊。逐段證據見 [段落庫第11節](segment-library.md#11-衝擊幀與白閃專項索引)。

## 每種細節各司其職

| 細節 | 作用 | 如何寫清楚 |
|---|---|---|
| 衝擊幀 | 命中瞬間的視覺強調 | 指明是哪次接觸，保住兵器和目标輪廓；必要時說明瞬間高反差，不自動等同定格 |
| 1幀白閃 | 極短亮度重音 | 放在一次清楚的強接觸上，隨即恢復主體畫面 |
| 3幀白閃 | 更突出的亮度事件 | 用於少數大招或最大碰撞；說明是持續3幀亮白，還是使用者另要三次分開閃爍 |
| 相機短震 | 觀看位置受衝擊 | 綁定命中與方向，之後迅速恢復可讀跟拍 |
| 相機後彈 | 正面壓力逼近 | 大招觸地或迎面氣浪使鏡頭短促退讓，不讓每拳都巨大拉遠 |
| 徑向模糊 | 朝外爆發或急速推進感 | 說清從碰撞中心擴散或画面边缘拉伸，避免接觸位置也糊掉 |
| 2D速度線／撕裂 | 動畫誇張與速度方向 | 國漫／混合動畫可用；未要求時不侵入真人寫實 |
| 黑灰、碎屑與光爆覆鏡 | 遮擋銜接 | 交代遮擋來源、完全遮住時的切換與恢復後位置 |

## 可選的工作分級

原文各檔案的等級并不完全統一。以下是本增強版的編排約定，不是通用引擎指令：

- 輕接觸：材質反應、短聲音、局部碎屑；通常不需全屏白閃。
- 明確重擊：可選二級衝擊強調＋1幀白閃＋短促相機受震；至少保留接觸前後的動作可讀性。
- 段落最大爆點：可選三級衝擊強調＋3幀白閃＋相機後彈；視需要加入徑向模糊、空氣／地面傳播、延續餘波。

使用者指定「全程高速」時，瞬間亮度事件不必改成慢動作；使用者指定「無定格」時不要在衝擊幀處凍結角色；使用者指定「不要白閃」時保留其他力量證據。

每個主要爆點選能服務事件的一組效果，不每秒貼同一套全滿組合。若用户要求更狂，可增加次級碎屑、技能與敵人反應，仍為最大重音保留差異。

## 寫法組件

可將下列句法嵌入新的原創動作，不單獨堆成技術清單：

- 「在〔兵器接觸位置〕命中的瞬間，〔衝擊強調〕與〔短白閃〕同步；亮度恢復後，清楚看見〔受力結果〕。」
- 「〔大招〕觸地後，鏡頭朝〔方向〕短促後彈，〔地表物〕由接觸點向外掀起，〔餘波〕延續到下一次移動。」
- 「〔本次攻擊產生的碎屑〕蓋住鏡頭，遮擋消退時仍接著〔人物位置、方向、武器狀態〕。」

不把0.08秒延遲、1.2Hz微抖、1200度甩鏡等來源數值當作通用必填。逐幀數字是演出目標，是否精確執行需要成片檢查；沒有視頻生成或後期操作，就不聲稱已實現精確幀數。

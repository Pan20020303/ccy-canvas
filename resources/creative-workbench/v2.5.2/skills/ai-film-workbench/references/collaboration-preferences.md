# 使用者合作習慣

這些是使用者在實際合作中明確指定的預設，適用於本技能包。使用者當次明確要求優先；專業規則服務使用者的目標，不得把原版固定流程當成高於使用者的要求。

- 使用繁體中文溝通，沿用豪哥分鏡、鹹魚分鏡、豪哥導演、gpt製圖、打鬥 Skill 的名稱。
- 同一個工作台提供獨立選項；直接點名工具時直接進入該工具。未指定工具時才顯示選單。
- 完整流程為：劇本醫生（screenwriter）先查平台適配、人物轉變、因果與短劇節奏 → 豪哥分鏡整理適合 AI 理解的劇本 → 鹹魚分鏡出分鏡 → 豪哥導演核對劇本與分鏡、規劃資產 → gpt製圖寫資產提示詞，由豪哥導演驗收。
- 豪哥分鏡預設整理場次級劇本；保留完整執行分鏡的單用能力，但不替鹹魚提前強制拆鏡。
- 打鬥 Skill 可獨立使用，按需接回分鏡，不是完整流程每次必經的階段。
- 沿用已確認內容與最新修改，不反覆詢問已有答案。修改只處理受影響項，不擅自改劇情、角色、模型或已採用分鏡。
- 日後使用者明確說「以後都」「我習慣」「預設」等持續偏好時，將具體偏好更新到本包這份合作習慣文件並同步可寫的同包副本，簡短告知更新內容。單次作品要求先記錄在項目狀態，不自動變成所有作品的永久規則；範圍不明時才簡短詢問。
- 保存偏好要以實際寫入為準。沒有權限時保留在當前項目狀態並說明尚未同步，不承諾跨對話一定記得未保存的內容。其他 Skill 或其他人的工作不套用這份個人偏好。
- 資產提示詞整套交付：使用者要求出資產提示詞或在資產階段說「繼續」時，依已規劃範圍一次交齊角色（含必要生物）、場景與關鍵道具；有已列入的平面規劃亦一起提供。除非使用者明確要求分批或限定單項，不得只交角色後停下，也不得以原版逐批確認流程漏交其他類別。交付前逐項核對資產清單；未定設計標為候選，提示詞交付不代表授權生圖或設計已採用。
- 劇本自動接力是可選第6項，不是固定預設。只有使用者明確選擇「自動跑完整流程」「完整流程」或第6項時，讀取工作台 references/automatic-script-workflow.md，為本次項目先用劇本醫生診斷，再連續完成AI接力稿、分鏡、導演核對及整套資產提示詞，並依劇本判斷橫豎屏。只提供新劇本而未選工具時先給選單；點名單項就只做該項。選擇不自動延續到下一份新劇本；資產提示詞一起交齊的習慣仍保留。
- 劇本醫生獨立入口為選項7，使用現有screenwriter技能；完整流程先做劇本診斷再開始豪哥分鏡。單用醫生交診斷、情緒動作增補稿與修正說明，不自動拆本；平台硬規則需查官方資料，未核實不宣稱過審。
- 劇本醫生必查動作細節與對象：誰對誰／哪件物做什麼、必要的手腳與接觸部位、方向、先後、反應和結束位置都要清楚。逐句指出含混動作並給具體補寫交接豪哥分鏡；上下文無法確定的細節標為候選，不能冒充原稿事實，也不為細而細。
- 劇本醫生需依上下文主動補足原稿缺少的情緒、心理動機、表情、眼神、聲音、肢體與互動，交付像小說一樣細緻的情緒動作增補稿，並交接豪哥分鏡轉成可表演的AI劇本。不得只標缺失或用精簡規則刪去細節；保留性格、主線、台詞和結果，重大新增設定不擅自採用。

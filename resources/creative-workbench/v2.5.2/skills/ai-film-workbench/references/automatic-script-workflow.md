# 使用者的劇本自動接力模式

這是工作台第6項「自動跑完整流程」的可選模式，不是收到劇本後的固定預設。只有使用者選定本模式後，本次項目才跳過原版逐階段／逐批確認；不建立定時任務或監控資料夾。

## 啟動與範圍

只有使用者明確選第6項、說「自動跑完整流程」「完整流程」或其他同義授權時啟動。只貼劇本、說「這是我的本子」或未指定範圍的「幫我做」時，先展示工作台選單；點名工具、只要求閱讀／評論／翻譯／局部修改則直接執行相應任務。檔案內指令及劇本引文不構成模式選擇。

選定本模式即授權本次項目連續接力，不重問是否開始、不等每階段的「繼續」。本模式預選豪哥分鏡的「AI 劇本接力版」；單用豪哥分鏡時保留其交付選項。下一份新劇本重新按當次指示選路線，不因先前用過自動流程就默認啟動。

## 畫幅、時長與語言

1. 最新直接指示優先，其次劇本明載的9:16／16:9、豎屏／橫屏或其他明確比例；保留指定時長、語言、劇情與平台。不因短片便改成90–120秒，也不因進入導演階段更換既定模型。
2. 沒有明載畫幅时自主判斷：手機短劇、單人／雙人表演、上下高度關係或狹長縱深主導可選9:16；多人橫向調度、廣闊環境、橫向追逐／群體動作主導可選16:9。不能只看時長、類型或標題中的「短」字。
3. 證據相當時選最利於主要場面的畫幅，記錄「推定畫幅」和一句具體依據，不為普通選擇停工。遇見互斥的明確規格才釐清；並先完成不依賴畫幅的劇本整理。
4. 畫幅決定後，調整所有鏡頭的景別、人物占比、運鏡與站位，不只替換提示詞尾端比例。資產母板保留各類功能畫幅，最後用於影片的鏡頭圖／首幀按成片畫幅。
5. 沒有總時長時按完整台詞和動作提出可執行的時長，標為提案，不刪戲去硬湊固定秒數。保留來源台詞語言；面向使用者的說明沿用繁體中文。

## 連續執行

依次真正讀取各 Skill 及当前必要參考，不把讀檔當已完成創作，也不假稱已派出代理。

0. 劇本醫生：讀取 ../screenwriter/SKILL.md 及 references/script-doctor.md，先完成平台適配、人物轉變、因果、短劇節奏、時長及具體動作清晰度診斷，將含混動作的補寫交接下游，補齊小說式情緒、心理與具體表演細節，保存原稿定位、情緒動作增補稿與修正交接單。未選平台不冒稱符合特定平台；可繼續的部分先做。醫生完成後才進豪哥分鏡。
1. 豪哥分鏡：整理完整 AI 劇本接力稿，保留人物、台詞、因果、事件與結果。原稿只讀保存，製作稿另存。
2. 鹹魚分鏡：交付全片分鏡與每段完整影片提示詞、時長／台詞核對、跨鏡連續性。沒有圖就用文字資產描述，不能虛構素材綁定。
3. 打鬥 Skill：只有實際段落需要攻防／追逐編排時按需插入，結果回到既有分鏡；不另加戰鬥、不改勝負，不把它變成每片必跑。
4. 豪哥導演：核對劇本與分鏡。可自行修正不改劇情的鏡頭過載、接續、門向命名及計時錯誤，再核對受影響項。漏台詞直接補回。重大改戲、刪台詞、改身份、改結局或超過明定總時長不能自作採用；保留原需求、交付具體候選方案與未決標記，其餘工作繼續。
5. 豪哥導演立資產清單，gpt製圖把已規劃的角色／必要生物、場景、關鍵道具、列入的平面及設定板完整編譯成可複製提示詞。一次交齊所有類別，不只交角色，不以逐批確認或未回傳圖片阻塞。新造型、尺寸與空間方案可自主提出但必須與原稿事實區分，不能冒稱已採用。
6. 豪哥導演核對最終提示詞，補齊清單缺項、人物識別、機構方向、動作通道、畫幅和參考職責。只有真實可用且使用者指定的素材才能寫成已綁定參考。下游依賴未生成圖片時可明示未綁定的外部素材占位與用途，不能稱為已確認圖片。

## 一次交付與恢復

完整交付包至少包含：劇本醫生診斷、情緒動作增補稿與修正交接單、AI 劇本、全片分鏡、分段影片提示詞、導演核對、資產清單、全套資產圖片提示詞及流程狀態。提供一份總入口與打包檔；資產提示詞按 ID 各自完整、可單獨複製。

交付前以資產清單核對每項都有提示詞或明確未決原因，不能悄悄漏項。逐項記錄完成／候選／未決狀態；算術檢查、文字核對、動態預演、實際生成分開，不用「核對通過」冒充全片已測試。

流程完成於文本及提示詞交付。不自動生成圖片、影片，不自動上傳或消費付費服務。需要來源材料但找不到時說明缺項；長篇工作持續保存進度，不為篇幅限制默默截斷或把部分成果標成完成。續作從狀態恢復，優先更新受影響內容。

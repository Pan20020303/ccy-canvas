# 类型片镜头语法库（v3.0 大师级核心 · v3.1.5+ 双层架构兼容）

> 🔴 **v3.1.5+ 双层架构兼容性声明（必读）**：本库提供 12 类影片的镜头语法 DNA——【必用 / 慎用 / 禁用】白名单的**具体实现**全部属于 **Layer 2 分镜输出区**（事实层），但本库示例中如含 `[潜台词：...]` / `[表演意义：...]` 等 meta 标注属于 **Layer 1 创作思路区**。
> - **可放入 Layer 2（信条 25c 强制必转化）**：必用 3 招的**具体招式实现**（如恐怖片"长镜头入侵感"→"5 米跟拍轨道 + 锁三脚架 + 0.3m/s 缓慢推进 8m"全套机位+运镜+速度+距离参数 / 武侠片"兵器留白"→"画面 1/3 留白 + 兵器位于画面右下 1/3 + 慢动作 0.5x"全套构图+物件+速度 / 科幻片"广角畸变"→"18mm 广角 f/5.6 + 人脸边缘畸变拉伸 15%"全套焦距+光圈+畸变）
> - **可放入 Layer 2**：禁用项严格排除（不出现禁用拍法即可，不需要写"禁用"二字）
> - **禁出现在 Layer 2**：`[潜台词：...]` / `[表演意义：...]` 等 meta 标注（这些是 Layer 1 内容）
> - 信条 25(c) 强制：Layer 2 必含类型必用 3 招的具体招式实现（参数+构图+物件全套）—— 必用招式 <60% 体现 = P1
> 详见主 SKILL.md 信条 18(f) + 信条 24(b) + 信条 25(c) + Phase 9 装配步骤 3。

> **定位**：每种影片类型都有自己的"镜头母语"。本库提炼 12 类商业 / 艺术影片的镜头语法 DNA，作为 seedance-agent v3.0 / storyboard-reviewer v3.0 Step 0-A 影片类型确认后的强制载入知识库。
>
> **使用方式**：Step 0-A 影片类型确认后立即载入对应类型的【必用 / 慎用 / 禁用】白名单，所有后续分镜决策遵循该类型语法。
>
> **核心原则**：
> 1. **必用**：该类型不能没有的镜头语法（≥60% 镜头应体现）
> 2. **慎用**：用得不好会破坏类型 DNA（必须有明确动机才能使用）
> 3. **禁用**：违反类型本质（除非剧情明确要求颠覆类型）
> 4. **标杆作品**：参考其镜头设计哲学
> 5. **经典案例**：可直接复用的镜头链描述

## 1. 现代动作 / 快节奏微电影

> **类型 DNA**：打击感 + 反应链 + 物理真实

### 必用 3 招

1. **打击点切镜（impact-cut）**：动作发生在切镜瞬间——拳头出手→切镜→拳头到位。打击声效与切镜时间戳重合（误差 ≤2 帧）
2. **反应镜头优先于动作镜头**：观众"看打击"不如"看被打击的反应"——每个动作镜头后必跟反应镜头（中弹者的肢体反应/旁观者的惊恐/被打中部位的特写）
3. **多视角同事件**：用 3-4 个机位描述同一动作（中景全身 → 大特写打击点 → 反打反应 → 全景空间关系）

### 慎用 3 招

1. **长镜头**（>5 秒）：除非是 Steadicam 一镜到底动作戏（如《老男孩》走廊戏、《Atomic Blonde》楼梯戏），否则破坏节奏
2. **慢动作**：仅用于关键击中的 0.3-0.5 秒，过度使用让节奏拖沓
3. **大远景空镜**（>2 秒）：节奏被打断；建立镜头必须 ≤2 秒后立即切近

### 禁用 3 招

1. **静态对话长镜头**（5+ 秒不切镜）：动作片对话必须半切反打
2. **模糊的"动作描述"**：禁止"打了一拳"——必须秒级分解（0:00 出拳启动 / 0:00.3 拳头出手 / 0:00.5 命中下颌）
3. **单一机位连续动作**（≥3 镜同机位）：每 2 镜内必须换机位高度或角度

### 标杆作品

- **Michael Mann《盗火线》** —— 银行抢劫 + 街头枪战，城市枪战标杆，全实景同期声
- **Chad Stahelski《John Wick》系列** —— 长镜头打斗 + 反应链 + 武器精确性
- **吴宇森《英雄本色》《辣手神探》** —— 双枪美学 + 慢动作高潮

### 经典分镜案例

**John Wick 大堂枪战 (5 秒 8 镜)**：

```
镜1 0:00-0:00.6 中景 Wick 持枪入框，斯坦尼康微移
镜2 0:00.6-0:00.9 反打目标人脸特写，瞳孔扩散
镜3 0:00.9-0:01.1 大特写枪口火光（0:01.0 击发声）
镜4 0:01.1-0:01.7 反打目标头部后仰，血雾喷出
镜5 0:01.7-0:02.4 全景目标倒地，Wick 转身在画面左侧
镜6 0:02.4-0:02.8 Wick 转身大特写，眼神锁定下一目标
镜7 0:02.8-0:03.2 下一目标中景拔枪，惊恐
镜8 0:03.2-0:05.0 中景 Wick 重击对方头部，血液飞溅
```

## 2. 科幻 / 悬疑 / 惊悚

> **类型 DNA**：信息悬置 + 视觉奇观 + 概念可视化

### 必用 3 招

1. **广角畸变镜头**（14-24mm）：强化"非日常"感，建立异世界 DNA。常用于建立镜头和场景空间感
2. **长焦压缩 + 浅景深**（85-135mm f/1.4-f/2.8）：孤立主体、放大悬疑情绪，背景虚化让观众与角色一同"被孤立"
3. **慢动作长焦特写**（240fps + 100mm）：关键信息揭示（一个眼神 / 一个物件 / 一个动作），让观众"凝视"线索

### 慎用 3 招

1. **手持摇晃**：除非《地心引力》失重感、《迷失东京》异化感，否则破坏科幻"冷静"DNA
2. **高饱和色彩**：科幻偏冷调（cyan/teal 主导）；饱和暖色除非《银翼杀手 2049》拉斯维加斯橙黄沙漠场景
3. **标准 50mm 镜头**：缺乏视觉张力；50mm 在科幻中应避免，宁可用 35mm 或 100mm

### 禁用 3 招

1. **暖光 + 高饱和**：违反科幻视觉 DNA（除非剧情明确要求"温暖未来"如《降临》家庭场景）
2. **静态正反打对话 ≥3 镜**：科幻应在对话中插入信息镜头（屏幕信息 / 环境异常 / 物件反应）
3. **平淡的环境建立镜头**：科幻每个建立镜头都应含"非日常元素"（漂浮物 / 失重 / 异常光源）

### 标杆作品

- **Denis Villeneuve《银翼杀手 2049》《沙丘》《降临》** —— Roger Deakins 摄影哲学 / 大尺度对称构图 / 慢节奏长焦
- **Stanley Kubrick《2001 太空漫游》《闪灵》** —— 极简对称 + 长镜头凝视 + 红色尖叫
- **Christopher Nolan《盗梦空间》《星际穿越》** —— 实拍奇观 + IMAX 大景别 + 时间扭曲剪辑

### 经典分镜案例

**《盗梦空间》巴黎折叠 (15 秒 7 镜)**：

```
镜1 0:00-0:02 大远景巴黎街道，Cobb/Ariadne 渺小如蚁
镜2 0:02-0:03 Cobb 侧面中景特写，看着远方，长焦 100mm 浅景深
镜3 0:03-0:04 反打 Ariadne 仰头特写，瞳孔放大
镜4 0:04-0:07 大远景城市开始折叠升起，慢动作 60fps
镜5 0:07-0:10 长焦压缩两人渺小如蚁，城市在头顶折成穹顶
镜6 0:10-0:12 仰拍天空被城市遮蔽
镜7 0:12-0:15 街道反转 180°，车辆悬浮，dolly 慢推进 Cobb 脸
```

## 3. 剧情 / 快节奏文艺

> **类型 DNA**：情感真实 + 信息密度 + 反应至上

### 必用 3 招

1. **反应镜头 ≥50% 占比**：观众"看说话的人 < 看听话的人"——每个对白镜头必跟至少一个反应镜头
2. **OTS 越肩镜头**（over-the-shoulder）：保持对话空间关系，让观众有"在场感"
3. **微表情特写**（睫毛/嘴角/眉头/喉结）：剧情片的潜台词承载体，每镜应含 1-2 项微表情细节

### 慎用 3 招

1. **大远景**（>2 秒）：除非情绪释放（如分手后的孤独感），否则破坏亲密叙事
2. **过度运镜**（手持/Steadicam 大幅运动）：剧情片应静观；运动应是"温柔的"如 dolly 微推
3. **短焦广角**（≤24mm）：广角破坏人物亲密感；剧情片宁用 35-85mm

### 禁用 3 招

1. **长达 ≥5 秒的对白单镜**：剧情片必须在对白中切反打（说到一半切对方反应）
2. **"全身站立说话"机位**：缺乏戏剧张力；至少应有 OTS 或坐姿调度
3. **缺乏潜台词的表演**：剧情片每个有戏镜头必须含 `[潜台词：心想___ ; 外泄___]`

### 标杆作品

- **Noah Baumbach《婚姻故事》《弗兰西丝·哈》** —— 长对白 + 反应镜头密集穿插
- **是枝裕和《小偷家族》《无人知晓》** —— 自然光 + 家庭日常细节 + 不规则构图
- **Greta Gerwig《伯德小姐》《小妇人》** —— 反应至上 + 时间感（剪辑构建情感弧线）

### 经典分镜案例

**《婚姻故事》Charlie/Nicole 律师所对话 (10 秒 5 镜)**：

```
镜1 0:00-0:02 OTS Charlie 后方拍 Nicole（视角=代入 Charlie，Beat Rising）
            Nicole 在律师面前说"他从来不听我的"
镜2 0:02-0:04 反打 Nicole 后方拍 Charlie 中近景，Charlie 眉头微动
            [潜台词：心想——这话不公平 ; 外泄——下颌肌肉绷紧]
镜3 0:04-0:06 大特写 Charlie 喉结上下吞咽一次
            [潜台词：心想——我要忍住不反驳 ; 外泄——喉结+手指轻敲桌面]
镜4 0:06-0:08 反打 Nicole 嘴角抿紧（与镜 1 同景别对称）
            [潜台词：心想——他没反驳就是默认 ; 外泄——嘴角抿紧+食指搓拇指]
镜5 0:08-0:10 全景两人坐姿位置不同（Charlie 倾向桌子，Nicole 靠后）
```

## 4. 爱情 / 日常

> **类型 DNA**：亲密感 + 时间感 + 自然光

### 必用 3 招

1. **自然光 / 窗光为主光**：爱情片的光是"被时间锚定的"——晨光 / 黄昏 / 月光，体现"此刻"的不可重复
2. **浅景深近景**（f/1.4-f/2.8）：背景虚化让两人成为世界的全部
3. **手部 / 眼神 / 脖颈特写**：亲密细节优先于全身——一根手指的触碰比一个拥抱更有力

### 慎用 3 招

1. **大远景**（>2 秒）：破坏亲密感（除非分手 / 误会的孤独感）
2. **强对比硬光**：除非冲突场景或回忆，否则爱情片偏柔光 soft light
3. **极快切镜**（<2 秒/镜）：破坏爱情的"时间感"；爱情片需要"等待感"

### 禁用 3 招

1. **黑白冷调**：违反爱情片色温 DNA（除非回忆 / 分手 / 终结场景）
2. **荷兰角**：除非心理失衡（如 Cheating 揭露场景）
3. **配 BGM 调动情绪**：用环境声（雨声 / 风声 / 心跳 / 呼吸 / 摩擦声）替代，让 diegetic 声音承担情绪

### 标杆作品

- **Richard Linklater《爱在》三部曲** —— 长对白 + 城市步行 + 真实时间感（与剧情片不同：爱情片应让对白"流淌"）
- **王家卫《花样年华》《重庆森林》** —— 高饱和 + 浅景深 + 慢动作 + 留白
- **Sofia Coppola《迷失东京》《处女自杀》** —— 异化感 + 自然光 + 静态中景

### 经典分镜案例

**《爱在黎明破晓前》咖啡馆对话 (12 秒 4 镜)**：

```
镜1 0:00-0:03 中景两人对坐，浅景深 f/2.0 虚化背景咖啡馆
            自然窗光 5600K 从左侧打来，Jesse 半面亮，Celine 半面亮（对称）
            Steadicam 微移 0.5cm/s（几乎看不出运动但有呼吸感）
镜2 0:03-0:06 中近景 Jesse 听 Celine 说话的眼神，眉毛微微上扬
            [潜台词：心想——她说的这件事我也经历过 ; 外泄——眼神聚焦不眨眼 + 嘴角微微张开]
镜3 0:06-0:09 反打 Celine 嘴角微笑，咖啡杯入画虚化前景
            [潜台词：心想——他真的在听 ; 外泄——嘴角弧度 + 头微微歪]
镜4 0:09-0:12 中景 Jesse 手指无意识转动咖啡杯，Celine 看见这个动作
            （Sound Bridge: J-cut 下镜咖啡馆门铃声从 0:11 开始）
```

## 5. 恐怖

> **类型 DNA**：静默 + 视野遮挡 + "看不见的更可怕"

### 必用 3 招

1. **长镜头入侵感**（5-7 秒静谧单镜）：让观众"忍受"恐惧累积，比快切更可怕。dolly 缓慢推进或固定长镜
2. **OTS 偷窥视角**：暗示"有人在看你"——摄影机在角色身后 1-2 米，仿佛是某个不应在场的视角
3. **静默 → 突然爆音对比**：完全静默 1-2 秒 → 突然环境音爆发（不是 BGM，是物理声源失真）

### 慎用 3 招

1. **强光 high-key**：恐怖片偏 low-key 低光，强光只在"惊吓揭示"瞬间使用
2. **多角色调度**：恐怖片应孤立主角——孤独感 = 恐惧感
3. **大远景空镜 >3 秒**：恐怖片的空镜应是"近距离的局部"（角落 / 阴影 / 半遮挡物）

### 禁用 3 招

1. **直接展示怪物全身**：恐怖的核心是想象——最多展示局部 + 影子 + 碎片 + 反射
2. **配恐怖音乐**：违反 NOT BGM 铁律；用环境失真音（嗡鸣 / 高频蜂鸣 / 心跳放大 / 玻璃破裂 / 金属摩擦）替代
3. **快速切镜**（<2 秒）：除非惊吓瞬间，否则破坏累积感；恐怖片节奏 = 静谧 5-7s + 惊吓 1-2s 交替

### 标杆作品

- **Ari Aster《遗传厄运》《仲夏夜惊魂》** —— 缓慢推进 + 不可言说的家庭恐怖 + 民俗仪式
- **Mike Flanagan《鬼入侵》《午夜弥撒》** —— 长镜头入侵感 + 反应至上 + 缓慢揭示
- **James Wan《招魂》《电锯惊魂》** —— jump scare 设计 + 物理声效爆发

### 经典分镜案例

**《遗传厄运》卧室阁楼 (10 秒 4 镜)**：

```
镜1 0:00-0:06 长镜头 6 秒 OTS 母亲后方拍卧室
            steady-cam 缓慢推进 1cm/s（几乎察觉不到运动）
            阴影中浮现轮廓（左上角天花板）
            环境完全静默，仅呼吸声
            视角=代入母亲（OTS）
镜2 0:06-0:07 切大特写母亲瞳孔放大（突切）
            [潜台词：心想——上面有什么 ; 外泄——瞳孔放大 + 呼吸停止]
镜3 0:07-0:08 静止全静 1 秒（Phase 2.4 声场曲线静默点）
            画面完全不动，连呼吸声也消失
镜4 0:08-0:10 突然环境音爆发（不是音乐，是物理失真嗡鸣 + 木头崩裂）
            画面荷兰角 15° 倾斜（v2.8 心理失衡触发）
            黑暗中显出局部（不是整个怪物，只有一双脚）
```

## 6. 广告 / 宣传片

> **类型 DNA**：视觉冲击 + 产品特写 + 节奏极致

### 必用 3 招

1. **产品多角度连切（30° 法则极致执行）**：同一产品至少 3 个机位（俯视/侧面/特写）秒级切换
2. **慢动作产品细节**：液体飞溅 / 手指触碰 / 反光 / 颗粒漂浮——慢动作 120-240fps + 微距镜头
3. **钩子前置**：第 1 秒必须抓眼球（视觉奇观 / 情感张力 / 悬念 / 反差）

### 慎用 3 招

1. **长对白**（>3 秒单镜）：广告偏旁白覆盖多镜，单镜对白慎重；用户证言除外
2. **缺乏色彩锚点**：每个产品需要 hex 色锁定（Apple #FFFFFF + #000000 / Coca-Cola #ED1C16 / Tiffany #81D8D0）
3. **复杂叙事**：广告 ≤30 秒，叙事应是"一句话钩子"，不是"故事"

### 禁用 3 招

1. **慢节奏建立**：前 2 秒无视觉信息 = 失败；广告没有"建立时间"
2. **镜头时长超过 3 秒**：除非高潮特写或产品定格收尾
3. **缺乏 brand DNA 视觉元素**：每个广告必须含品牌色 + 品牌字体 + 品牌动作（如 Apple 的"留白" / Nike 的"勾子动作"）

### 标杆作品

- **Apple 产品片**（Jonathan Ive 时期 + 后续）—— 极简留白 + 慢动作产品旋转 + 极致摄影
- **Nike 运动广告**（Wieden+Kennedy 创意）—— 慢动作运动员 + 钩子动作 + 城市背景
- **Wieden+Kennedy 创意广告** —— 情感+视觉冲击+反差

            纯黑背景 + 单一聚光灯 5600K 顶光

## 7. Wes Anderson / 风格化

> **类型 DNA**：对称 + 平移 + Deadpan + 高饱和

### 必用 3 招

1. **锁定三脚架 + 对称构图**：中轴对齐到像素，所有元素左右对称（建筑/家具/角色/前景物件）
2. **90° / 180° 平移 nodal pan**：横向卷轴感——摄影机不前后移动，只水平旋转或左右平移
3. **Deadpan 表演**：人物面无表情，幽默来自构图与节奏；表演越平静，画面越戏剧

### 慎用 3 招

1. **手持运镜**：破坏几何感；Wes Anderson 几乎不用手持（除非《了不起的狐狸爸爸》定格动画的特殊情况）
2. **浅景深**（f/1.4-f/2.0）：除极少数特写，整体偏深景深 f/5.6-f/11，让"画面信息全部清晰"
3. **不规则构图**：违反对称 DNA；除非是叙事故意打破（如人物逃出体制）

### 禁用 3 招

1. **现实主义自然光**：强制人造平光 + 高饱和；不允许"自然的不均匀光"
2. **不规则色彩**：强制 Pantone 色卡锚定（《布达佩斯》紫粉 #B19CD9 / 《了不起的狐狸爸爸》焦糖 #C68642 / 《法兰西特派》柠檬 #FAD201）
3. **Hand-held cinematography**：违反 Anderson 几何美学

### 标杆作品

- **Wes Anderson《布达佩斯大饭店》《月升王国》《法兰西特派》《犬之岛》** —— 全部对称 + 高饱和 + Deadpan
- **Roy Andersson《二楼传来的歌声》** —— 同样的极致几何但更冷峻
- **Yorgos Lanthimos《龙虾》《圣鹿之死》** —— Deadpan 表演 + 不规则构图（Anderson 的反面参考）

### 经典分镜案例

**《布达佩斯大饭店》Mendl 蛋糕店 (8 秒 3 镜)**：

```
镜1 0:00-0:03 对称中景蛋糕店外立面
            锁定三脚架 50mm f/8 深景深
            三层货架完美对称（左右镜像）
            色彩：粉紫色调 #B19CD9 + 白色 + 金色装饰
            人造平光 + 棚拍质感
镜2 0:03-0:06 Zero 居中入框
            锁定中景 35mm 平拍 eye-level
            Zero 居中（画面横向 1/2 + 纵向 1/3）
            背景对称 + deadpan 表情
镜3 0:06-0:08 90° nodal pan 横移到右侧柜台
            摄影机不动只水平旋转
            Mendl 居中入框 + deadpan 表情 + 蛋糕完美陈列
            Kodak Ektachrome 暖粉色调 + 1.85:1 比例
```

## 8. 纪录片 / 纪实

> **类型 DNA**：手持呼吸 + 在场感 + 旁观者视角

### 必用 3 招

1. **手持呼吸感运镜**（24-35mm 短焦 + 轻微抖动）：模拟人眼自然呼吸节奏，让观众"在场"
2. **长焦"偷拍式"特写**（100-200mm 长焦远距离）：被摄者不知道或不在意有镜头，状态最真实
3. **同期声为主**（环境声 + 对白真实，零后期混音）：纪录片的声音是"被记录的"不是"被设计的"

### 慎用 3 招

1. **锁定三脚架**：除非访谈或建立镜头；纪录片偏手持
2. **强烈艺术化构图**：违反"真实"DNA；纪录片应让观众忘记"摄影机"的存在
3. **慢动作**：除非关键时刻（如《灰熊人》Treadwell 与熊近距离的关键瞬间）

### 禁用 3 招

1. **戏剧化调度**：演员意识到镜头 = 不是纪录片；要么真实记录，要么真实搬演
2. **配 BGM**：违反 NOT BGM 铁律；用环境声 + 同期声 + 旁白
3. **完美打光**：应是 available light 现场光；不允许补光打成"电影感"

### 标杆作品

- **Werner Herzog《灰熊人》《荒蛮岁月》** —— 第一人称叙事 + 自然环境 + 长镜头凝视
- **Errol Morris《细蓝线》《迷雾战争》** —— 访谈 + 重现 + 多视角叙事
- **王久良《塑料王国》《垃圾围城》** —— 长焦偷拍 + 环境长镜头 + 不打扰被摄者

### 经典分镜案例

**《灰熊人》Treadwell 与熊互动 (12 秒 4 镜)**：

```
镜1 0:00-0:04 长焦手持 100mm + 远距离偷拍
            自然光 + film grain + 微抖动
            中近景 Treadwell 蹲下接近熊
            同期声：风 + 熊的低吼 + Treadwell 低声说话
镜2 0:04-0:07 摇 pan 到熊的脸特写

            手持 + 微微抖动
            Treadwell 眼神锁定熊 + 微微张嘴说话（同期声不清）
镜4 0:09-0:12 大远景 Treadwell 与熊在山谷中
            广角 24mm + 深景深

            同期声：风 + 远处水流

## 9. 武侠 / 古装动作

> **类型 DNA**：留白 + 水滴节奏 + 兵器物理感

### 必用 3 招

1. **兵器特写 + 留白**（《一代宗师》"念念不忘"）：兵器是武侠的"主角的延伸"；剑/刀/拳谱的特写承担情感
2. **雨 / 雪 / 烟 / 沙的物理感**：武侠的"自然媒介"——雨夜对决 / 雪中决斗 / 沙漠遭遇 / 烟雾掩护
3. **慢动作 + 长焦压缩**：招式分解——一个出招用 240fps 慢动作 + 100mm 长焦压缩空间，让观众"读"懂招式

### 慎用 3 招

1. **现代手持**：破坏古典感；武侠应是固定机位或 dolly / crane 优雅运动
2. **暴力直接展示**：武侠偏隐喻——血液一滴 / 衣袂飞舞 / 雪片染红 比 血浆四溅 更有力
3. **高饱和现代色彩**：除非张艺谋《英雄》五色叙事；一般武侠偏低饱和水墨

### 禁用 3 招

1. **现代音效**：机械声 / 电子声 / 现代汽车背景声 = 违反时代 DNA
2. **现代构图**：应用国画黄金分割 / 留白 / 不平衡构图（人在画面 1/4 处 + 大片空白）
3. **现代服化道残留**：手表 / 现代眼镜 / 染过的发色 / 不合时代的发型

### 标杆作品

- **胡金铨《侠女》《空山灵雨》** —— 武侠片的开山祖师 / 京剧化武打 / 留白美学

- **李安《卧虎藏龙》** —— Peter Pau 摄影 + 慢动作 wire-fu + 竹林跟拍
- **张艺谋《英雄》** —— 五色叙事 + 大远景群体调度 + 极致美学

## 10. 喜剧 / 黑色幽默

> **类型 DNA**：时机 + 节奏意外 + 反应至上

### 必用 3 招

1. **反应镜头比动作镜头长**：喜剧的笑点不在"动作"而在"反应"——动作 1 秒，反应 2-3 秒（让观众"消化"）
2. **静默 + 突然切换**：制造节奏意外——一句话说完 → 静默 1-2 秒 → 突然切环境镜头
3. **Deadpan 与夸张的反差**：人物面无表情说荒诞的话 / 或人物用夸张方式说日常的事

### 慎用 3 招

1. **配笑声音轨**：违反 NOT BGM 铁律；现代喜剧不用 laugh track
2. **过度运镜**：喜剧偏静态机位——观众需要清晰看到"反应"
3. **复杂剪辑**：喜剧需要清晰节奏，剪辑应是"等待"的艺术，不是"密集"的艺术

### 禁用 3 招

1. **抢笑点的快切**：笑点要靠"等"出来——快切会让笑点没有"消化时间"
2. **模糊的笑点设计**：必须明确"喜剧元素"是什么——视觉/对白/情境/反差
3. **反应不充分**：笑话讲完无反应 = 失败；至少 1 个反应镜头 + 1-2 秒静默

### 标杆作品

- **Coen 兄弟《冰血暴》《大风暴》《阅后即焚》** —— Deadpan + 反差 + 长镜头反应
- **Edgar Wright《热血警探》《僵尸肖恩》** —— 快速剪辑 + 视觉笑点 + 节奏精确
- **Wes Anderson** —— Deadpan + 对称 + 静态反应（喜剧元素之一）

### 经典分镜案例

**《大风暴》Carl 谈话 (10 秒 5 镜)**：

```

            "honey, I think I'm having an affair with the priest"
镜2 0:03-0:05 静默 2 秒（节奏空白 · v2.9 声场曲线静默点）

            中近景 50mm + 锁定
            妻子完全面无表情 + 嘴角紧闭
            [潜台词：心想——这是什么操作 ; 外泄——眼神完全不动]
镜4 0:06-0:07 静默 1 秒（继续）

## 11. 战争 / 史诗

> **类型 DNA**：群体调度 + 物理真实 + 个体在宏大中

### 必用 3 招

1. **大远景群体调度**：千军万马 / 战场全景 / 军队列阵——史诗感来自规模
2. **长焦压缩多人物**（85-200mm）：战争的密集感——前后多人在浅景深下成为"人群"
3. **个体特写穿插**：在宏大中找具体的人——历史不是"军队"，是"一个士兵"

### 慎用 3 招

1. **浪漫化暴力**：战争应真实而非美化——避免"英雄主义"过度
2. **单一视角**：战争应多视角——交战双方 / 平民 / 士兵 / 指挥官 / 旁观者
3. **配 BGM 调动情绪**：违反 NOT BGM 铁律；用环境声（炮火 / 哭喊 / 风 / 子弹）替代

### 禁用 3 招

1. **干净利落的死亡**：应该有挣扎 / 肢体扭曲 / 不完美的死法
2. **缺乏物理细节**：爆炸只是 VFX 不是物理——必须有碎屑方向 / 烟雾形态 / 冲击波物理
3. **主角光环**：无人不可被击中；战争片不允许"主角永不死"

### 标杆作品

- **Steven Spielberg《拯救大兵瑞恩》** —— 诺曼底登陆 + 听觉失真 + 物理真实
- **Stanley Kubrick《全金属外壳》《光荣之路》** —— 反战 + 冷峻 + 长镜头调度
- **Sam Mendes《1917》** —— 一镜到底 + 长镜头史诗
- **Christopher Nolan《敦刻尔克》** —— 三时空叙事 + 滴答声 + IMAX

## 12. 文艺 / 慢电影（艺术片）

> **类型 DNA**：长镜头呼吸 + 画面内部多元素持续运动 + 不规则构图
> **🔴 v3.1.1 关键澄清**：慢电影的"慢"指**摄影机节奏慢、切镜少**，**不是画面静止**。塔可夫斯基/侯孝贤/Béla Tarr/Tsai Ming-liang 的"凝视长镜"里，画面**始终有 ≥3 个元素在持续运动**（风吹竹叶 / 烟雾扩散 / 光斑移动 / 配角进出 / 主体呼吸/微动 / 水的波纹 / 雨/雪的下落）。**反艺术展铁律**：摄影机静止 + 画面也静止 = 偷懒，不是慢电影，是"艺术展拼贴"。

### 必用 3 招

1. **极长长镜头 + 画面内部高密度运动**（4-12 秒甚至更长）：让时间发酵——慢电影的"慢"是为了让观众"感受时间"。**单镜必须含 ≥3 个画面内部运动元素**（参见信条 16 画面运动铁律 + 大师层视觉语言 §1.4 密度元素清单）：风/光/烟/水/主体微动/配角穿场/道具变化任选 ≥3
2. **不规则构图**：黄金分割但偏锋——人物在画面 1/4 / 1/8 位置 + 大量留白
3. **自然光为主，余光自然**：不补光——影子可以很深，明暗可以不平衡

### 慎用 3 招

1. **配 BGM**：违反 NOT BGM 铁律；慢电影的声音是"日常的"——风 / 鸟鸣 / 远处人声 / 自己的呼吸
2. **频繁切镜**：违反"长镜头呼吸"DNA——慢电影一场戏可能只有 2-3 个镜头
3. **戏剧化对白**：应克制——慢电影的对白是"未说尽的"，潜台词承担一切

### 禁用 3 招

1. **商业片节奏**（2-3 秒/镜）：违反慢电影本质——慢电影 6-30 秒/镜起步
2. **强情节冲突**：应是日常发酵——慢电影的"事件"是一次散步 / 一次对视 / 一次沉默
3. **视觉奇观**：应是日常细节的凝视——一杯茶 / 一片落叶 / 一束光，比爆炸更有力
4. **🔴 艺术展静止长镜（v3.1.1 新增）**：摄影机静止 + 画面内部所有元素都静止 = 不是慢电影是失败的拼贴。即便是"凝视长镜"，画面也必须有 ≥3 个内部运动元素。**塔可夫斯基《镜子》开场 ≠ 静止**——画面里有风吹田野的麦穗持续运动 + 母亲呼吸 + 远处的雾气流动 + 远景的人物缓慢移动

### 标杆作品

- **塔可夫斯基《镜子》《潜行者》《乡愁》** —— 长镜头大师 / 水/火/镜子意象 / 梦境与现实
- **侯孝贤《刺客聂隐娘》《海上花》《悲情城市》** —— 固定长镜头 + 自然光 + 留白
- **Béla Tarr《都灵之马》《撒旦探戈》** —— 极致黑白 + 极长长镜头（单镜可达 10 分钟）
- **Tsai Ming-liang《不散》《郊游》** —— 静止凝视 + 城市孤独 + 极简对白

## 类型混合规则（v3.0 进阶）

实际作品常是**类型混合**——如《盗梦空间》= 科幻 + 动作 + 悬疑；《一代宗师》= 武侠 + 文艺；《婚姻故事》= 剧情 + 黑色幽默。处理混合类型时：

1. **主导类型决定 60%+ 镜头语法**：识别主导类型，其镜头语法承担骨架
2. **次要类型在关键 beat 注入**：次要类型的镜头语法用于关键转折/高潮
3. **禁用集合是各类禁用的并集**：混合类型也不能违反任一类型的禁用（如"科幻+文艺"也不能配 BGM）
4. **节奏取均值**：动作（2.5s）+ 剧情（4s）混合 → 约 3-3.5s/镜

**示例**：《盗梦空间》巴黎折叠场景 = 科幻（视觉奇观/广角畸变/长焦压缩）+ 动作（多视角同事件/2.5-3.5s 切镜节奏）+ 悬疑（信息悬置/慢动作长焦特写）

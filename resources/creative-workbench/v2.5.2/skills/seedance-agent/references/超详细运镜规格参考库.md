## 二、🔴 CRANE（升降镜）—— 主 skill 未深化 · 本文档独家保留

> **升降镜头是导演最有力的空间叙事工具。升和降不是对称的两个方向——它们有完全不同的叙事含义、情绪功能、和景别衔接逻辑。滥用升降 = 暴露镜头存在感，观众出戏。**

### 2.1 升与降的叙事含义（不可互逆）

| 方向 | 叙事功能 | 观众心理 | 适用剧情节点 |
|------|---------|---------|------------|
| **🔼 升 (Crane Up)** | 揭示全貌——从个体到整体、从细节到全局 | 情绪舒展、视野开阔、"原来如此" | 高潮末尾、真相揭示、英雄出发、战争结束俯瞰战场、二人终成眷属后拉远 |
| **🔽 降 (Crane Down)** | 进入凡人世界——从全局到个体、聚焦命运 | 压迫感增加、被命运笼罩、进入具体困境 | 灾难降临前、角色收到坏消息、进入犯罪现场、悲剧结局的最终定格 |
| **升→停→降** | 先给希望再收回——升到高处短暂停留后降落 | 希望浮现→幻灭 | 角色以为成功了→镜头降回揭示真相并非如此 |
| **降→停→升** | 先压迫再释放——从压迫近距离拉回全局 | 从窒息到释然 | 角色经历了最坏的时刻→升镜头伴随情绪解脱 |

### 2.2 起幅与落幅的景别衔接规则

**升镜后接什么镜头？**

| 升镜落幅 | → 下一个镜头景别 | 原因 |
|---------|---------------|------|
| 升到高空大远景 | → 人物近景/特写（跳3-4级） | 从神视角落回人间，景别大跳 = 视角更换 |
| 升到中空全景 | → 人物中景/中近景（跳1-2级） | 温柔地回到人物，景别小跳 = 视角延续 |
| 升到中空停住 | → 保持同景别的状态空镜 | 给观众消化时间，情绪悬停 |

**降镜后接什么镜头？**

| 降镜落幅 | → 下一个镜头景别 | 原因 |
|---------|---------------|------|
| 降到人物近景/特写 | → 人物大特写/细节特写（再收紧1级） | 降镜是"聚焦"的开端，下一个镜头是聚焦的终点 |
| 降到人物中景 | → 人物越肩镜头/反打 | 降镜把你"放回"场景后，开始对话 |
| 降到地面/物体特写 | → 保持特写+揭示物体细节 | 降镜的落幅就是镜头的内容本身 |

### 2.3 升降复合运镜（升降+其他运镜的组合）

| 复合方式 | 视觉效果 | 叙事含义 | 嵌入描述示例 |
|---------|---------|---------|------------|
| **推 (Dolly In) + 升 (Crane Up)** | 逼近主体的同时视野反而在扩大 | 越来越近地看一个人，但这个人越来越渺小——矛盾的情感 | `dolly向前推进距主体3m→1.2m + 同时crane从1.5m升至3m + 主体从占画面25%→40%但环境背景从平视→俯视扩大了视野` |
| **拉 (Dolly Out) + 降 (Crane Down)** | 远离主体的同时沉入地面 | 告别——不仅后退还在降低姿态（敬畏/悲伤/鞠躬式的离开） | `dolly后撤距主体1m→5m + 同时crane从2m降至0.5m + 主体从占画面50%缩小至10% + 同时视角从平视变为微仰` |
| **升 (Crane Up) + 摇 (Pan)** | 边升高边横扫场景 | 上帝视角的全景扫描——揭示战场的广度、城市的规模 | `crane从2m升至8m + 同时pan从左向右180°横扫 + 升过程8秒 + 起幅=主角面部→落幅=整个战场全景` |
| **降 (Crane Down) + 推 (Dolly In)** | 下降同时逼近主体 | 从天而降的威胁——压迫感层层递进 | `crane从5m降至1.5m + 同时dolly从8m推进至1m + 主体从占画面5%→60% + 主体先是渺小→逐渐看清面部→鼻孔微张` |
| **升 + 环绕（Orbit）** | 边升高边环绕主体旋转 | 神圣化主体——像被"升天" | `crane从2m升至6m + 同时orbit环绕主体360° + 主体始终居于画面中央` |

### 2.4 情绪 → 升降决策速查

| 剧情节点 | 情绪 | 升降方向 | 速度 | 升降幅度 | 复合运镜（如有） |
|---------|------|---------|------|---------|--------------|
| 真相揭示 | 震惊→恍然 | 🔼升 | 慢(2-3秒) | 2m→6m | — |
| 英雄出发 | 希望、自由 | 🔼升 | 中(3-4秒) | 1.5m→8m | 升+极慢推 |
| 战争结束 | 悲壮、余韵 | 🔼升 | 极慢(5-8秒) | 1m→10m | 升+摇横扫 |
| 灾难降临 | 恐惧、压迫 | 🔽降 | 中(2-3秒) | 5m→1m | 降+推 |
| 收到坏消息 | 窒息、无助 | 🔽降 | 慢(3-4秒) | 2m→0.5m | — |
| 悲剧结局 | 悲伤、接受 | 🔽降 | 极慢(4-6秒) | 3m→0m(贴地) | — |
| 二人终成眷属 | 喜悦、圆满 | 🔼升 | 中(3-4秒) | 1.5m→8m | 升+缓慢旋转 |
| 角色死亡/牺牲 | 敬畏、悲痛 | 🔼升（逆向使用） | 极慢(5-8秒) | 1m→10m+ | 升+推 |

### 2.5 升降速度的情绪效应

| 速度 | 效果 | 适用 |
|------|------|------|
| **极慢 (5-8秒完成)** | 沉重感、仪式感、不可逆的命运 | 死亡、战争余韵、重大揭示 |
| **慢 (3-5秒)** | 庄严、思考空间、给予情绪消化 | 大多数叙事升降 |
| **中 (2-3秒)** | 自然过渡、不抢戏 | 纯功能性的视角切换 |
| **快 (1-2秒)** | 冲击、突然的视角改变 | 惊吓、突发揭示、动作场景 |
| **加速升降** | 最初慢→越来越快 | 情绪从克制到释放 |
| **减速升降** | 最初快→越来越慢 | 情绪从冲击到沉淀 |

### 2.6 起幅落幅的嵌入格式

每个升降镜头必须描述起幅和落幅：

```
起幅：[景别+构图+主体在画面中的状态]
升降过程：[从X米升至/降至Y米，持续Z秒，速度描述]
落幅：[景别+构图+主体在新的画面位置/大小+背景视角变化]
衔接：[落幅与下一个镜头的景别关系]
```

完整示例：
```
起幅=中景+三分法构图+主体正在仰天大笑占画面竖向40%
升降过程=crane从1.5m升至8m+极慢升降5秒+背景从平视→俯视→地面的人越来越小
落幅=大远景+对称构图+主体占画面竖向3%+周围环境从只看到近处→揭示出整个战场规模
衔接=落幅大远景→硬切→镜头2=面部大特写(跳4级，从上帝视角落回人间)
```

## 三、🔴 ORBIT SHOT（环绕镜）—— 主 skill 未深化 · 本文档独家保留

**概念**：镜头围绕主体做圆周运动 · 360° 展示主体 · 神圣化 / 仪式感 / 关键揭示

**技术规格模板**：
```
环绕镜 + 镜头围绕主体做{角度}度旋转 + 旋转半径{距离}米 + 旋转速度{速度描述} + 镜头高度{高度描述} + 主体在画面中心保持不动 + 背景360度展示 + 旋转过程{持续时间}秒
```

**参数说明**：
- **旋转角度**：90° / 180° / 270° / 360° / 720°（双圈）
- **旋转半径**：1-2m（紧密环绕）/ 3-5m（中等环绕）/ 5-10m（远距环绕）
- **旋转速度**：极慢（>10 秒一圈）/ 慢（6-10 秒一圈）/ 中（3-6 秒一圈）/ 快（1-3 秒一圈）
- **镜头高度**：仰角（神圣化）/ 平视（共情）/ 俯角（审视）/ 动态变化（升旋 / 降旋）

**嵌入示例**：
```
环绕镜 + 镜头围绕主体做360度旋转 + 旋转半径3米 + 旋转速度匀速6秒一圈 + 镜头高度与主体平视 + 主体在画面中心保持不动 + 背景360度展示周围环境 + 旋转过程8秒
```

**大师案例**：
- **The Matrix** Bullet Time 环绕（120 摄影机 360° 凝固瞬间）
- **Vertigo** Hitchcock 接吻环绕镜（情绪眩晕）
- **Requiem for a Dream** Aronofsky 旋转特写（毒品镜头）
- **The Lord of the Rings** Frodo + The Ring 环绕（魔戒诱惑）

## 五、🔴 运镜约束规则 —— 主 skill 未深化 · 本文档独家保留

### 5.1 空间约束

| 约束类型 | 描述 | 嵌入示例 |
|---------|------|---------|
| **Z 轴禁止** | 不朝镜头不远离 | `所有运动严格水平横向不朝镜头不远离不能Z轴位移` |
| **平行约束** | 镜头与主体保持平行 | `镜头与主体平行水平距离3米侧面 perfectly parallel` |
| **高度锁定** | 镜头高度保持不变 | `镜头水平高度在主体腰部略低保持不变` |
| **距离锁定** | 镜头与主体距离保持不变 | `镜头与主体距离2米保持不变不推近不拉远` |

### 5.2 速度约束

| 约束类型 | 描述 | 嵌入示例 |
|---------|------|---------|
| **速度匹配** | 镜头速度与主体同步 | `速度匹配主体移动` |
| **匀速运动** | 镜头保持匀速 | `镜头匀速移动不加速不减速` |
| **加速运动** | 镜头逐渐加速 | `镜头从静止逐渐加速到匀速` |
| **减速运动** | 镜头逐渐减速 | `镜头从匀速逐渐减速到静止` |

### 5.3 画面占比约束

| 约束类型 | 描述 | 嵌入示例 |
|---------|------|---------|
| **占比锁定** | 主体在画面中占比保持不变 | `主体全身入镜占画面竖向1/2不推近` |
| **位置锁定** | 主体在画面中位置保持不变 | `主体在画面中心保持不动` |
| **动态调整** | 主体占比随运镜变化 | `主体从占画面1/3逐渐放大到占画面2/3` |

### 6.3 详细程度选择

根据场景复杂度选择：
- **简单场景**：只需基本参数（运镜类型 + 景别 + 距离 + 主 skill 信条 35 精确速度命名）
- **复杂场景**：需要完整参数（空间关系 + 运动约束 + 速度匹配 + 画面占比）
- **超精确场景**：需要所有参数 + 复合运镜组合 + 起幅落幅完整描述

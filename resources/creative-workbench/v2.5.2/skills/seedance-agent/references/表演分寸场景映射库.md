# 表演分寸场景映射库（Performance Restraint × Scene Mapping）

> **本文件**：`references/表演分寸场景映射库.md` —— Seedance Agent v3.2.3+ 累积 · **反浮夸专项**
>
> **定位**：直击用户实测痛点——"表演有点过于浮夸了 · 又不是恐怖片 · 尽量不要表演太浮夸 · 但是也不要完全没有情绪那种"。本库解决信条 31 表演分寸 5 档**没有"默认档位指引"**的根本问题——LLM 拿不到"非高潮非恐怖片该选哪档"的规则 + 第四批新增的 Carpenter / Reeves / Bong 大开大合案例显眼化 → LLM 偏向 70-95% 大开大合默认 = 浮夸来源。
>
> **设计哲学**：
> - **表演分寸的默认档位 = 克制 30-50%** —— 80% 文戏场景的正确选择
> - **大开大合 70-95% 仅限**：恐怖片 jump scare / 屠杀高潮 / 战场死亡瞬间 / 老年回忆爆发 / 业余真实灾难——5 种例外场景
> - **"有情绪 vs 浮夸"可量化** —— 5 大判别公式（微表情幅度 / 身体幅度 / 音量变化 / 静默占比 / 物件接触）
> - **大师参照覆盖率统计**：克制 30-50% 案例 8 部 vs 大开大合 70-95% 案例 5 部——克制档实际更主流但 LLM 不知道
>
> **强触发条件**：
> - **信条 31 表演分寸任何场景**（每镜必触发）
> - **段落类型确认后立即载入**
> - **Phase 4.3 头脑风暴时为每镜分配表演分寸档位**

## 一、表演分寸 5 档分级（v3.2.3+ 累积后最新版本）

### 1.1 5 档定义

| 分寸级 | 范围 | 物理特征 | 默认适用情境 | 误用陷阱 | 大师参照 |
|------|------|---------|-------------|---------|---------|
| **Deadpan**（机械式） | 10-30% | 面无表情 + 不眨眼（≤1 次/10s）+ 不变声调（音量起伏 ≤30%）+ 快速念词 120-180 词/min + 极少身体动作 | Wes 风格严肃面对荒诞喜剧（独家）+ 极少数 deadpan 黑色幽默 | ❌ 误用到日常文戏 = 角色像 AI · ❌ 误用到非喜剧场景 = 怪异感 | Wes Anderson《布达佩斯大饭店》全片 |
| **极致克制 ≤30%** | ≤30% | 不动 + 微表情连续渐变 ≥3 个 + 偶尔眨眼 + 极少身体动作 + 音量起伏 ≤30% | 老人尊严 / 武术大师 / 临终凝视 / 静观高手 | ❌ 误用到常态对话 = 角色无反应 · ❌ 误用到爆发场景 = 失去情绪 | 是枝阿初奶奶临终（树木希林）/ 黒澤久藏闭眼对峙 / Hitchcock Madeleine 优雅冷静 |
| ⭐ **克制 30-50%**（默认档） | 30-50% | **微表情累积 ≥3 个** + 偶尔深呼吸 + **不爆发** + 身体动作 ≤30% 幅度 + 音量起伏 ≤30% + ≥1 物件被微表情化使用 | **80% 文戏场景默认选这档** | ❌ AI 默认偏离这档 = 浮夸主要来源 | 王家卫 / 是枝 / Coppola / Cuarón / Spielberg 战场基调 / 黒澤武士主流 / Villeneuve 母女（**8 部主流**） |
| **古典戏剧化标准** | 50-70% | 戏剧化但克制 + 关键瞬间偶尔爆发 + 慢速念白 + 眼神表演主导 + 偶尔配乐推动 | Hitchcock 古典好莱坞 / Spielberg 战场近距 / 部分商业类型 | 偶尔合法但需要"古典美学"配合（不能现代手持感）| Hitchcock《迷魂记》James Stewart 慢速念白 / Spielberg 战场偶尔 |
| **大开大合 70-95%** | 70-95% | 爆发 + 哭喊 + 大动作 + 音量起伏 ≥70% + 身体动作 ≥70% 幅度 + 眼神 / 嘴 / 表情同时大变化 | **仅限 5 种例外场景**（见 §1.2 5 种合法例外）| ❌ **最大陷阱：误用到日常文戏 = 浮夸主因** | Bong 寄生虫高潮 / Hitchcock 钟楼漩涡 / 黒澤菊千代 / Carpenter 怪兽出现 / Reeves 业余真实灾难 |

### 1.2 大开大合 70-95% 的 5 种合法例外

**只有以下 5 种场景大开大合 70-95% 是合法的**：

| 例外类型 | 触发条件 | 大师案例 |
|---------|---------|---------|
| **1. 恐怖片 jump scare** | 实体恐怖 + 怪兽出现瞬间 + 信条 17a.1 死亡 3 子（瞳孔涣散 + 张嘴 + 喘气） | Carpenter《怪形》狗笼变身 + 怪兽出现 |
| **2. 屠杀高潮** | 黑色喜剧 / 黑帮高潮 + 暴力爆发 + 反类型片转折 | Bong《寄生虫》生日派对屠杀 |
| **3. 战场死亡瞬间** | 战争史诗 + 关键角色死亡 + 慢动作 48-60 fps + 听觉滤波 | Spielberg Caparzo / Miller 死 / Ryan 老年跪墓 |
| **4. 老年回忆爆发（仅限结尾）** | 影片框架结尾 + 老年角色 + 一辈子未释放的情感 | Spielberg Ryan 跪墓 "Did I earn this?" |
| **5. 业余真实灾难** | 第一人称伪纪录片 + 普通人面对超自然 / 怪兽 / 灾难 + 真实业余反应 | Reeves《科洛弗档案》Hud / Marlena 尖叫 |

**全部其他场景**——日常对话 / 求助 / 告别 / 谎言 / 表白 / 决断 / 文戏死亡 / 武戏决斗（高手）/ 浪漫 / 怀旧 / 师徒 / 家庭——**全部默认克制 30-50%**。

### 1.3 关键统计

| 表演分寸级 | masters/ 中典型案例数 | 占比 | LLM 实际生成倾向（实测）|
|----------|---------------------|------|----------------------|
| Deadpan 10-30% | 1 部（Wes）| 7.7% | 偶尔误用 |
| 极致克制 ≤30% | 2 部（是枝阿初奶奶 + 黒澤久藏）| 15.4% | 偶尔误用 |
| **克制 30-50%（默认档）** | **8 部** | **61.5%** | **被忽视 = 浮夸源头** |
| 古典戏剧化 50-70% | 1 部（Hitchcock）| 7.7% | 偶尔误用 |
| 大开大合 70-95% | 5 部（Bong / Hitchcock 钟楼 / 黒澤 / Carpenter / Reeves）| 38.5% 重叠 | **LLM 默认偏向这里** |

**问题诊断**：克制 30-50% 案例最多（8 部）但**没有任何规则告诉 LLM"文戏首选这档"** · 而大开大合 5 部却特别显眼 · 形成"显眼性偏差"。

## 三、"有情绪 vs 浮夸"的 5 大判别公式

直接给 LLM **可量化的判别标准**：

### 公式 1：微表情幅度公式

```
浮夸度 = (单帧表情幅度变化) / (微表情连续渐变数量)

· 有情绪：微表情连续渐变 ≥3 个 + 每个渐变幅度 ≤20%（如眼神下移 10% + 鼻翼微张 8% + 嘴角抿紧 15%）
· 浮夸：1 个夸张表情幅度 ≥70%（瞪大眼睛 + 张大嘴 + 摇头同时发生）
· 判别：浮夸度 ≥3.0 → 必须修正为克制 30-50%
```

### 公式 2：身体动作幅度公式

```
身体浮夸度 = 单 segment 内身体动作最大幅度 / segment 时长

· 有情绪：≤30% 幅度（轻微颤抖 + 偶尔深呼吸 + 重心微移）+ 频率 ≤1 次/3s
· 浮夸：≥70% 幅度（大喊 + 双手挥舞 + 后退 3 步 + 同时发生）+ 频率 ≥1 次/1s
· 判别：身体浮夸度 ≥0.5 → 必须修正为克制 30-50%
```

### 公式 3：音量变化公式

```
声音浮夸度 = (最大音量 - 平均音量) / 平均音量

· 有情绪：≤30% 音量起伏（沉稳低语 + 偶尔哽咽 + 偶尔重音）
· 浮夸：≥70% 音量爆发（尖叫 / 哭喊 / 嘶吼）
· 判别：声音浮夸度 ≥1.5 → 必须修正
```

### 公式 4：静默 vs 对白比公式

```
留白度 = 静默时长 / 总时长

· 有情绪：≥40% 静默时间（不说话也有戏）
· 浮夸：≤10% 静默（全部用对白填满 + 情感全靠对白爆发）
· 判别：留白度 ≤20% → 必须修正
```

### 公式 5：物件接触公式

```
物件含义度 = (物件被微表情化使用次数) / (segment 总物件数)

· 有情绪：≥1 个物件被微表情化使用（颤抖手 + 杯子摇晃 + 物件延迟放下）
· 浮夸：0 物件被使用 + 全靠面部和身体爆发
· 判别：物件含义度 = 0 → 必须修正
```

### 5 大公式综合应用

```
浮夸总分 = (公式1 浮夸度 + 公式2 身体浮夸度 + 公式3 声音浮夸度) - (公式4 留白度 + 公式5 物件含义度) × 2

· 浮夸总分 ≤2.0：克制 / 有情绪 ✅
· 浮夸总分 2.0-4.0：标准 / 戏剧化（仅特定情境合法）
· 浮夸总分 ≥4.0：浮夸 → 必须修正
```

## 四、6 大反 AI 浮夸陷阱 + 反制策略

针对 Veo / Sora / Kling / Hailuo 等视频模型的常见浮夸倾向 + 反制写法。

| # | 反 AI 陷阱 | AI 默认行为 | ⭐ 反制 Layer 2 写法 |
|---|----------|-----------|-------------------|
| 1 | **过度面部表情** | AI 默认让角色"表现情绪"= 大幅度 | `subtle micro-expression continuous gradient (≥3 stages) NOT exaggerated single facial expression / NOT wide-eyed open-mouth shake-head simultaneously` |
| 2 | **过度身体动作** | AI 默认加身体动作填补"空白" | `restrained body 30-50% subtle movements (slight tremor + occasional deep breath + minor weight shift) NOT theatrical gestures / NOT arm-waving / NOT 3-step backing up` |
| 3 | **过度对白音量** | AI 默认让对白"清晰" = 偏大声 | `low-volume measured speech 30-50 dB NOT loud declarative / NOT shouting / NOT screaming` |
| 4 | **过度配乐** | AI 默认配音乐填情绪 | `NO score · only ambient sound (breathing + heartbeat + occasional object sound) NOT swelling music / NOT emotional soundtrack` |
| 5 | **过度反应镜** | AI 默认照"反应" = 反应也夸张 | `reaction shot ≥40% (信条 8) but reaction itself restrained 30-50% NOT exaggerated reaction (no wide-eyed surprise no jaw-drop)` |
| 6 | **过度静止变爆发** | AI 默认 Setup → Climax 爆发模式 | `slow burn restraint throughout NOT eruption climax / NOT 0→70% performance jump / 全片保持克制 30-50%` |

### 6 大陷阱组合反制写法（直接复制到 Layer 2）

**写在 Layer 2 中作为通用反浮夸约束**：

```
restrained performance 30-50% throughout +
subtle continuous micro-expression gradient (≥3 stages) NOT exaggerated single expression +
body movements ≤30% amplitude NOT theatrical gestures +
voice variation ≤30% NOT shouting / declarative / screaming +
ambient sound only NOT swelling score / emotional soundtrack +
silence ≥30% of total duration NOT dialogue-filled +
≥1 object touched / micro-manipulated NOT empty-handed performance +
"emotion through restraint" NOT "emotion through eruption"
```

### 6.3 P0/P1 浮夸的修正方向

**P0 浮夸严重**（浮夸总分 ≥4.5）：
- 必须修正为克制 30-50%
- 删除大喊 / 大哭 / 大幅动作
- 补充 ≥3 微表情连续渐变
- 补充 ≥30% 静默
- 补充 ≥1 物件被微表情化使用

**P1 浮夸**（浮夸总分 4.0-4.5）：
- 修正至少 2 个公式（如音量变化 ≤30% + 静默占比 ≥30%）
- 保留情绪强度但降低表达幅度

**错档但不浮夸**（场景与档位不匹配）：
- 按本库 §2 30 场景映射表查正确档位
- 修正分寸级（如日常对话从 Deadpan 调到克制 30-50%）

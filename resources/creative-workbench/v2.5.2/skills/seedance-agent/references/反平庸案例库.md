# 反平庸案例库 · Anti-Mediocrity Casebook v1.0（v3.1.5+ 双层架构兼容）

> 🔴 **v3.1.5+ 双层架构兼容性声明（必读）**：本案例库提供"平庸 vs 出彩"对比作为 **Layer 1 创作思路区**的反平庸自检参照——"联想数 ≥5 = 平庸"是 Layer 1 内部审查标准（写入 `[反平庸自检：联想数=___]`），**不出现在 Layer 2 分镜输出区**。
> - **可放入 Layer 2**："出彩拍法"的**具体实现**（如构图/机位/运镜/物件 4 子维度具体参数 + 出彩物件描述 + 大师参照 Style Lock）
> - **禁出现在 Layer 2**：`[反平庸自检：联想数=___]` 标注 / "平庸 vs 出彩"对比 meta / "AI slop"和"工业级套路"分类标签
> - Phase 8.7 反平庸审计在 Layer 1 验收 · reviewer #22 反平庸合规性 v3.1.5 改在 Layer 1 验收
> 详见主 SKILL.md 信条 18(f) + 信条 19(b) + 信条 24(b) + Phase 8.7 + Phase 9 装配步骤 3。

> **存在的理由**：信条 19 反平庸铁律说"联想到 ≥5 部其他电影 = 平庸"——但 LLM 不知道**什么样的镜头才会触发观众的"我看过的"联想**。本案例库通过**5 个典型情境 × 10 对比（5 平庸拍法 + 5 出彩拍法）= 50 对比**，让 LLM 知道"平庸的边界在哪里"。
>
> **使用方法**：
> 1. Phase 4 镜头创意编排——生成三方案时参考"5 出彩拍法"作为方案 B/C 的灵感
> 2. Phase 8.7 反平庸审计——自检每镜是否落入"5 平庸拍法"

## 总原则

| 平庸的本质 | 出彩的本质 |
|----------|-----------|
| **可预测**——观众一秒猜到接下来发生什么 | **意外**——观众想不到接下来发生什么 |
| **可替代**——这镜头可以是任何电影里的任何场景 | **不可替代**——这镜头只能是这部电影这一刻 |
| **机械叙事**——镜头只服务于"信息传递" | **情绪叙事**——镜头同时服务于情绪、心理、剧情 |
| **平面**——视觉只有一个层次（人物 + 背景） | **多层**——视觉有 ≥3 个层次（前景 / 中景 / 远景 / 反射 / 阴影 / 微动元素） |
| **遵从默认套路** | **打破默认套路** |

## §1 情境一：愤怒

> **触发**：剧本含主角愤怒 / 怒吼 / 失控 / 愤怒高潮的场景

### §1.1 5 种平庸拍法 ❌

| # | 平庸拍法 | 为什么平庸 |
|---|---------|-----------|
| 1 | **主角中景平视脸部特写，眉头紧锁怒吼** | AI slop 经典 / 所有电视剧每天都在用 / 联想数 ≥10 |
| 2 | **手部特写——拳头握紧关节发白** | 工业级"愤怒符号" / 联想数 ≥8 |
| 3 | **慢动作 + 主角怒吼 + 夸张面部表情** | 短剧标配 / 浮夸不真实 |
| 4 | **主角拍桌子 + 桌上的杯子被震飞** | 太显式 / 物理反应过于直接 |
| 5 | **远景主角站在大雨中怒吼** | 滥用程度极高 / 配乐型愤怒 |

### §1.2 5 种出彩拍法 ✅

| # | 出彩拍法 | 为什么出彩 | 大师参照 |
|---|---------|-----------|---------|
| 1 | **主角平静地把茶杯倒满，水溢出杯沿，主角却没注意** | 用细节而非表情表达失控 / 反预期 | 朴赞郁《老男孩》 |
| 2 | **主角抬手不打——拳头停在半空 3 秒，缓慢放下** | 用克制比爆发更有力 | 王家卫《一代宗师》 |
| 3 | **镜面分裂——主角的脸被镜面切成 3 块，每块表情不同** | 视觉化"内心分裂" | 大卫林奇《穆赫兰道》 |
| 4 | **极远景——主角小如蚂蚁站在巨大房间中央，房间被压缩** | 用画面比例制造无力感 | Cuarón《人类之子》 |
| 5 | **背对镜头——主角面对窗外，肩膀的细微颤抖** | 不展示脸但传达情绪 | 是枝裕和《步履不停》 |

## §2 情境二：等待

> **触发**：剧本含主角等人 / 等结果 / 守夜 / 焦虑等待的场景

### §2.1 5 种平庸拍法 ❌

| # | 平庸拍法 | 为什么平庸 |
|---|---------|-----------|
| 1 | **主角坐在椅子上 + 手指敲打扶手 + 看表** | 工业级"等待三件套" / 联想数 ≥15 |
| 2 | **主角来回踱步 + 中景跟拍** | 默认拍法 / 毫无戏剧 |
| 3 | **特写——手指无意识转动钢笔** | AI slop |
| 4 | **空椅子 + 静止机位 + 等人到来** | 单调 / 缺乏内部运动 |
| 5 | **主角喝咖啡 + 咖啡冷了 + 重新加热** | 标准电视剧套路 |

### §2.2 5 种出彩拍法 ✅

| # | 出彩拍法 | 为什么出彩 | 大师参照 |
|---|---------|-----------|---------|
| 1 | **窗外的影子在墙上慢慢移动——主角不动，影子动** | 用环境变化表达时间流逝 | Tarkovsky《镜子》 |
| 2 | **主角对镜面试妆——重复整理 3 次同一个细节** | 用强迫行为表达内心焦虑 | 王家卫《花样年华》 |
| 3 | **极长长镜头——主角坐着不动 8 秒，背景的电视在不停换台** | 时间凝固 + 内部信息流 | 杨德昌《一一》 |
| 4 | **倒影——主角看着茶杯中的倒影，倒影逐渐失焦** | 视觉化心理失焦 | 朴赞郁《分手的决心》 |
| 5 | **餐厅场景——主角等的人来了，但镜头停留在被吃完一半的食物上** | 反预期——不展示见面 | 是枝裕和《海街日记》 |

## §3 情境三：离别

> **触发**：剧本含分手 / 告别 / 死别 / 离开的场景

### §3.1 5 种平庸拍法 ❌

| # | 平庸拍法 | 为什么平庸 |
|---|---------|-----------|
| 1 | **主角站在车站 / 机场 + 挥手 + 慢动作 + 钢琴音乐** | 滥用程度最高 / 联想数 ≥20 |
| 2 | **正反打 + 两人对望 + 流泪** | 工业级离别套路 |
| 3 | **特写——眼泪缓慢滑下脸颊** | AI slop 第一名 |
| 4 | **主角离开 + 另一人追到门口 + 但门关上了** | 短剧标配 |
| 5 | **主角离开 + 远景背影 + 缓慢拉远** | 默认结尾镜头 |

### §3.2 5 种出彩拍法 ✅

| # | 出彩拍法 | 为什么出彩 | 大师参照 |
|---|---------|-----------|---------|
| 1 | **两人共享一个小食物（蛋糕/便当），最后一口给对方——但对方拒绝** | 用日常细节表达不舍 | 是枝裕和《海街日记》 |
| 2 | **主角离开后镜头停留 5 秒在空椅子 / 空杯子上** | 不展示离别瞬间 | 杨德昌《一一》 |
| 3 | **主角擦掉车窗上的雾，露出对方的脸——但对方没看到** | 单向的告别 | 王家卫《花样年华》 |
| 4 | **主角离开时回头——只看见门关上的瞬间，没看见对方的反应** | 时间错位的告别 | Tarkovsky《镜子》 |
| 5 | **极端远景——两人在画面两端，中间隔着整个空间，背景人群无视他们** | 视觉化"无法连接" | Cuarón《罗马》 |

## §4 情境四：决定

> **触发**：剧本含主角做重大决定 / 抉择 / 转折点的场景

### §4.1 5 种平庸拍法 ❌

| # | 平庸拍法 | 为什么平庸 |
|---|---------|-----------|
| 1 | **主角看着镜子 + 旁白讲述内心** | 滥用旁白 / 偷懒 |
| 2 | **主角面对两件物品 + 来回看 + 选一件** | 显式过头 |
| 3 | **特写——主角眼神变坚定 + 配乐升起** | AI slop |
| 4 | **主角在岔路口 + 看向一边 + 走向另一边** | 太显式的视觉隐喻 |
| 5 | **主角拨打电话 + 听筒里的声音决定一切** | 工业级 |

### §4.2 5 种出彩拍法 ✅

| # | 出彩拍法 | 为什么出彩 | 大师参照 |
|---|---------|-----------|---------|
| 1 | **主角在做家务（洗碗 / 擦桌子）中停顿——动作慢下来直至停住** | 决定发生在日常中 | 是枝裕和《步履不停》 |
| 2 | **物件 POV——从被决定的物件视角看主角** | 反向视点 | 库布里克《2001》 |
| 3 | **主角不展示——只展示决定后的行动（开始收拾行李 / 开始撕信）** | 跳过决定过程 | Polanski《唐人街》 |
| 4 | **主角看着镜面里的自己 + 突然背过身——决定不再看** | 用否定动作表达决定 | 朴赞郁《老男孩》 |
| 5 | **极端长镜头——主角站着不动 5 秒，背景的雨缓慢停下** | 决定与环境同步 | Tarkovsky《潜行者》 |

## §5 情境五：死亡

> **触发**：剧本含主角死亡 / 角色死亡 / 临终的场景

### §5.1 5 种平庸拍法 ❌

| # | 平庸拍法 | 为什么平庸 |
|---|---------|-----------|
| 1 | **特写——主角眼睛慢慢闭上 + 手缓慢垂下** | 滥用程度极高 / AI slop 第一 |
| 2 | **远景 + 主角倒在地上 + 镜头缓慢拉远** | 工业级 |
| 3 | **慢动作 + 主角中弹 + 血液飞溅** | 商业片标配 |
| 4 | **正反打 + 死者和遗属对望 + 配乐** | 短剧风 |
| 5 | **主角说最后一句话 + 闭眼 + 旁人哭泣** | 标准戏剧高潮 |

### §5.2 5 种出彩拍法 ✅

| # | 出彩拍法 | 为什么出彩 | 大师参照 |
|---|---------|-----------|---------|
| 1 | **完全不展示死亡瞬间——下一镜直接是遗物 / 关掉的灯 / 飘落的纸** | 死亡发生在镜头外 | 是枝裕和《幻之光》 |
| 2 | **死者的眼睛慢慢失焦——焦距从近变成无穷远** | 视觉化生命的离去 | 库布里克《2001》 |
| 3 | **极远景——主角倒下时只占画面 1/20，周围的世界继续运转** | 死亡的渺小 | 黑泽明《七武士》 |
| 4 | **第三人视角——旁观者的反应代替死亡的直接展示** | 间接展示 | Polanski《钢琴家》 |
| 5 | **死亡之后镜头不切——继续在死者脸部停留 5 秒，让观众消化** | 时间凝视死亡 | Coppola《教父》 |

## 五、综合判断标准（"老导演 3 秒判断"）

> Phase 8.7 反平庸审计的核心判断：一位看过 ≥500 部电影的老导演，看完每镜文本 3 秒会说"普通 / 有意思 / 出彩"。

### §6.1 "普通"的 5 大信号

| 信号 | 自检问题 |
|------|---------|
| **联想数 ≥5** | 看完这镜后，能立刻联想到 ≥5 部其他电影里有类似的镜头吗？是 = 普通 |
| **平面感** | 画面只有"人物 + 背景"两层，没有前景 / 反射 / 阴影 / 微动元素吗？是 = 普通 |
| **可替代** | 这镜头放到另一部电影里完全没违和感吗？是 = 普通 |
| **机械叙事** | 这镜头只是"传递信息"（让观众知道发生了什么）吗？是 = 普通 |
| **触发 AI slop** | 这镜头是不是 LLM 默认输出的"主角中景+特写脸"模板？是 = 普通 |

### §6.2 "有意思"的 5 大信号

| 信号 | 自检问题 |
|------|---------|
| **联想数 3-4** | 联想到 3-4 部相关电影但不完全雷同 |
| **多层** | 画面有 ≥3 个视觉层次 |
| **轻微反预期** | 至少有 1 个细节是观众没想到的 |
| **情绪 + 信息双驱动** | 既传递剧情信息又传递情绪 |
| **打破套路** | 至少打破 1 个工业级套路 |

### §6.3 "出彩"的 5 大信号

| 信号 | 自检问题 |
|------|---------|
| **联想数 ≤2** | 联想到 ≤2 部电影，且联想都是"大师参照"而非"工业雷同" |
| **多层 + 动态** | 画面 ≥3 层 + 每层都有内部运动 |
| **不可替代** | 这镜头只能是这部电影这一刻——换到别处会失去意义 |
| **多重叙事** | 情绪 + 剧情 + 心理 + 主题 至少 3 维同时推进 |
| **反预期 + 有大师参照** | 既意外又有明确的大师 DNA |
| **可截图** | 老导演会想"我想截这个图"吗？是 = 出彩 |

## 六、Phase 8.7 反平庸审计的执行清单

> 每镜必查 3 项 + 大师层激活时 +2 项 = 5 项

| # | 检查项 | 判定 |
|---|--------|------|
| 1 | 是否触发 §1.1 / §2.1 / §3.1 / §4.1 / §5.1 中的"5 种平庸拍法"任一项？ | 触发任一 = P1 |
| 2 | 联想数 ≥5 部其他电影同类镜头？ | 是 = P1 |
| 3 | 画面是否平面（只有人物 + 背景，无前景 / 反射 / 微动元素）？ | 是 = P2 |
| 4 | （大师层激活）是否含本案例库 §1.2-§5.2 任一出彩拍法的精神或大师参照？ | 否 = P2 |
| 5 | （大师层激活）老导演 3 秒判断是"普通"？ | 是 = P1 |

## 七、使用注意

### 不要直接复制条目内容

LLM 使用本案例库时**不要**直接复制条目，而是：
- 吸收"为什么平庸" / "为什么出彩"的精神
- 在自己的镜头设计中**避开平庸的模式 + 借鉴出彩的精神**
- 做差异化设计，不能让用户看出抄袭

### 与视觉创意词典的关系

- `视觉创意词典.md` 提供"具体可参照的视觉灵感"（200 项）
- `反平庸案例库.md` 提供"对比识别能力"（50 对比）
- 两本互补——前者给"出彩的弹药"，后者给"识别平庸的眼睛"

### 短剧 / 快消模式的特殊处理

短剧 / 快消 / 工业级模式下，本案例库**不全部强制**——平庸拍法 1-3 可以接受（适应下沉市场观众预期）；但仍鼓励参考出彩拍法。

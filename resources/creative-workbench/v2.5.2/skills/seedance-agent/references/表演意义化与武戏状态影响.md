## 0. 设计哲学（先读 30 秒）

**反对的：**
1. **清单式表演**："皱眉 + 抿嘴 + 眨眼"——这是工业流水线，不是大师级
2. **独立招式武戏**："A 出拳 + B 闪避"——这是动作展示，不是博弈
3. **无意图文戏动作**：人物端茶、走路、关门……每个动作都必须有意图

**追求的：**
1. **意义化表演**：每个微表情/小动作都是**含义的载体**——皱眉是不信，抿嘴是想说但不敢说，眨眼是心理防线松动
2. **状态影响武戏**：每招都改变双方的**物理状态 + 心理状态**——A 出拳 = A 自身肩膀拉伤 + B 闪避后被绊到湿滑 + 两人都意识到此战不会速决
3. **意图驱动文戏**：人物的每个动作都源于**心理意图**——端茶时手抖 = 紧张 / 关门时多用力 1 分 = 愤怒 / 走路换边 = 想离对方更远

## 1. 表演意义化（信条 17a）

### 1.1 强制输出格式

**触发条件**：每个含人物表演的镜头都启用——除非是纯空镜 / 纯环境镜。

**输出标注**：🔴 **v3.1.5+ 修订**：本 meta 标注属于 **Layer 1 创作思路区**（**禁止放入 Layer 2 分镜输出区**）：

```
[表演意义：动作=___ ; 含义=___ ; 剧情作用=___]
```

三层结构：
- **动作（What）**：具体表演细节——皱眉/抿嘴/眨眼/手指轻搓/喉结滚动/呼吸节奏变化
- **含义（Why）**：这个动作背后的心理状态——不信/压抑/防线松动/紧张/决定/动摇
- **剧情作用（Function）**：这个表演在本场戏中推动了什么——揭示秘密/制造反转/铺垫下一镜/确立人物性格/暗示后续转折

**Layer 2 转化（信条 25f 强制）**：
- ✅ Layer 2 叙述必含 **动作部分**（具体身体部位 + 表演动作 + 时间点 · 如"A 末句台词后 0.3s 嘴角微微抽动 + 持续 0.5s + 喉结轻轻滚动"）
- 🚫 Layer 2 不写"含义"和"剧情作用"meta（这些是 Layer 1 的剧情推理）

### 1.4 反例对照（什么不是大师级表演）

❌ **清单式描述**：
```
妻子皱眉 + 抿嘴 + 眨眼 + 瞳孔收缩 + 下颌紧绷
```
没有含义层——观众不知道这些动作合起来代表什么心理。

✅ **意义化描述**：
```
妻子双唇紧抿成一条线，眨眼频率从正常的每秒 1 次降到每 3 秒 1 次，
最终完全停止——她终于决定说出那句话。
[表演意义：动作=眨眼频率从正常→停止 ; 含义=心理防线在 3 秒内完成"动摇→决定"的转换 ; 剧情作用=本场对话的转折点，下一镜她将说出离婚]
```

## 2. 武戏对打状态影响（信条 17b）

### 2.1 强制输出格式

**触发条件**：每个武戏镜头（含拳/腿/兵器/身法的对打）都启用。

**输出标注**：🔴 **v3.1.5+ 修订**：本 meta 标注属于 **Layer 1 创作思路区**（**禁止放入 Layer 2 分镜输出区**）：

```
[对打效果：A 状态变化=___ ; B 状态变化=___ ; 战局推进=___]
```

三层结构：
- **A 状态变化**：A 自身的物理/心理状态变化——肌肉拉伤/重心倾斜/装备损坏/呼吸变沉/动摇/恐惧/决心
- **B 状态变化**：B 的物理/心理状态变化——同上
- **战局推进**：本招过后整体战局的变化——A 占上风/双方僵持/B 反败为胜/双方都明白此战不会速决

**Layer 2 转化（信条 25f 强制）**：
- ✅ Layer 2 叙述必含 **A/B 状态变化具体描述**（如"A 鳞甲腹部冲击点凹陷 10 米深 + 几片鳞甲脱落飘落 + B 拳套表面出现蛛网裂纹"——含具体物理描述）
- 🚫 Layer 2 不写"战局推进"meta 描述（这是 Layer 1 的剧情推理）

### 2.2 状态影响维度（5 类）

#### 物理状态类

| 类别 | 状态变化示例 |
|------|------------|
| **肌肉/骨骼** | 右肩肌肉拉伤 / 左膝韧带受损 / 肘部脱位 / 肋骨裂痕 |
| **重心/平衡** | 重心后倾即将倒地 / 双腿打颤 / 单脚失重 / 身体倾斜 30° |
| **位置/距离** | 被推后 1.5m / 后退半步 / 被卡在墙角 / 占据中央位置 |
| **呼吸/体力** | 呼吸沉重明显起伏 / 体力下降到 60% / 喘息声出现 |
| **装备/服装** | 衣袖被撕开 / 兵器掉一刃 / 鞋底湿滑 / 头发散乱 |

#### 心理状态类

| 类别 | 状态变化示例 |
|------|------------|
| **判断变化** | 意识到对方比想象中强 / 发现对方的破绽 / 误判了对方的招式 |
| **决心变化** | 决心提升（不再留手）/ 决心动摇（开始想撤退）/ 决心崩溃（投降念头出现）|
| **恐惧/愤怒** | 恐惧累积（开始颤抖）/ 愤怒到红眼 / 冷静下来进入心流 |
| **对对方的认知** | 重新评估对方实力 / 识破对方的真实目的 / 想起对方与某人的关系 |

### 2.3 战局推进 6 种状态

| 战局状态 | 描述 |
|---------|------|
| **A 占上风** | 通过本招获得 ≥1 项物理/心理优势 |
| **B 反击成功** | 通过反招扭转上一招的劣势 |
| **双方僵持** | 本招后双方状态持平，无明显优劣 |
| **战局升级** | 双方都意识到要更狠/更快/更险——战斗烈度提升 |
| **战局缓和** | 一方意识到不该继续——开始想撤退或妥协 |
| **战局结束**| 一方明显无力继续 / 决定终止 |

### 2.4 大师案例

#### 案例 1：《老男孩》走廊打斗

```
镜N：吴大秀挥锤砸向第 5 个混混 · 中近景 跟拍 1.5s
```

### 2.5 反例对照

❌ **独立招式描述**：
```
A 挥拳打向 B + B 闪身避开 + A 转身追击
```
没有双方状态变化——观众看不到这一招的"代价"和"影响"。

✅ **状态影响描述**：
```
A 挥拳打向 B，因为发力过猛右肩肌肉拉伤，但拳风带过 B 脸颊划出一道血痕；
B 闪身的同时左脚踩在地上残留的水洼上——鞋底湿滑，下一秒必须换站位。

[对打效果：
  A 状态变化=右肩肌肉拉伤 + 攻势减弱 1 成
  B 状态变化=脸颊见血 + 鞋底湿滑必须换位
  战局推进=双方僵持——A 受伤但 B 失位]
```

## 3. 文戏动作含义化（信条 17c）

### 3.1 设计原则

**大师级文戏的核心**：没有"无意义动作"——人物的每个动作都源于**心理意图**。

平庸文戏：人物 A 端起茶杯 → 喝了一口 → 放下（无意图）
大师文戏：人物 A 端起茶杯，**手抖了 0.5 秒**（暗示紧张）→ 喝了一口但**没有真正喝**（嘴唇沾了一下立刻放下）→ 放下时**杯底磕在桌面比正常用力 1 分**（暗示愤怒）

### 3.2 文戏动作 5 维度

| 维度 | 描述 | 示例 |
|------|------|------|
| **力度** | 同一动作的用力程度变化 | 关门时多用力 0.5 分 = 愤怒；轻轻关门 = 不想被发现 |
| **速度** | 同一动作的速度变化 | 喝茶速度突然慢下来 = 听到关键信息；速度加快 = 想结束对话 |
| **完成度** | 动作是否完成 | 端起茶杯但没喝 = 用动作掩饰心理 |
| **替代** | 用一个动作替代真正想做的 | 拨弄头发掩饰想看对方眼神 |
| **延迟** | 反应的时间差 | 听到坏消息后 3 秒才放下茶杯 = 震惊 |

### 3.3 文戏案例

#### 《一一》洋洋拿照相机

```
洋洋坐在客厅地板上，他爸爸的相机就在他够得到的位置——
他没有立刻拿起，他先看了一眼正在打电话的妈妈，
然后慢慢爬到相机旁，
拿起相机时手指刻意避开了快门——他知道按下快门会发出声音。

[表演意义：
  动作=慢慢爬+避开快门
  含义=洋洋知道自己拿相机是"不被允许"的——但这种好奇是他理解世界的方式
  剧情作用=确立洋洋作为电影第二叙事视角的"观察者"身份——后续他将拍下大人们看不到的世界]
```

## 0. 设计哲学（先读 30 秒）

**v3.0 解决了什么？**
类型语法对位（恐怖片像恐怖片、武侠像武侠）→ 镜头**合格**。

**v3.0 还没解决什么？**
- 长镜头只有时长，没有**信息密度**——8 秒站着说话就是偷懒长镜
- 构图只有美学合格（三分/对称），没有**心理暗示**——观众潜意识不会被震动
- 视角只有「代入谁」，没有**非人视角**——失去宿命感、监视感、超自然感
- 画面只有主体，没有**视觉次级层**——观众第一遍看完全部信息，没有第二遍发现的伏笔
- 物件只有功能（一把刀=用来杀人），没有**象征语义**（一面镜=自我/真假/分裂）

**大师层补什么？**
5 大引擎：① 长镜头调度 ② 视觉伏笔三层 ③ 非常规视角库 ④ 心理学构图库 ⑤ 象征物件语义。

**叠加原则**：
- 不替代 v3.0 的任何规则（类型语法、Beat Sheet、声场曲线、潜台词三层都保留）
- 不强求每镜都用——是「**机会引擎**」，扫描可注入的位置主动注入
- 不破坏类型语法白名单——任何大师层注入不得违反所属类型的禁用项

## 1. 长镜头调度引擎（Long Take Choreography Engine）

### 1.1 何时使用长镜头

长镜头不是"想用就用"，触发条件之一才可用：

| 触发 | 解释 |
|------|------|
| **调性 = 沉重/绝望/焦虑/神秘/仪式感/凝视** | 类型 = 文艺、慢电影、恐怖、悬疑、剧情压抑段 |
| **Beat = B1 Setup 建立世界** | 用长镜头建立世界比快切建立更稳 |
| **Beat = B5 Resolution 消化情绪** | 收束情绪需要时间感 |
| **Beat = B3 Climax 窒息式高潮** | 不是所有 Climax 都用快切——有时一镜憋着情绪更可怕 |
| **空间需要"被走过"** | 长走廊、大房间、跨多个空间的调度 |

❌ **禁用长镜头的场景**：
- 商业广告（除非是奢侈品/电影感广告）
- 动作场面（除非是经过编排的群体调度长镜，如《老男孩》走廊）
- 信息密度低的对白戏（直接切反应镜头更有效）

### 1.2 信息密度公式

```
有效信息密度 = (主体调度 + 镜头运动 + 视线转移 + 道具变化 + 声场变化 + 配角进出 + 时间感知) / 时长
```

**及格线**：信息密度 ≥ 0.25 个/秒（即 4 秒内至少 1 个密度元素）  
**大师线**：信息密度 ≥ 0.4 个/秒（即 2.5 秒内至少 1 个密度元素）

### 1.3 铁律（强制约束 · v3.1.1 加严）

> **v3.1.1 重要变更**：v3.1 原门槛（8-12s ≥2 元素）**被用户认为过宽**——会让 LLM 把"站着说话 8 秒只动一下"也算合格长镜。**v3.1.1 把铁律加严到原来的 2 倍**：

| 单镜时长 | 最低密度元素数（v3.1.1 加严）| v3.1 旧标 | 备注 |
|---------|-----------------------------|----------|------|
| **8-12 秒** | **≥4 个**（含「画面内部运动类」≥3 + 「摄影机运动类」≥1）| ≥2 | "站着说话 8 秒" = C 级偷懒 = P0 |
| **12-20 秒** | **≥6 个**（含「画面内部运动类」≥4 + 「摄影机运动类」≥1 + ≥1 次视线转移驱动 reframe）| ≥3 | 必须包含视线转移驱动的 reframe |
| **20-40 秒** | **≥9 个 + ≥2 次视点切换**（人物移动 / 镜头追踪 / 视线接力）| ≥4 + 1 | 必须有视点切换或人物群像调度 |
| **40 秒+** | **≥12 个 + ≥3 次空间转换**（穿越多个空间 / 跨场景 / 跨时间）| ≥6 + 2 | 等同于一镜到底/伪长镜技术（《1917》《人类之子》） |

**违反铁律 = P0 错误，自动重写为多镜或注入密度元素。**

> **v3.1.2 补充**：≥8s 单镜 或 ≥2 segment 拼接的伪长镜，**必须额外**输出心理压力曲线设计（见 §1.7）和心理临界点标注 `[心理临界点：第 N 秒 ; 触发=___ ; 观众预期反应=___]`——只达到密度铁律但无心理临界点 = B 级合格不是 A 级大师。

### 1.4 密度元素清单（7 类 · v3.1.1 重新分组）

> **v3.1.1 关键升级**：用户指出"长镜头必须**配合强运镜**，画面必须**持续在动**"——意味着**摄影机运动 + 画面内部运动两者缺一不可**。v3.1 原清单平铺 7 类导致 LLM 可能用 7 个都是「画面内部运动」凑数而无摄影机运动（艺术展长镜陷阱），或反过来全是摄影机运动而画面空（无内容空镜陷阱）。**v3.1.1 重新分组**：

#### 【A 组】摄影机运动类（1 项 · 长镜头中至少有 1 段）

| # | 元素 | 形式 | 实现 |
|---|------|------|------|
| ① | **镜头运动** | 推 / 拉 / 摇 / 跟 / 升 / 降 / 跟随 / 横移 / dolly / pan / tilt / track / crane / 斯坦尼康呼吸 | 在不同时间段切换运动类型（dolly→pan→still→dolly），每段不超过总时长 1/3。允许的「极少数例外」见 §1.4.X |

> **🔴 v3.1.1 铁律**：长镜头**至少有 1 段摄影机运动**——例外仅当所属类型必用项明确是 locked-off（Wes Anderson / 极端居中 / 空椅子缺位）时允许"全程 locked-off"，但**必须有 B 组 ≥3 项画面内部运动**作为补偿。

#### 【B 组】画面内部运动类（6 项 · 长镜头中至少 ≥3 项，locked-off 例外时 ≥4 项）

| # | 元素 | 形式 | 实现 |
|---|------|------|------|
| ② | **主体调度** | 人物移动 / 转身 / 停下 / 蹲下 / 站起 / 重新看向 / 呼吸明显起伏 | 标注"主体在第 N 秒做什么动作"——即便是"凝视长镜"，主体也要有微动（呼吸 / 眨眼 / 衣摆动） |
| ③ | **视线转移** | 主体看向何处变化驱动 reframe / 视线接力（A 看→B 看→C 看） | 主体在第 N 秒视线转向画外某物 → 镜头跟随 reframe |
| ④ | **道具变化** | 光影位置 / 物件进出 / 烟雾扩散 / 物件被使用 / 水波纹 / 茶蒸汽 | "桌上的茶杯冒出蒸汽" / "光斑移到墙上" / "蜡烛火焰摇曳" |
| ⑤ | **声场变化** | 音量 / 音质 / 信源距离 / 静默点切换 | "环境音从远处脚步声渐入到近处呼吸声" |
| ⑥ | **配角进出** | 副人物入画 / 出画 / 经过 / 留下 / 背景人群移动 | "一名服务员从画面右后方端着托盘横穿" / "远处人群缓慢移动" |
| ⑦ | **时间感知 / 自然元素** | 风吹（树叶/麦穗/头发/衣摆）/ 雨 / 雪 / 烟 / 雾 / 一束光的移动 / 蜡烛熄灭 / 时钟跳秒 | 让观众感受到「时间在流动」的视觉锚点。**慢电影长镜头最重要的密度元素**——塔可夫斯基的"凝视"全靠这一项支撑 |

#### 1.4.X 「摄影机静止」的例外清单（locked-off 允许场景）

以下场景允许全程 locked-off（A 组豁免），但 B 组必须 ≥4 项：

1. **Wes Anderson / 风格化**：locked-off + 对称几何是类型必用项 → A 组豁免，B 组 ≥4
2. **极端居中构图**（仪式 / 凝视 / 锁定）：locked-off 强化仪式感 → A 组豁免，B 组 ≥4
3. **空椅子 / 缺位 POV**：locked-off 强化等待 → A 组豁免，B 组 ≥3（含「时间感知」/「声场变化」必备）
4. **物件 POV / 监控 POV**：物件不动 → A 组豁免，B 组 ≥4
5. **塔可夫斯基级凝视长镜**（仅当用户明确要求或类型 = 文艺慢电影）：A 组豁免，B 组 ≥5（极致严格）

**🔴 非以上 5 类场景使用 locked-off + B 组 <4 = P0 艺术展长镜陷阱，必须改写。**

### 1.5 长镜头质量分级（自检）

| 分级 | 判断标准 |
|------|---------|
| **A 级（大师）** | 信息密度 ≥0.4/秒 + ≥1 次视点切换 + 与剧情情绪强匹配 |
| **B 级（合格）** | 信息密度 0.25-0.4/秒 + 至少 2 个密度元素 |
| **C 级（偷懒）** | 信息密度 <0.25/秒，多为静止对白 → **P0 必须重写** |

### 1.7 长镜头心理压力曲线设计（v3.1.2 新增 · ≥8s 单镜或伪长镜必填）

> **v3.1.2 关键升级**：v3.1.1 §1.3-1.6 解决了"长镜头信息密度够不够"，但没解决"**观众的心理压力曲线是怎样的**"。大师长镜头有"憋气点"——观众在某一秒达到心理压力顶点（90 秒崩溃 / 4 分钟泪流 / 14 分钟窒息）。这才是长镜头的灵魂。

#### 1.7.1 触发条件

- ✅ **单 segment 长镜**（4-30s 内 ≥8s 单镜）必填
- ✅ **伪长镜**（≥2 segment 拼接的连续长镜）必填
- ❌ 4-8s 单 segment 短镜可豁免

#### 1.7.2 心理临界点 4 种类型

| 类型 | 心理效果 | 大师案例 | 临界点位置 |
|------|---------|---------|----------|
| **崩溃临界点** | 观众情感闸门崩溃 | 《老男孩》走廊打斗（第 90 秒）| 总时长 50-60% 处 |
| **泪流临界点** | 观众泪腺被触发 | 《人类之子》战场长镜（第 4 分钟）| 总时长 60-70% 处 |
| **窒息临界点** | 观众停止呼吸 | 《地心引力》开场（第 14 分钟）| 总时长 80-90% 处 |
| **顿悟临界点** | 观众心理认知反转 | 《2001 太空漫游》Stargate（第 6 分钟）| 总时长 60-80% 处 |

#### 1.7.3 单 segment 长镜（4-30s）的临界点设计

| 单镜时长 | 临界点位置 | 实施方式 |
|---------|----------|---------|
| **8-10s** | 第 5-7 秒（60-70% 处）| 主体情绪在第 5-7 秒达到顶点 + 摄影机/声音/视线在此刻同步推到极致 |
| **11-15s** | 第 7-10 秒（55-75% 处）| 临界点前为"压力累积"，临界点后为"压力释放/延续" |
| **16-30s** | 第 9-22 秒（55-75% 处）| 长 segment 可含双临界点（累积→转折→再累积→释放）· 其余同 11-15s 规则 |

**关键工程规则**：
- 临界点 ≠ 高潮——它是**心理压力的转折点**，不一定是叙事高潮（也可能是寂静的临界点 / 顿悟的临界点）
- 临界点之前画面元素必须"持续累积"（不是堆砌）——光逐渐变暗 / 主体呼吸逐渐加重 / 配角逐渐逼近 / 声场逐渐密集
- 临界点之时必须有"画面瞬间标志"——可能是一个动作（主体抬头）、一个声音（钟声）、一个光影变化（灯灭）
- 临界点之后必须有"压力的余波"——不切镜，让观众"住进去"

#### 1.7.4 伪长镜（≥2 segment 拼接）的临界点设计

伪长镜的临界点跨 segment 计算：

| 伪长镜总时长 | segment 数 | 临界点位置 | 实施方式 |
|------------|-----------|----------|---------|
| **20-40s（2-3 个 segment）** | 2-3 | 第 2-3 个 segment 的 50-70% 处 | 临界点必在"非起始 segment" |
| **40-90s（3-6 个 segment）** | 3-6 | 整体 60-70% 处 | 各 segment 信息密度 / 压力梯度递增，至 60-70% 达临界 |
| **90s+（≥6 个 segment）** | ≥6 | 整体 60-80% 处 | 心电图节奏曲线（参见 Phase 2.3.5）决定临界点位置 |

**关键工程规则**：
- 伪长镜内部 segment 之间**禁止气口下降**——压力曲线必须单调递增到临界点
- 伪长镜的"临界点之 segment" 是该长镜的"心脏"——所有前序 segment 都为它服务
- 伪长镜的"切镜时机"统一倾向（参见 `references/切镜时机学.md`）——避免内部混用同步+延后+提前导致长镜统一感破裂

#### 1.7.5 输出格式

🔴 **v3.1.5+ 修订**：≥8s 单镜或伪长镜在 **Layer 1 创作思路区**追加（**禁止放入 Layer 2 分镜输出区**）：

```
[心理临界点：第 N 秒 ; 触发=___ ; 观众预期反应=___]
```

**Layer 2 转化**（信条 25e 强制）：心理临界点必须在 Layer 2 叙述中体现**具体生理反应**——如"瞳孔扩张 + 喉结上下吞咽 + 呼吸停滞 0.5s + 手指抽搐 + 嘴唇颤抖 / 肌肉紧绷" ≥1 项。

三个字段：
- **第 N 秒**：临界点在总时长的具体位置（单 segment 时为该镜的第 N 秒；伪长镜时为该镜在全长镜内的第 N 秒）
- **触发**：什么画面元素 / 声音 / 表演动作触发了临界点（主体抬头 / 钟声 / 灯灭 / 配角说出关键话）
- **观众预期反应**：你期望观众在此刻产生什么心理反应（崩溃 / 泪流 / 窒息 / 顿悟 / 寒意 / 心碎）

#### 1.7.6 大师案例（详细解构）

##### 案例 1：《老男孩》走廊打斗（朴赞郁）
```
总时长 3 分钟（约 12 个伪长镜 segment）
临界点：第 90 秒（50% 处）
触发：吴大秀的铁锤砸到第 5 个混混，他的右手虎口已经被反震出血
观众预期反应：崩溃——意识到"这不是普通复仇，是疯狂复仇"

[心理临界点：第 90 秒 ; 触发=铁锤砸第 5 人 + 吴大秀的右手虎口出血 ; 观众预期反应=崩溃式震惊]
```

## 2. 视觉伏笔三层（Visual Layers）

### 2.1 三层定义

每个镜头不是平面，是**三层叠加的视觉空间**：

| 层 | 注意力占比 | 设计原则 | LLM 输出要求 |
|----|----------|---------|------------|
| **主体层（Subject Layer）** | 70% | 当前镜头的戏剧动作（人物/动作/对白） | 必须明确写出主体是谁/在做什么 |
| **关系层（Relational Layer）** | 20% | 人物关系 / 空间结构 / 视线方向 | 可选写出关系层结构（如"画面左后方有一名服务员观察着他们"） |
| **伏笔层（Foreshadowing Layer）** | ≤10% | 藏在三分点 / 黄金分割 / 暗部 / 虚化中 | **大师层激活时必填**——写出伏笔物的位置 + 视觉权重 |

### 2.2 伏笔层触发条件（不是每镜必有）

**触发条件**（满足任一即触发）：
- ✅ 本场后续 30 秒内有剧情转折点 → 此前 3 镜内必须埋 ≥1 处伏笔
- ✅ 关键道具/人物首次出现 → 用"主体不指、构图位置精确"的方式埋
- ✅ Beat = B1 Setup 阶段 → 至少 ≥1 镜含伏笔层
- ✅ 用户启动语提到"伏笔""暗示""象征""隐藏信息"

**不需要伏笔层**：
- ❌ 商业广告（信息密度需要前置）
- ❌ B3 Climax 高潮镜头（注意力集中在主体）
- ❌ 反应镜头特写（画面太满）

### 2.3 伏笔类型（4 种）

| 类型 | 形式 | 示例 |
|------|------|------|
| **物件伏笔** | 象征性道具藏在画面角落 | 《双瞳》三分构图左侧释迦牟尼佛像 |
| **行为伏笔** | 配角的细微动作 | 一名路人多看了主角一眼 / 服务员的微笑略带异常 |
| **空间伏笔** | 环境结构暗示 | 一扇半开的门 / 一面镜子映出主角看不到的东西 / 楼梯通向暗处 |
| **光影伏笔** | 异常光源/阴影 | 一束本不该出现的光 / 一道伸出画面外的阴影 |

### 2.4 伏笔位置工程学（如何"藏"）

**位置 4 选 1**（任选）：
- 三分构图的**左下** / **右下**（人眼第二注意区，但仍在视野内）
- 黄金分割点（0.382 / 0.618 位置）
- 主体身后的**虚化区**（景深虚化但仍可辨）
- 画面**暗部边缘**（在视觉权重最低的区域）

**视觉权重压制 3 选 1**（任选）：
- 焦点不在伏笔层（f/1.4 - f/2.8 浅景深虚化）
- 光照不在伏笔层（处于暗部/阴影中）
- 色彩不在伏笔层（低饱和度 / 与主体色彩对比弱）

**LLM 输出格式**：在镜头描述末尾用 `[伏笔层：位置=___ ; 物件/行为=___ ; 视觉权重压制=___ ; 回收点=镜头N+M]` 标注。

### 2.5 大师案例

| 影片 | 伏笔层描述 | 回收点 |
|------|----------|--------|
| 《双瞳》| 黄火土进入女屋的镜头，三分左侧释迦牟尼佛像在暗部 | 后续宗教/罪与赎主题 |
| 《重庆森林》| 凤梨罐头堆叠的「过期」标签在浅景深虚化中可见 | 主角的失恋时间隐喻 |
| 《一一》| 水族箱里的鱼出现在多个镜头边缘 | 婷婷的"被注视" |
| 《老男孩》| 墙上的照片在多个长镜头中反复在画面后景出现 | 报复对象的身份 |
| 《沉默的羔羊》| Lecter 牢房后景的画作 | 心理分析师的暗喻 |

## 3. 非常规视角库（Unconventional POV Library · 8 类）

### 3.1 视角清单总览

| # | 视角名 | 心理效果 | 代表作 | 触发条件 |
|---|--------|---------|--------|---------|
| 1 | **物件 POV**（冷气机/电视/相框/监视器/灯）| 无情观察 / 宿命感 / 死亡近在咫尺 | 《双瞳》开头老板死亡 = 冷气机视角 | 死亡场景 / 超自然场景 / 暗示有"无名观察者" |
| 2 | **镜面反射视角** | 真假难辨 / 自我分裂 / 双重身份 | 《黑天鹅》《双瞳》 | 角色面对自我 / 双重人格 / 真假难辨 |
| 3 | **监控 / CCTV 视角** | 失去主体性 / 被监视 / 被害妄想 | 《楚门的世界》《谍影重重》 | 角色不知道自己被看 / 阴谋揭示 |
| 4 | **动物 / 婴儿视角** | 失去判断 / 童真 / 闪回 / 单纯 | 《无人知晓》《白色丝带》| 角色失去理智 / 童年闪回 / 异乎寻常的纯真 |
| 5 | **神 / 上帝俯瞰** | 宿命降临 / 命运感 / 不可逆 | 《教父》开场墓地 | 重大转折 / 命运降临 / 不可挽回 |
| 6 | **极低角度地面 / 死者视角** | 卑微 / 被踩 / 被遗忘 / 死亡 | 《2001 太空漫游》开场骨头 | 角色失败 / 死亡 / 被压垮 |
| 7 | **空椅子 / 缺位 POV** | 缺席 / 死亡 / 等待 | 《东京物语》《镜子》 | 重要人物缺席 / 死亡后场景 |
| 8 | **反射玻璃叠影 POV** | 多重身份 / 内心冲突 / 时空叠加 | 《重庆森林》《阿凡达》 | 角色内心矛盾 / 多重身份 |

### 3.2 每种视角的执行细节

#### 1. 物件 POV
- **机位**：与物件等高（冷气机 = 高于人 2-2.5m / 电视 = 1.3m / 相框 = 1.8m）
- **运动**：摄影机 locked-off（物件不动）+ **画面内部必须 ≥3 项运动**（信条 16）——主体的微动 + 配角进出 + 环境声场变化 + 光影变化
- **构图**：略带广角畸变（28-35mm），增加"非人感"
- **音效**：环境音保留，主体声音可略压（仿佛物件听得到但不在意）
- **🔴 反艺术展铁律**：locked-off ≠ 画面静止
- **示例输出**：`视角=冷气机俯视 + 机位高度2.5m挂墙位置 + 35mm略广角 + 摄影机locked-off + 主体（死者）在画面下方占 1/3 但右手手指有最后的肌肉抽搐 + 远处一名服务员从画面右侧入画看到尸体停顿 + 桌上的水杯水波被空调风吹起涟漪 + 环境空调嗡鸣声中突然加入服务员的呼吸声`

#### 2. 镜面反射视角
- **机位**：透过镜面拍摄——镜外人物在前/镜中映像在后，或两者并置
- **构图**：常用对称构图——人物本体 vs 镜中映像并列
- **景深**：深景深，让本体和映像都清晰
- **示例输出**：`视角=镜面反射 + 镜面占画面右 1/2 + 主体本体在镜面左侧 + 镜中映像与本体表情有 0.3 秒延迟（暗示分裂）+ 35mm + f/8 深景深`

#### 3. 监控 / CCTV 视角
- **机位**：固定高位（2.5-3m）+ 略带广角畸变
- **图像处理**：低饱和度 + 略带颗粒 + 时间戳叠加（可选）
- **运动**：极轻微 zoom 或完全静止
- **示例输出**：`视角=CCTV监控 + 机位高度2.8m + 24mm广角带桶形畸变 + 低饱和25%+颗粒明显 + 右下角时间戳"2024-03-15 23:47:12" + locked-off`

#### 4. 动物 / 婴儿视角
- **机位**：极低（猫 = 30cm / 狗 = 50cm / 婴儿 = 60cm 卧姿/80cm 坐姿）
- **运动**：手持轻摇（模拟非人主体的呼吸/转头）
- **焦距**：广角（24-28mm）模拟眼睛视野
- **示例输出**：`视角=猫视角 + 机位高度30cm + 24mm广角 + 手持轻微晃动模拟动物呼吸 + 焦点在主体腿部以下 + 主体头部在画面外`

#### 5. 神 / 上帝俯瞰
- **机位**：90° 直俯 / 或航拍高度 30m+
- **构图**：极度对称 + 主体在画面绝对几何中心
- **运动**：极慢 zoom in 或完全静止
- **示例输出**：`视角=上帝俯瞰 + 90°直俯 + 航拍高度35m + 主体在画面几何中心 + 24mm广角 + 极慢zoom in 0.5%/秒 + 周围环境对称展开`

#### 6. 极低地面 / 死者视角
- **机位**：5-15cm 高度（贴近地面）
- **构图**：仰拍 + 主体被压缩在画面上方 1/3
- **焦距**：广角（21-28mm）+ 远离主体 0.5-1m
- **示例输出**：`视角=死者地面视角 + 机位高度8cm贴地 + 24mm广角 + 仰拍 + 主体（站立者）在画面上方 1/4 + 焦点在天花板上的吊灯`

#### 7. 空椅子 / 缺位 POV
- **机位**：与"应该在的人"等高
- **构图**：椅子/缺位物在画面**主体位置**（替代人物的位置）
- **运动**：摄影机 locked-off + **画面内部 ≥3 项运动**（信条 16）——蒸汽 / 风 / 光斑 / 远处声场起伏
- **🔴 反艺术展铁律**：locked-off 8 秒 ≠ 画面静止 8 秒
- **示例输出**：`视角=空椅子 + 机位平拍1.5m高度 + 50mm + 空椅子在画面三分中心 + 桌上未喝完的茶蒸汽缓慢上升 + 椅背上的外套被窗风轻吹 + 远处隔壁房间笑声起伏 + 摄影机locked-off 8秒`

#### 8. 反射玻璃叠影 POV
- **机位**：透过玻璃窗/橱窗/玻璃幕墙拍摄
- **构图**：玻璃后的主体 + 玻璃反射的画外内容**重合**
- **运动**：静止或极慢 dolly
- **示例输出**：`视角=玻璃叠影 + 透过咖啡馆橱窗拍摄主体 + 玻璃反射街道车流叠在主体脸上 + 35mm + f/4 + 主体本体清晰 + 反射略虚化`

### 3.3 何时绝对不能用（禁用清单）

- ❌ **动作场面**禁用物件 POV、神视角（情感抽离打断动作肾上腺素）
- ❌ **商业广告**禁用监控视角、死者视角（无法服务产品销售）
- ❌ **爱情温馨场景**禁用监控、动物、死者视角（情绪错位）
- ❌ **Wes Anderson 风格化片**禁用动物视角、监控视角（破坏对称几何 DNA）

### 3.4 大师案例

| 视角 | 影片 | 场景 | 效果 |
|------|------|------|------|
| 冷气机 POV | 《双瞳》开头 | 老板死亡 | 死亡的"无名观察"感 |
| 镜面反射 | 《黑天鹅》 | Nina 在化妆间 | 双重人格 |
| 监控视角 | 《楚门的世界》 | 全片大量监控镜头 | 失主体性 |
| 上帝俯瞰 | 《教父》 | 墓地俯拍 | 家族命运降临 |
| 极低地面 | 《2001》 | 史前人猿骨头 | 文明卑微起点 |
| 空椅子 | 《东京物语》 | 母亲去世后 | 缺席的死亡 |
| 玻璃叠影 | 《重庆森林》 | 林青霞咖啡馆 | 内心分裂 |

## 4. 心理学构图库（Psychological Composition Library · 8 类）

### 4.1 构图清单总览

| # | 构图名 | 心理暗示 | 代表作 | 触发情绪 |
|---|--------|---------|--------|---------|
| 1 | **框架构图（门/窗/镜/栏）** | 被困 / 隔离 / 监视 | 《双瞳》《卡萨布兰卡》 | 角色被命运/关系/自我困住 |
| 2 | **镜面分裂构图** | 人格分裂 / 真假 / 双重身份 | 《黑天鹅》《双瞳》 | 内心冲突 / 真假难辨 |
| 3 | **极端居中构图** | 停滞 / 仪式 / 凝视 / 锁定 | 《双瞳》Wes Anderson《布达佩斯》 | 仪式感 / 命运凝视 / 时间静止 |
| 4 | **极端不平衡（主体偏一角）** | 失衡 / 边缘 / 孤立 | 《阳光普照》《一一》 | 角色被边缘化 / 失去归属 |
| 5 | **长焦压缩构图** | 命运迫近 / 无路可逃 / 被夹击 | 《沉默》《毕业生》 | 危险逼近 / 被命运推动 |
| 6 | **80%+ 大留白** | 寂寥 / 渺小 / 宇宙 / 孤独 | 伯格曼 / 塔可夫斯基 | 极度孤独 / 存在主义 |
| 7 | **仰角低视角** | 压迫 / 权力 / 神圣 / 不可触 | 《公民凯恩》《教父》 | 权力对峙 / 神圣感 / 被压制 |
| 8 | **空椅子 / 缺位构图** | 缺席 / 死亡 / 等待 / 失去 | 《镜子》《东京物语》 | 重要人物的不在场 |

### 4.2 每种构图的执行细节

#### 1. 框架构图（Frame-within-Frame）
- **元素**：门框 / 窗框 / 镜框 / 栏杆 / 树枝间隙 / 楼梯扶手 / 拱门
- **位置**：主体被包裹在框内，框占画面 30-50% 边缘
- **景深**：框层与主体层都清晰（深景深 f/8-f/16），制造"被关在画里"
- **示例输出**：`构图=框架构图 + 前景门框占画面边缘40% + 主体在门框内中央 + 24mm + f/8 + 框/主体均清晰 + 框层用暗部包围 + 主体处于亮部 [心理暗示：被困]`

#### 2. 镜面分裂构图
- **元素**：单面镜 / 双面镜 / 玻璃 / 水面 / 任何反射面
- **位置**：镜面占画面 40-60%，主体本体与镜中映像并列
- **特殊处理**：可让镜中映像与本体表情有微妙延迟/差异（暗示真我vs假我）
- **示例输出**：`构图=镜面分裂 + 镜面占画面右1/2 + 主体本体在镜面左侧中近景 + 镜中映像与本体表情有 0.3 秒延迟 + 35mm + f/5.6 [心理暗示：自我分裂]`

#### 3. 极端居中构图
- **位置**：主体在画面**绝对几何中心**（1/2 横向 + 1/2 纵向）
- **背景**：高度对称（左右镜像）
- **运动**：locked-off 摄影机锁定**但画面内部必须 ≥3 项运动**（信条 16 画面运动铁律）——主体呼吸/眨眼 + 配角微动 + 光影/烟/风 三选三
- **🔴 反艺术展铁律**：locked-off ≠ 画面静止。"完全静止"是艺术展拼贴的失败，不是大师作品
- **示例输出**：`构图=极端居中 + 主体几何中心 + 背景左右完全对称 + 35mm + locked-off摄影机锁定 + 主体呼吸明显起伏 + 背景一缕香烟缓慢上升 + 远处钟摆每秒摆动 + 主体直视镜头 [心理暗示：凝视/锁定/仪式]`

#### 4. 极端不平衡构图
- **位置**：主体在画面**最边缘**（左 1/8 或右 1/8 或下 1/8）
- **留白**：其余 7/8 是空间/天空/墙面
- **运动**：略偏向"主体被推到角落"的运动
- **示例输出**：`构图=极端不平衡 + 主体在画面右下角占 1/8 + 左上 7/8 是大片空白墙面 + 50mm + 主体身体朝向画面外（即将出画）[心理暗示：边缘化/孤立]`

#### 5. 长焦压缩构图
- **焦距**：85-200mm 长焦
- **景深**：极浅（f/2-f/2.8）
- **效果**：前景/中景/远景被压缩到同一平面，主体感到"无路可逃"
- **示例输出**：`构图=长焦压缩 + 135mm长焦 + f/2.8极浅景深 + 主体在中景 + 前景虚化人群与远景建筑都压在主体身上 [心理暗示：命运迫近]`

#### 6. 80%+ 大留白构图
- **比例**：主体占画面 ≤20%，其余 80%+ 是天空/墙面/水面/雪地
- **位置**：主体在画面下方或边缘（不在中心）
- **焦距**：广角 21-28mm
- **示例输出**：`构图=大留白 + 主体在画面竖向下方 8%（极小） + 上方 92% 是大片灰白天空 + 24mm广角 + 主体在三分横线上 [心理暗示：渺小/孤独/宇宙感]`

#### 7. 仰角低视角构图
- **机位**：低于主体 0.5-1m
- **角度**：仰拍 20-45°
- **焦距**：广角 21-28mm（轻微畸变增加压迫感）
- **示例输出**：`构图=仰角低视角 + 机位高度0.5m + 仰拍35° + 24mm广角 + 主体占画面上方 2/3 + 头部超出画框上沿 [心理暗示：压迫/权力/不可触]`

#### 8. 空椅子 / 缺位构图
- **位置**：缺位物（椅子/餐具/床位）在画面**主体应在的位置**
- **辅助**：缺位物周围有"刚刚用过"的痕迹（未喝完的茶/未叠的衣物）
- **运动**：locked-off 摄影机锁定 + **画面内部必须 ≥3 项运动**（信条 16）——茶杯冒出蒸汽 / 窗帘被风吹动 / 远处的环境声起伏 / 一束光斑缓慢移过桌面
- **🔴 反艺术展铁律**：locked-off ≠ 画面静止。"完全静止 8 秒"是艺术展拼贴的失败
- **示例输出**：`构图=空椅子缺位 + 空椅子在画面三分中心 + 桌上未喝完的茶（蒸汽缓慢上升）+ 椅背上挂着外套（被窗外吹来的风轻微吹动）+ 一束夕阳光斑缓慢移过桌面 + 远处隔壁房间传来的人声起伏 + 35mm + locked-off 摄影机锁定 8 秒 [心理暗示：缺席/等待]`

### 5.2 触发条件（何时主动注入）

| 触发条件 | 注入行动 |
|---------|---------|
| **剧本中明确提到该物件** | 必须设计其象征位置（不能让它只是"道具"） |
| **角色经历转变** | 用"水/雨/烟"等流动物象征过渡 |

| **关系破裂** | 用"门/栏杆"象征隔离 |
| **死亡场景** | 用"花/空椅子/水"暗示终结 |

### 5.3 警告：避免符号过载

❌ **不要在同一镜头堆砌 ≥3 个象征物**（变成符号过载，观众反感）
❌ **不要让象征物喧宾夺主**（主体永远是人物/动作，象征物在画面边缘/虚化）
✅ **一场戏内 1-2 个象征物足够**（多了就成了符号游戏）

## 6. Phase 7.5 大师层注入工作流（5 子项）

> 仅当**信条 14 激活**时执行。在 Phase 7（NOT 约束收尾）之后、Phase 8（对抗性逐镜验收）之前。

### 6.1 Phase 7.5.1 长镜头扫描

```
扫描所有镜头 → 单镜时长 ≥8s 的镜头标记为"长镜候选"
  ├─ 检查信息密度元素数（7 类清单）
  │   ├─ ≥铁律最低数 → 通过
  │   └─ <铁律最低数 → 强制注入 1-2 个密度元素 或 拆分为多镜
  └─ 评估长镜质量等级（A/B/C）
      ├─ A/B → 保留
      └─ C → P0 重写
```

### 6.2 Phase 7.5.2 视觉伏笔层注入

```
扫描全段镜头 → 找到所有"剧情转折点"
  └─ 检查转折前 3 镜内是否有伏笔层
      ├─ 有 → 验证伏笔位置工程学（位置 + 视觉权重压制）
      └─ 无 → 强制在前 3 镜内 ≥1 镜中注入伏笔层
          ├─ 选择伏笔类型（物件 / 行为 / 空间 / 光影）
          ├─ 标注伏笔回收点（镜头N+M）
          ├─ 🔴 v3.1.5+ Layer 1 输出 [伏笔层：___]（创作思路区 · meta）
          └─ 🔴 v3.1.5+ Layer 2 输出"物件具体位置+动态"（如"画面右上角窗台上一只蓝色花瓶"——不写"伏笔层"标签 · 信条 25b 强制）
```

### 6.3 Phase 7.5.3 视角升级评估

```
扫描每个镜头当前视角主体 → 评估是否应升级为非常规视角
  ├─ 当前视角 = 代入主角 + 场景 = 死亡/超自然 → 升级为「物件 POV」
  ├─ 当前视角 = 代入主角 + 场景 = 双重身份 → 升级为「镜面反射」
  ├─ 当前视角 = 旁观者 + 场景 = 阴谋/被监视 → 升级为「监控视角」
  ├─ 当前视角 = 代入主角 + 场景 = 失去理智/闪回 → 升级为「动物/婴儿视角」
  ├─ 当前视角 = 旁观者 + Beat = 重大转折 → 升级为「上帝俯瞰」
  ├─ 当前视角 = 代入主角 + 场景 = 失败/死亡 → 升级为「极低地面视角」
  ├─ 重要人物缺席 → 升级为「空椅子 POV」
  └─ 内心冲突 → 升级为「玻璃叠影 POV」

约束：每段最多升级 1-2 镜为非常规视角（过多会失去常规视角的锚定）
```

### 6.4 Phase 7.5.4 心理构图替换

```
扫描每个镜头当前构图 → 评估是否应替换为心理学构图
  ├─ Beat 情绪 = 被困/隔离 → 替换为「框架构图」
  ├─ Beat 情绪 = 自我冲突 → 替换为「镜面分裂」
  ├─ Beat 情绪 = 仪式/凝视 → 替换为「极端居中」
  ├─ Beat 情绪 = 边缘/孤立 → 替换为「极端不平衡」
  ├─ Beat 情绪 = 危险迫近 → 替换为「长焦压缩」
  ├─ Beat 情绪 = 孤独/存在主义 → 替换为「大留白」
  ├─ Beat 情绪 = 权力对峙 → 替换为「仰角低视角」
  └─ Beat 情绪 = 缺席/死亡 → 替换为「空椅子构图」

🔴 v3.1.5+ Layer 1 创作思路区追加 [心理暗示：___]（meta · 不放 Layer 2）
🔴 v3.1.5+ Layer 2 通过具体构图实现（如"框架构图门框压向主体 + 主体占画面下 1/3 头顶留白 2/3"——不写"心理暗示"标签 · 信条 25b 强制）
```

### 6.5 Phase 7.5.5 象征物件检测

```
扫描剧本/分镜 → 列出所有提到的物件
  ├─ 物件在象征对照表中 → 检查是否设计了象征位置
  │   ├─ 有 → 验证位置（暗部/虚化/边缘） + 视觉权重压制
  │   └─ 无 → 强制注入象征位置
  └─ 物件不在对照表中 → 跳过

约束：一场戏内象征物 ≤2 个，避免符号过载
```

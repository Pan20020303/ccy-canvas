## 三、镜头语法 DNA（What makes Wong Kar-wai's "Mood for Love" work）

1. **窄景框 + 前景遮挡 ≥30% 占比**：用门框 / 楼梯栏杆 / 旗袍褶皱 / 镜面边缘做前景虚化遮挡 · **不让观众看清全貌 · 永远在偷窥** · 适用场景：暧昧关系 / 道德困境 / 角色情感被空间困住

2. **升格 48-72 fps 慢动作 ≥4s/次**：把日常动作（走路 / 擦肩 / 喝茶）变成仪式 · 时间被拉长 · 每个细节被放大 · 适用场景：情感节拍的关键时刻

3. **正反打严格对称（同景别同焦距同灯光同运镜速度）**：信条 9 视角主体的最佳实践 · 让观众潜意识理解"两人是镜像"

4. **暖钨丝 3200K + 冷霓虹蓝 #2050B0 对比**：90% 场景用钨丝暖光打底 · 关键节点用冷霓虹蓝做对比 · 形成欲望/克制的色温战争

5. **旗袍系列作为时间码**：苏丽珍每场戏不同旗袍 · 23 套旗袍 = 23 次情感节拍 · 观众通过旗袍读时间和情绪变化

6. **OTS 越肩 + 长焦压缩 85-135mm**：王家卫对白戏标志性语法 · 不是正反打的"谁说话照谁" · 而是 OTS 越肩让观众站在角色后面"和角色一起看"

7. **Yumeji's Theme 主题反复对位**：音乐每次出现都对位特定情感节拍（步行戏 / 楼道相遇 / 雨夜等待）· 形成"听到音乐 = 心跳加速"的条件反射

8. **静默 ≥40% 对白时长**：欲望从不直说 · 重要的对话都在沉默和眼神里 · 信条 11 声音先行铁律的极致实践

## 四、声音/音乐设计 DNA

1. **Yumeji's Theme（梅林茂作曲）**：弦乐主题反复出现 ≥8 次 · 每次都对位"两人擦肩 / 步行 / 雨夜"的特定情感节拍 · 形成观众的潜意识"心跳代码"

2. **Nat King Cole 西班牙语 "Quizás, Quizás, Quizás"**：反复 ≥3 次 · 出现在"想见又不能见"的时刻 · 歌词"也许，也许，也许" = 不确定 = 不能说出的话

3. **静默时长 ≥40%**：王家卫剪辑师张叔平的代表作 · 大量留白让画面自己说话 · 不用配乐填满

4. **环境音真实质感**：街市叫卖 / 雨声 / 高跟鞋节奏 / 旗袍丝绸轻微摩擦声 = 都被精心录制和混音

5. **对白的"画外"处理**：很多对话是"声音先行 + 画面延后"——观众先听到角色的话再看到角色的脸（J-cut / L-cut · 信条 11 sound bridge）

## 一、整体风格指纹（Style Fingerprint · 6 项可量化特征）

### 1. **垂直空间阶级隐喻（Vertical Class Hierarchy）**

- **物理参数**：3 层垂直空间 —— 半地下室（地面以下 -3m · 朴家） / 山上豪宅（地面以上 +5m · 朴社长家）/ 地下密室（地面以下 -8m · 前管家丈夫）/ 楼梯出现 ≥30 次（数过原片）

- **情感意图**：上下高度 = 阶级地位 / 楼梯 = 阶级流动的物理路径 / 地下 = 被遗忘的最底层

### 2. **前景遮挡偷窥构图（Foreground Voyeurism）**

- **物理参数**：80% 镜头有"窗户/扶手/绿植/玻璃门"作为前景框架 + 占画面 30-50% + 主体在框内被"偷看"
- **物理实现**：35-50mm 镜头 + f/2-2.8 + 前景虚化但保留可识别轮廓
- **情感意图**：观众站在"偷窥者"位置 / 阶级窥探的视觉化 / 隐喻角色之间的暗中观察

### 3. **空间秩序的极端对比（Order vs Chaos）**

- **富人家（朴社长家）**：
  - **物理参数**：90° 直角对称 + 极简家具 + 高大窗户 + 大草坪 + 木质纹理（橡木暖橙 #D4A574）+ 光线明亮（暗部 ≤30%）
- **穷人家（半地下室）**：
  - **物理参数**：物件堆叠 ≥20 件可见 / 杂物随机分布 + 黄绿荧光灯 4000K + 窗户低于地面 + 暗部 ≥60%
- **情感意图**：空间组织本身就是阶级——富人控制空间 / 穷人被空间控制

### 4. **三色对比色调（Tri-color Palette）**

- **物理参数**：
  - **黄绿冷光 #6B7B4A**（穷人区域 · 荧光灯 4000K · 饱和度低 30%）
  - **暖橙木质 #C49A6A**（富人区域 · 钨丝 3200K + 自然光 5200K · 饱和度高 70%）
  - **冷蓝暴雨夜 #2C4670**（暴雨场景 · 5800K + 雨水冷感）
- **物理实现**：调色阶段分区调色 + 实景灯光不同（穷人荧光 vs 富人钨丝）
- **情感意图**：颜色 = 阶级位置 / 角色穿越色调 = 阶级穿越

### 5. **节奏骤变三段式（Tonal Tri-Shift）**

- **物理参数**：
  - **前 1/3（约 0:00-0:45）**：黑色喜剧节奏 2-3s/镜 · 角色微表情幽默 · Beat 推进快
  - **中段 1/3（约 0:45-1:30）**：紧张惊悚 3-4s/镜 · 静默拉长 · 反应镜头多
  - **后 1/3（约 1:30-2:12）**：血腥暴力 短切 1-2s/镜 · 突如其来的转折 + 升格慢动作
- **物理实现**：剪辑节奏 + 配乐 + 镜头时长全部配合三段式
- **情感意图**：观众情感被节奏推着走——笑→紧张→震惊 · 反类型片传统三幕结构

### 6. **手持微抖动 + 极慢推 双轨（Handheld + Slow Dolly）**

- **物理参数**：
  - **手持 micro-jitter 0.3-0.5°**（对话戏 + 跟随戏 + 紧张戏）
  - **极慢 dolly 推 0.05-0.1 m/s**（揭示戏 + 阶级符号特写）

- **物理实现**：Steadicam + dolly track + 长焦 50-85mm 压缩

## 三、镜头语法 DNA（What makes Bong Joon-ho's "Parasite" work）

1. **垂直空间阶级隐喻 ≥30 次楼梯母题**：用上下高度差表达阶级位置 · 楼梯是阶级流动的物理路径 · 适用场景：阶级议题 / 社会寓言 / 空间隐喻

2. **前景遮挡偷窥构图 ≥80% 镜头**：用窗户/扶手/绿植/玻璃做前景框 · 让观众站在"偷窥者"位置 · 阶级窥探视觉化

3. **空间秩序的极端对比（直角对称 vs 杂物混乱）**：富人家 90° 直角 + 极简 / 穷人家杂物 ≥20 件 + 随机分布 · 空间组织 = 阶级身份

4. **三色对比色调（黄绿冷光 vs 暖橙木质 vs 冷蓝暴雨）**：颜色 = 阶级位置 · 角色穿越色调 = 阶级穿越（如金家穿越富人家时暖橙包围）

5. **节奏骤变三段式（喜剧→紧张→暴力）**：前 1/3 黑色喜剧 2-3s/镜 · 中段紧张 3-4s · 高潮血腥 1-2s · **反类型片三幕结构**——观众被节奏推着走

6. **手持微抖动 + 极慢推 双轨**：手持 0.3-0.5° = 角色躁动 / 极慢推 0.05-0.1 m/s = 揭示真相 · 双轨切换创造心理节奏

7. **表演分寸的最大反差**：全片克制 30-50%（吃饭/对话/折盒）+ 暴力高潮大开大合 70-95%（屠杀场景）· 与王家卫/Villeneuve 全片克制不同——Bong 用反差制造冲击

8. **物件作为阶级符号**：石头（金哥的"上升机会"）/ 桃子（前管家的过敏触发器）/ 摩斯密码灯（地下密室求救）/ 披萨盒（穷人家维生）—— 每个物件都是阶级语言

## 四、声音/音乐设计 DNA

1. **Jung Jae-il 原创配乐**：钢琴 + 弦乐 + 巴洛克风格 · 用"高雅古典乐"配"低俗血腥场面"= 反差讽刺
2. **环境音真实质感**：暴雨声 / 楼梯回声 / 半地下室漏水声 / 披萨盒折叠声 + 富人家草坪派对喧闹声 = 都被精心录制
3. **静默的转折使用**：暴力高潮前 1-2 秒突然静音 + 然后声音爆炸 = 信条 11 声音先行的极致实践
4. **配乐与画面反差**：屠杀场景配古典乐 = 阶级讽刺
5. **方言/口音的阶级标记**：金家说话有市井气 + 朴社长家说话有上层韩语精致感

## 五、表演分寸 DNA

- **本片主导分寸级别**：**克制 30-50% → 标准 50-70% → 大开大合 70-95%**（三段式递进）
- **演员代表性表演细节**：
  - 宋康昊（金父）：全片克制 + 屠杀瞬间爆发 + 茫然逃离
  - 李善均（朴社长）：精致优雅 + 优越感微表情（皱鼻子闻穷人"气味"）+ 死亡瞬间不可置信
  - 崔宇植（金哥）：年轻人的伪精致 + 阶级假面渐渐崩塌
- **可复用模板**：`Bong 式三段式表演：克制铺垫（30-50%）+ 中段紧张（50-70%）+ 高潮爆发（70-95%）· 与王家卫/Villeneuve 全片克制形成最大对比`
- **反例**：如果全片克制（无暴力高潮爆发）= 破坏 Bong 风格 · 如果全片大开大合（无前段克制铺垫）= 破坏反类型片三段式

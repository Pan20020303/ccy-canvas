# 大师作品案例库 · Masters Library

> **本目录**：`references/masters/` —— Seedance Agent v3.2.0 新增 · 大师作品逐场分镜深度分析案例库
>
> **定位**：信条 22（导演意图）大师参照的**强制引用源**——所有 `[导演意图：大师参照=___]` 标注必须精确到"本目录某部具体作品某场具体戏"，不允许只写"《教父》" 或 "Coppola"。

>
> **持续扩张**：v3.2.0 启动 · 不封顶 · 持续添加作品 · 这是 Max 版本"激进打法 · 一切以效果优先"的核心扩张方向。

## 添加新作品的流程

1. 在 `masters/[导演英文名]/` 下新建 `[作品中文名].md`
2. 严格按"标准作品模板 9 大 section"+ **顶部 §索引摘要（v3.2.3 新增 · ≤300 字超浓缩 DNA）**填写
3. 在本 README.md 目录结构中标记为 ✅ 完成
4. **同步 `masters/INDEX.md`**——按类型 / 风格关键词 / 适用场景三轴更新索引（v3.2.3 索引同步铁律）
5. 在 SKILL.md 矩阵 A 不需要更新（masters/ 作为一个整体已经在矩阵 A）
6. **永远不需要升版本号**——案例库累积是 v3.2.x 的预期行为 · 用户战略明确指示"加大师作品不计入版本号"
7. 在 agent + reviewer 双 CHANGELOG.md 顶部 `## 🎬 大师作品库累积日志 (Append-Only)` 追加 1 行记录（含日期 · 作品名 · 导演 · 类型）
8. 主 SKILL.md 不需要修改

> **核心原则**：作品库扩张 = 内容增长，不是架构变更——架构在 v3.2.0 一次性确定，之后只是持续 add files。

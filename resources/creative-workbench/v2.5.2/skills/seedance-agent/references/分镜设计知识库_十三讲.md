# 分镜设计知识库 · 十三讲

> **来源**：Storyboard Design Framework — The Thirteen Principles, by an unnamed director
> **原始页面**：https://w-gc1x2.neowow.studio/
> **定位**：Seedance 2.0 Agent 的底层分镜知识引擎，按章节/场景/关键词可查

## 序言（PROLOGUE）

分镜不是画面的组合，是情绪的结构。每一个机位、每一寸景别、每一道光，都为剧本当下的情绪服务。

本卷以十三个核心问题为骨架，从拍什么到怎么拍，从单镜头到镜头衔接，从技法到伦理——构建一套可被反复检阅的分镜思维框架。

**章节索引**：主体 → 构图 → 运镜 → 光 → 轴线 → 情绪 → 对话 → 打斗 → 叙事

---

## 第1讲 · 画面主体（The Subject）—— 拍什么？

**核心概念**：主体不是画面里"最大"的东西，而是这一秒观众必须看到的那一个信息。分镜的第一问，是问剧本：这个镜头存在的理由是什么？

### 三种主体类型
| 类型 | 定义 | 示例 |
|------|------|------|
| 人物主体 | 角色的脸、动作、状态——观众跟随的情感载体 | 主角反应镜头 |
| 物件主体 | 关键道具（信、刀、戒指、照片）——剧情的具象钥匙 | 桌上的邀请函 |
| 情境主体 | 环境/空间本身（空城、荒原）——气氛与隐喻 | 空镜素材镜头 |

### 判断主体的三个问题
- **Q1**：这个镜头如果删掉，剧情还能不能往前走？
- **Q2**：观众看完这个镜头之后，必须知道/感受到什么？
- **Q3**：这个信息只能用画面给吗？还是台词已经覆盖？

**铁律**：一个镜头一个主体。两个主体并列时，必须用景别/光/景深明确"现在该看谁"。"啥都想拍" = "啥都没拍"。

### Seedance 应用映射
- 单角色街拍 → 人物主体，角色全身+环境为情境主体
- 道具特写镜头 → 物件主体
- 空镜素材 → 情境主体

## 第2讲 · 主体表现（Subject Presentation）—— 怎么拍出他？

**核心概念**：确定了"拍谁"之后，下一步是"怎么拍出他"。同一个人坐在椅子上，什么样的姿态、表情、动作、节奏，决定观众看到的是英雄还是囚徒。

### 四组表现张力轴

| 维度 | 极A | 极B | 选择信号 |
|------|-----|-----|---------|
| 动作 vs 静止 | "事在发生" | "事已发生"或"事在酝酿" | 沉默的脸 > 哭喊的脸 |
| 表情 vs 行为 | 特写 → 读情绪 | 全景 → 读决定 | "她哭了" vs "她转身离开" |
| 直接 vs 间接 | 直接拍人物本身 | 倒影/阴影/剪影/他人反应 | 间接往往更有力 |
| 完整 vs 局部 | 全身/半身 | 一只手、一只眼、嘴角 | 剥夺信息 → 强迫聚焦 |

### 表现强度递进（从弱到强）
```
环境暗示 → 背影/侧面 → 正面中景 → 面部特写 → 眼睛大特写
```
整场戏不要一开始就用尽。

### Seedance 应用映射
- 身体写作原则与本讲一致：写肢体，不写形容词
- 变装揭示时使用"间接表现"（遮挡后出现新造型）

## 第3讲 · 拍摄方位（Camera Angle）—— 从什么方位拍？

**核心概念**：机位的高低、左右、远近，本质上是观众与主体的**权力关系**。俯拍让人物渺小，仰拍让人物高大——这是镜头语言的政治学。

### 垂直方位（高度）

| 角度 | 效果 | 情绪含义 |
|------|------|---------|
| ↓ 俯拍 | 压缩、渺小、宿命、被审视 | 失败、悲剧、孤立 |
| → 平视 | 平等、客观、对话 | 观众与角色同立场 |
| ↑ 仰拍 | 高大、威严、英雄、压迫 | 权威、胜利、神性 |
| ⊥ 顶拍 | 上帝视角、几何感、抽离 | 死亡、宿命、群像 |

### 水平方位（角度）

| 角度 | 效果 | 适用场景 |
|------|------|---------|
| 正面 | 直接、坦诚、对峙 | 最强情感正向输出 |
| 3/4 | 自然对话角度 | 立体感与亲密感并存 |
| 侧面 | 疏离、观察、行进感 | "路过"或被偷窥 |
| 背面 | 悬念、孤独、未知 | 观众"跟随"但不"读取" |

### 特殊机位
- **荷兰角（Dutch Angle）**：画面倾斜，制造心理失衡。慎用——超过3次就做作
- **主观视角（POV）**：强烈代入感，也强烈"提示"
- **越肩（OTS）**：对话戏标准武器，前景肩膀让观众"贴在B身上看A"

### Seedance 应用映射
- 街拍跟拍 → 平视 + 正面/背面（跟拍方向决定）
- 动作奇观 → 仰拍 low angle hero shot
- 室内对话 → 3/4 角度为主，需要时切 OTS

## 第4讲 · 构图焦段光圈（Composition · Focal · Aperture）

**核心概念**：构图是把观众的视线"逼"到主体上的几何手段。占比决定权重，焦段决定空间感，光圈决定深浅——三者共同雕刻一张画面。

### 构图位置 · 五种主流

| 构图方式 | 效果 | 适用场景 |
|---------|------|---------|
| ⊟ 三分法 | 最稳妥；眼睛放在上1/3线 | 通用叙事 |
| ◉ 居中 | 仪式感、对称、孤立 | Wes Anderson / 史诗 |
| ◐ 框中框 | 门、窗、镜——制造层次 | 窥视、隔阂 |
| ↘ 引导线 | 道路、铁轨、视线推向主体 | 纵深、命运 |
| ◑ 边缘留白 | 主体偏一侧，留出"心理空间" | 孤独、未来感 |

### 焦段对应表

| 焦段 | 视角 | 空间感 | 典型用途 |
|------|------|--------|---------|
| 14-24mm | 超广角 | 夸张纵深，边缘畸变 | 环境戏、压迫感、奇观 |
| 28-35mm | 广角 | 接近肉眼，带环境 | 街头戏、纪实感、双人戏 |
| 50mm | 标准 | 最接近人眼 | 中景对话、客观叙事 |
| 85mm | 中长焦 | 轻度压缩，背景柔化 | 人物特写、肖像、抒情 |
| 135mm+ | 长焦 | 强烈空间压缩 | 偷窥感、追逐、人海孤独 |

### 光圈 · 景深控制

| 光圈 | 效果 | 情感含义 |
|------|------|---------|
| f/1.4-2.8 | 大光圈，背景虚化 | 主体悬浮于环境外，抒情/主观 |
| f/4-5.6 | 中光圈 | 主体清晰且环境可读，客观叙事 |
| f/8-11 | 小光圈，深焦 | 王家卫的反面——奉俊昊式的社会全景 |

### 主体占比

| 占比 | 景别含义 | 适用情绪 |
|------|---------|---------|
| < 10% | 环境主导，人物渺小 | 孤独、无力 |
| 25-40% | 中景标准 | 最舒服，日常叙事 |
| 60%+ | 特写 | 强情绪输出 |
| 90%+ | 大特写 | 情绪极值 |

## 第5讲 · 运镜衔接（Camera Movement）

**核心概念**：镜头不动是表态，镜头一动就必须有理由。每一次推、拉、摇、移，要么跟着情绪走，要么跟着动作走——绝不为"看起来高级"而动。

### 八种运镜类型

| 运镜 | 符号 | 效果 | 情绪含义 |
|------|------|------|---------|
| PUSH IN（推） | ⊕ | 情绪聚焦 | 意识、决定、惊觉——观众从外部进入角色内部 |
| PULL OUT（拉） | ⊖ | 揭示真相 | 观众发现"这只是更大事件的一部分" |
| PAN（摇） | ↔ | 扫视、过渡、寻找 | 最像"观众在转头" |
| TILT（俯仰） | ↕ | 从下到上/从上到下 | 英雄出场 / 审视、压抑 |
| DOLLY（移） | ⇉ | 平行跟随 | 观众"陪着"角色走——最稳重 |
| CRANE（升降） | ↗ | 大场面、史诗感 | 慎用，一用就给 |
| HANDHELD（手持） | ⌇ | 不安、紧张、纪实 | 心跳的节奏 |
| STEADICAM（斯坦尼康） | ◯ | 流畅长镜头 | 观众"飞着"穿过空间 |

### 前后衔接连贯三原则
1. **动接动 / 静接静**：前镜运动结束的瞬间剪入下一个静态镜头；或运动镜头之间用相同方向衔接
2. **动作匹配剪辑**：前镜A伸手推门，下一镜从门后拍同一个推门动作的完成
3. **视线引导剪辑**：前镜角色看向画面右侧，下一镜呈现他看到的东西

**最常见错误**：每个镜头都在动。当所有镜头都运动时，运动本身失去意义。**静止是奢侈品。**

### Seedance 应用映射
- 街拍跟拍 → Steadicam 稳定器跟拍
- 打斗 → Handheld 手持微抖
- 史诗空镜 → Nodal pan / Orbit shot
- 室内对话 → 三脚架锁定或手持呼吸感

## 第6讲 · 构图雷区（Composition Beyond Subject）

**核心概念**：主体是画面的"主语"，前景与远景是"形容词"。没有它们，画面只剩孤立的人；用错它们，主体被淹没。

### 三层景深的功能

| 层次 | 功能 | 战术价值 |
|------|------|---------|
| 前景（Foreground） | 虚化物件、过肩、栏杆、人群轮廓 | 增加层次/暗示被窥视/框定主体 |
| 中景（Midground） | 主体所在的层 | 观众的"焦点战场" |
| 远景（Background） | 环境、空间、时代 | 叙事注脚/对比/暗示未出场力量 |

### 好的构图四标准
1. **视觉等级清晰**：主体最亮、最清晰、占比最大
2. **三层景深都参与叙事**：前景挡半张脸暗示秘密；远景车开过暗示时间
3. **留白服务情绪**：人物面前的空间 > 身后空间 → "未来感"；反之 → "被困"
4. **线条引向主体**：所有线条最终汇于主体的眼睛

### 构图雷区（工程性永不解锁）

| 雷区 | 描述 | 严重程度 |
|------|------|---------|
| 割颈/割腰构图 | 画框边缘正好切在脖子、手腕、脚踝 | ⛔ 高 |
| 头顶长枝 | 远景的灯柱、树枝、栏杆从角色头顶"长出来" | ⛔ 高 |
| 死中央+静止人物 | 除非仪式感或孤立感——居中静止 = 视觉死亡 | ⚠ 中 |
| 背景比主体抢眼 | 霓虹灯、动态人群、强对比图案在主体身后 | ⚠ 中 |
| 视线撞墙 | 人物看向画面外但那一侧没有留白 | ⚠ 中 |

### Seedance 应用映射
- 与 Skill 文件「构图雷区 B 类」高度一致
- 必须写入 Seedance 提示词的【关键约束】或 NOT 段
- 多人对话场景特别需要规避"一字排开""眼睛同高""视线散乱"

## 第7讲 · 光的设计（Light Design）

**核心概念**：光不只是为了"看得见"，光是一部电影的气质本身。

### 三点布光基础

| 光源 | 作用 | 经典位 |
|------|------|--------|
| 主光（Key Light） | 最强光源，决定主体形状与情绪 | 45°侧前 |
| 辅光（Fill Light） | 软化主光产生的阴影 | 辅光强=高调；辅光弱=低调（戏剧性） |
| 轮廓光（Back Light） | 从主体后方勾勒轮廓，把主体从背景"剥离" | 后上方 |

### 光的五大叙事功能
1. **塑造人物**：顺光=天真，硬侧光=老练，底光=邪恶——光雕刻人格
2. **建立气氛**：冷蓝（孤独）、暖橙（怀旧）、惨白荧光（医院/审讯）、绿色（不安/疾病）
3. **引导视线**：观众眼睛永远先看最亮的地方——构图的"光学版"
4. **提示时间/空间**：清晨蓝调、正午顶光、黄昏金光、午夜路灯
5. **隐喻与符号**：十字光=救赎/审判；半边脸在暗=人格分裂；一道光劈过空间=启示

### 调性选择

| 调性 | 特征 | 适用类型 |
|------|------|---------|
| 高调（High-Key） | 辅光强、阴影浅、整体明亮 | 喜剧、广告、童话、日常 |
| 低调（Low-Key） | 辅光弱、大块阴影、强烈反差 | 黑色电影、悬疑、悲剧、犯罪 |

### 动机光原则（Motivated Light）
每一道打在主体身上的光，画面里都应该有它的来源（窗、灯、火、屏幕）。**无源之光 = 廉价感的根源。**

### Seedance 应用映射
- 室内对话 → 电脑屏幕冷蓝白光 + RGB 灯条 + 窗帘缝微光（描述性语言）
- 多图参考 → hex 色号精确锁定模式
- NOT 约束：避免"clean digital surface""plastic look"——要求 practical light + film texture

## 第8讲 · 景别衔接（Shot Transition）

**核心概念**：跳戏的根源是观众"重启"了一次注意力。好的衔接让观众觉得"这是同一件事的下一秒"，差的衔接让观众惊醒"我在看电影"。

### 景别梯度法则 · 七级序列

```
大远景 → 远景 → 全景 → 中景 → 近景 → 特写 → 大特写
```

| 跳级 | 建议 | 说明 |
|------|------|------|
| 跳1-2级 | ✓ 推荐 | 中景→近景，全景→中景。最舒服 |
| 跳3级以上 | △ 慎用 | 远景→特写——除非作为情绪强调点（点穴式剪辑） |
| 同级别 | ✗ 避免 | 中景→中景，机位几乎没变——观众觉得"卡了一下" |

### 不跳戏的六个细则

| 法则 | 描述 |
|------|------|
| ① 30度法则 | 两个连续镜头之间，机位至少改变30度 |
| ② 动作匹配 | 前镜的动作没做完，下镜从另一角度接着完成。剪在动作中 |
| ③ 视线匹配 | A看向画面右侧 → 下镜B出现在画面左侧 |
| ④ 图形匹配 | 前镜的圆形物 → 下镜的圆形物（如太阳→眼睛）。视觉过门感最强 |
| ⑤ 声音搭桥 | 前镜声音延续到下镜（J-cut/L-cut），观众的耳朵已经"在场" |
| ⑥ 节奏呼吸 | 长镜头后接长镜头→观众睡着；短切接短切→观众累。长短交替 |

### Seedance 应用映射
- 硬切分段模板 C ——严格遵循景别跳级法则 + match cut
- 变装遮挡机制可视作一种"图形匹配"或"动作匹配"的物理实现

## 第9讲 · 轴线规则（The 180° Rule）

**核心概念**：轴线（180°线）是观众脑袋里那张地图的"北"。一旦跳轴，观众立刻丢掉方向感。

### 三种轴线类型

| 轴线 | 定义 | 违规后果 |
|------|------|---------|
| 关系轴线 | 两个角色之间的连线 | A在B左边→下一镜突然变右边，关系崩塌 |
| 运动轴线 | 角色行进的方向 | 前镜往左走，下镜往右走——观众以为他返回了 |
| 视线轴线 | 角色目光指向的方向 | A看右→B也看右，观众以为他们没在看对方 |

### 必须守轴的场景
- **对话戏（正反打）**：最严重的跳轴
- **追逐戏**：跳轴 = 观众以为追逃双方撞上了
- **体育/打斗**：跳轴 = 谁打谁完全乱套

### 可以跳轴的时机
- **关系发生重大转折**：合作→背叛、爱→恨——"用错误反映正确"
- **用过线镜头作为缓冲**：先插跨越轴线的运动镜头重画地图
- **主观/精神状态**：失忆、做梦、晕厥——诺兰、林奇用法
- **中性镜头过渡**：正面或背面机位（站在轴线上拍）→重置轴线

**铁律**：跳轴必须是"我故意的"，不能是"我没看出来"。学生作品最常见失误是无意识跳轴。

### Seedance 应用映射
- 对话模板 B ——严格遵守关系轴线
- 硬切分段模板 C ——过线镜头作为段间过渡
- 动作奇观模板 D ——需要时可用 Dutch angle + 运动轴线保持一致

## 第10讲 · 一切为情绪服务（Serving the Emotion）

**核心概念**：构图、焦段、运镜、光——这些都是手段，不是目的。判断一个镜头是否高级的唯一标准：**它有没有让观众这一秒的情绪比上一秒更强。**

### 情绪 → 工具对照表

| 情绪 | 景别/构图 | 焦段/光圈 | 运镜 | 光 |
|------|----------|----------|------|-----|
| 紧张/不安 | 特写、紧凑构图 | 长焦、大光圈 | 手持、推 | 硬侧光、低调 |
| 孤独 | 大远景、人物渺小 | 广角、小光圈 | 静止、缓慢拉 | 单一光源、大块暗 |
| 温暖/亲密 | 中近景、近距离 | 85mm、f/2 | 轻微移动 | 柔光、暖色温 |
| 震撼/启示 | 仰拍、对称居中 | 广角深焦 | 缓慢升降 | 逆光、强反差 |
| 混乱/暴力 | 多机位短切 | 变焦/手持广角 | 快速摇、抖 | 闪烁、霓虹 |
| 回忆/梦境 | 虚化前景、柔焦 | 长焦大光圈 | 慢速推拉 | 逆光、雾、过曝 |

### 导演的"自检三问"
1. **第一问**：这场戏的核心情绪是什么？（用一个形容词概括，不超过两个字）
2. **第二问**：这一刻情绪的强度从 0-10 是几？
3. **第三问**：我设计的镜头能让这个情绪从 X 升到 X+1 吗？

如果第三问答不上来，删掉这个镜头。**"看起来酷"不是答案。**

### Seedance 应用映射
- 此表是 Seedance 提示词中"Style Lock + 运镜 + 光影"选择的底层决策逻辑
- 每种模板类型的情绪基调决定了 Style Lock 变体的选择

## 第11讲 · 长台词戏（Long Dialogue Scenes）

**核心概念**：正反打是对话戏的"豆腐"——必须有，但全靠它会饿死。问题不是正反打本身，是机位不变、景别不变、情绪不变地切了三十次。

### 十二种破闷的方法

| # | 方法 | 核心技巧 | 参考片例 |
|---|------|---------|---------|
| ① | 一镜到底 | 完全不切，让观众和角色一起被困 | 《利器》《同窗会》 |
| ② | 走戏（Walk & Talk） | 人物一边对话一边移动，空间在变 | 《白宫风云》《社交网络》 |
| ③ | 二人镜头（Two Shot） | 两人同框，关系靠近/分开时信息量远超正反打 | — |
| ④ | 反应优于发言 | A说话时切B听完之后的脸。听比说更有戏 | — |
| ⑤ | 景别递进 | 中景→近景→大特写，用景别给情绪打节拍 | — |
| ⑥ | 改变机位高度 | A坐B站→关键台词后A站起，机位重建立 | — |
| ⑦ | 加入第三方/动作 | 倒咖啡、收拾桌子、抽烟——给眼睛"歇脚" | — |
| ⑧ | 间接拍摄 | 倒影、玻璃、监视器、镜子——间隔+新鲜感 | — |
| ⑨ | 焦点切换 | 同一镜头内焦点从A拉到B（rack focus） | — |
| ⑩ | 插入反应物 | 切到B手里转笔/捏杯子/搓戒指的动作特写 | — |
| ⑪ | 闪回插入 | 关键台词触发1-2秒画面闪回——双线并进 | — |
| ⑫ | 沉默 | 3-5秒沉默+静止特写 = 一吨情绪 | — |

### 长对话的节奏曲线（以5分钟为模版）

| 时间段 | 阶段 | 镜头策略 |
|--------|------|---------|
| 0-30s | 建立关系 | 二人镜头 + 中景 |
| 30s-2m | 主体推进 | 标准正反打 + 景别变化 |
| 2-3m | 破闷段 | 走戏 / 第三方动作 / 间接拍摄 |
| 3-4m | 情绪累积 | 景别递进，焦点切换 |
| 4-5m | 高潮+沉默 | 大特写 + 几秒静音 + 一句话定格 |

### Seedance 应用映射
- 室内对话模板 B ——默认使用 6 种以上破闷方法
- 声音设计必须区分"对白"和"非对白音效"
- 多人对话场景必须应用"反应优于发言"原则

## 第12讲 · 打斗分镜（Fight Choreography）

**核心概念**：差的打戏只剩"好快好乱"，好的打戏让观众每一秒都知道谁在打谁、谁占上风、谁可能输。打斗的核心不是"动作设计"，是"地理学 + 权力变化"。

### 五大设计原则

| # | 原则 | 核心内容 |
|---|------|---------|
| 1 | 地理优先（Geography First） | 每场打戏开头必有一个全景"建立镜头"——场地多大、几个人、谁站哪、什么道具 |
| 2 | 节奏波形（Rhythm Wave） | 每30-60秒插入"喘息点"：慢动作/静止/重整/台词 → 再加速。慢-快-慢-快波形 |
| 3 | 权力翻转（Power Shifts） | 三次反转：A占上风→B绝地反击→A找到弱点取胜。每次反转有清晰"转折镜头" |
| 4 | 冲击帧（Impact Frame） | 每一记关键打击→1-2帧定格→慢动作→恢复速度。让观众生理上感觉"打中了" |
| 5 | 情绪锚点（Emotional Anchor） | 每场打戏必须有一个非动作情绪点——"为什么打"，不是"怎么打" |

### 推荐镜头类型
- 广角全景：建立地理
- 中景跟拍：主体动作清晰
- 特写冲击：拳头/眼神/血
- 慢动作：关键打击瞬间
- 主观视角：受击瞬间
- 长镜头：《老男孩》走廊戏式炫技

### 打戏雷区
- 一秒一切的"晃动剪辑"：观众什么都没看清
- 没有节奏波：从头打到尾，观众10秒后疲劳
- 跳轴：谁打谁完全乱套
- 无情绪打戏：动作好看但没人在乎
- 弱者突然能打：没铺垫的"诈骗式翻转"

**参考片单**：《突袭2》·《疾速追杀》·《老男孩》·《疯狂麦克斯：狂暴之路》·《基督山伯爵》决斗段

### Seedance 应用映射
- 动作奇观/爆发模板 D ——严格应用冲击帧 + 节奏波形
- Mad Max 追逐变体 ——low angle hero shot + handheld + terrain intercut
- 声音设计：仅生成动作音效 + sound design，不要抒情背景音乐

## 第13讲 · 长叙事交代（Long Exposition）

**核心概念**：长叙事是导演的最大试炼场——给观众讲一段两分钟的过去/背景/规则，又不让他们走神。这是"展示而非告知"（Show, Don't Tell）的实战。

### 七种长叙事的镜头方案

| # | 方案 | 核心技巧 | 参考片例 |
|---|------|---------|---------|
| ① | 蒙太奇（Montage） | 10年故事压缩成1分钟，靠音乐+剪辑节奏 | 《飞屋环游记》 |
| ② | 旁白+动作 | 画外音叙述+画面里人物做事，信息差/反差 | 《好家伙》《华尔街之狼》 |
| ③ | 闪回穿插（Flashback Insert） | 现在时关键节点→1-2秒过去画面→切回 | — |
| ④ | 走戏交代 | 两个角色边走边说，信息嵌入对话+视觉前进 | 《社交网络》 |
| ⑤ | 视觉化讲述（Visualization） | 人物讲故事时画面变成讲述内容——"看见"而非"听见" | 《公民凯恩》 |
| ⑥ | 道具/文档驱动 | 翻档案、看照片、读信、看视频——信息通过道具传递 | 《云图》《盗梦空间》 |
| ⑦ | 沉浸式还原 | 直接扔进事件——无旁白无解释，观众自己拼全貌 | 《敦刻尔克》《1917》 |

### 长叙事的"反枯燥"四法则
1. **每30秒一个新视觉信息**：新地点、新角色、新动作、新道具
2. **埋钩子，不全说**：每段末尾留未解之谜
3. **情绪锚点定位**：至少一个2-3秒强情绪镜头（眼泪、笑、暴怒）
4. **音乐做骨架**：剪辑节奏严格匹配音乐节奏

**最终铁律**：如果一段长叙事可以用台词讲清楚——你已经输了一半。让观众"看到"，而不是"被告知"。这是电影区别于小说的根本。

### Seedance 应用映射
- 硬切分段模板 C ——可扩展为蒙太奇 + 道具驱动的时长性叙事
- 跨空间叙事需要每段有一个"建立镜头"（地理优先）

## 终章 · 心法六条（Manifesto）

> 所有技法的尽头，是六条心法。把这六句默念三遍，再去拍下一个镜头。

| # | 心法 |
|---|------|
| I | 每个镜头都要回答——"这一秒，观众必须看到的那一个信息是什么？" |
| II | 机位的高低就是权力关系，焦段长短就是心理距离。 |
| III | 运镜动起来必须有理由。静止是奢侈品，不是失败。 |
| IV | 光是这部电影的气质本身。无源之光，是廉价感的根源。 |
| V | 跳轴必须是"我故意的"，不能是"我没看出来"。 |
| VI | 所有技法都是手段。判断镜头高级与否的唯一标准——它有没有让观众这一秒的情绪，比上一秒更强。 |

> *"The shot is not the goal. The feeling is."*
> 镜头不是目的 · 情绪才是

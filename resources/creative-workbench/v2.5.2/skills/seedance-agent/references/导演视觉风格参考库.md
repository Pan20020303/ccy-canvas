# 导演视觉风格参考库

> **来源**：AI视频工作流完整版（0.75 导演视觉风格配置器）
> **用途**：将大师级导演视觉风格转化为纯粹的物理视觉特征描述，用于 Seedance 提示词生成

---

## 使用说明

本文档提供5种导演级视觉风格的纯视觉特征描述。**输出时绝不出现导演姓名、流派名称或解释性文字**，仅以色彩、光影、运镜、构图、质感等具象描述来内化风格。

---

## 五种导演视觉风格

### D-01：仪式色彩

**视觉特征**：
- **色彩**：极致饱和的色彩对比，正红碰撞墨黑，亮金碰撞深褐
- **构图**：大量阵列式构图与几何秩序感，人物站位呈现明显的对称或三角阵型
- **运镜**：关键动作瞬间采用慢放
- **细节**：放大微观物理质感
  - 液体飞溅在空中拉长的轨迹
  - 织物撕裂时纤维断裂的细节
  - 刀锋划过空气带起的细微水雾

**适用场景**：
- 仪式感场景（登基、祭祀、宣誓）
- 权力展示场景
- 史诗级群像场景
- 需要强烈视觉冲击的关键时刻

**嵌入描述示例**：
```
【镜头1：登基仪式】| 0:00-0:05
固定镜头 + 远景 + 正红色龙袍与墨黑色大殿形成极致色彩对比 + 人物站位呈现对称三角阵型 + 亮金色王冠在头顶闪耀 + 慢放0.5倍速 + 衣袍飘动时织物纤维清晰可见 + 空气中尘埃缓慢翻滚 + 不大声 + NOT subtitles + NOT BGM
```

### D-02：湿漉时间

**视觉特征**：
- **氛围**：雨夜或雨后城市氛围
- **地面**：湿漉漉的柏油路面映射着青蓝与品红的霓虹光斑
- **运动**：画面伴随明显的动态拖影与抽帧感，人物快速运动时边缘产生半透明残影
- **前景**：镜头常用浅景深，以布满水珠的玻璃、锈迹斑斑的栅栏、弥漫的烟雾作为虚化前景，营造窥视与隔绝感
- **色彩**：色彩饱和但暗部深沉，高光区域带有柔和的光晕扩散

**适用场景**：
- 雨夜城市场景
- 赛博朋克风格
- 孤独感、疏离感场景
- 霓虹灯下的追逐或对峙

**嵌入描述示例**：
```
【镜头1：雨夜街头】| 0:00-0:04
手持跟拍 + 中景 + 湿漉漉的柏油路面映射着青蓝与品红的霓虹光斑 + 人物快速奔跑边缘产生半透明残影 + 前景布满水珠的玻璃虚化 + 画面带有明显动态拖影 + 色彩饱和暗部深沉 + 高光区域柔和光晕扩散 + 不大声 + NOT subtitles + NOT BGM
```

### D-03：突兀暴力

**视觉特征**：
- **节奏**：长段日常琐碎动作或看似无关的对话后，毫无预兆地以急推镜头切入暴力瞬间
- **机位**：偏好低角度仰拍、后备箱视角
- **血液**：血液飞溅形态夸张，呈喷射状而非流淌
- **剪辑**：镜头剪辑节奏两极分化，静时极静，动时极快

**适用场景**：
- 犯罪片、黑帮片
- 需要强烈反差的暴力场景
- 日常生活突然被打破的瞬间
- 心理惊悚片

**嵌入描述示例**：
```
【镜头1：日常对话】| 0:00-0:08
固定镜头 + 中景 + 两人在餐桌前平静对话 + 缓慢推轨 + 画面极静 + 不大声 + NOT subtitles + NOT BGM

【镜头2：暴力突袭】| 0:08-0:10
急推镜头 + 低角度仰拍 + 毫无预兆切入暴力瞬间 + 血液呈喷射状飞溅 + 画面极快 + 剪辑节奏突变 + NOT subtitles + NOT BGM
```

### D-04：平行精密

**视觉特征**：
- **构图**：画面构图极度水平稳定，地平线始终保持绝对的平行
- **运镜**：推轨运镜平滑如机械运动，无手持晃动
- **色彩**：色彩呈现高对比度的金属质感，冷峻而客观
- **声音**：声音设计强调低频压迫，环境音或威胁声先于画面揭示

**适用场景**：
- 科幻片、惊悚片
- 需要冷峻客观视角的场景
- 机械化、非人性化的环境
- 悬疑片中的压迫感场景

**嵌入描述示例**：
```
【镜头1：走廊推进】| 0:00-0:06
推轨运镜 + 中景 + 地平线绝对水平 + 推轨平滑如机械运动无晃动 + 画面呈现高对比度金属质感 + 色彩冷峻客观 + 环境低频压迫音先于画面 + 不大声 + NOT subtitles + NOT BGM
```

### D-05：枪械芭蕾

**视觉特征**：
- **动作**：清晰展示战术换弹的细节动作、莫桑比克射击法的身体协调性
- **环境**：利用环境物件（墙壁转角、桌角、车门）完成流畅击杀
- **色彩**：画面基调为冷峻的蓝青色，暖色霓虹或枪火闪光作为唯一情绪点缀
- **运镜**：镜头常以中近景长镜头跟拍主角在空间中的连贯运动

**适用场景**：
- 枪战动作片
- 战术射击场景
- 约翰·威克式枪斗术
- 需要展示专业战术动作的场景

**嵌入描述示例**：
```
【镜头1：战术换弹】| 0:00-0:05
中近景长镜头跟拍 + 主角在空间中连贯运动 + 清晰展示战术换弹细节动作 + 利用墙壁转角完成流畅击杀 + 画面基调冷峻蓝青色 + 枪火闪光作为唯一暖色点缀 + 莫桑比克射击法身体协调性 + 不大声 + NOT subtitles + NOT BGM
```

## 使用指南

### 如何选择导演视觉风格

| 风格 | 核心特征 | 适用场景 |
|------|---------|---------|
| D-01 仪式色彩 | 极致饱和色彩对比、对称构图、慢放细节 | 仪式感、权力展示、史诗群像 |
| D-02 湿漉时间 | 雨夜霓虹、动态拖影、虚化前景 | 赛博朋克、孤独感、雨夜追逐 |
| D-03 突兀暴力 | 静动两极、急推切入、夸张血液 | 犯罪片、心理惊悚、反差暴力 |
| D-04 平行精密 | 水平稳定、机械运镜、金属质感 | 科幻惊悚、冷峻客观、压迫感 |
| D-05 枪械芭蕾 | 战术细节、环境利用、蓝青基调 | 枪战动作、战术射击、枪斗术 |

### 嵌入原则

1. **纯视觉描述**：只描述看得见的视觉特征，不提导演名字或流派
2. **自然融合**：将风格特征自然嵌入到 Seedance 的 `+` 串联描述中
3. **保持一致性**：同一场景内的多个镜头应保持相同的视觉风格
4. **量化参数**：慢放倍速、色彩对比度、运镜速度等可量化的参数直接标注

### 组合使用

导演视觉风格可以与其他reference组合使用：
- **D-01 + 动作设计 A3**：仪式感的仙侠爆气对波
- **D-02 + 色彩调性**：赛博朋克的霓虹色彩映射
- **D-03 + 速度与力量**：突兀暴力的量化冲击力
- **D-04 + 光影设计**：平行精密的冷峻布光
- **D-05 + 动作设计 A5/A6**：枪械芭蕾的战术射击

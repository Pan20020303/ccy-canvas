## 一、逆光：英雄感 / 浪漫感 / 神秘感

光源在人物身后，把人物边缘打亮，形成轮廓光，让主体从背景里"立"出来。适合制造史诗感、命运感、浪漫感和人物登场的仪式感。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 英雄感 | 英雄归来、战前动员、领袖站在人群前、人物从远处走向镜头、末日废墟中人物出现 |
| 浪漫感 | 夕阳下拥抱、海边牵手、草地/山顶/樱花林/雨后街道、恋人分别或重逢 |
| 神秘感 | 人物背对镜头、门口出现未知人物、强逆光只露出剪影、危险人物登场 |

**代表电影**：《指环王》系列（英雄登场、史诗群像）、《泰坦尼克号》（夕阳海面浪漫逆光）、《银翼杀手2049》（强逆光剪影孤独感）、《降临》（巨大空间强光神秘感）

---

## 二、顶光：压迫感 / 权力感 / 危险感

从人物正上方打下来的光，让眼窝变暗、脸部出现压迫性阴影。表现权力、危险、审判、阴谋和人物不可预测性。《教父》中Gordon Willis经常使用顶光，让角色眼睛藏在阴影中，形成神秘危险气质。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 权力场景 | 黑帮老大坐在长桌尽头、老板在会议室审视下属、反派俯视别人、审讯室/谈判桌/地下赌场 |
| 压迫场景 | 人物被审问、人物站在单盏吊灯下、地下室/仓库/监狱/实验室、角色陷入道德困境 |
| 危险人物 | 黑帮/反派/幕后操控者、表面平静但令人不安的人物、阴影遮住眼睛只见嘴角和轮廓 |

**代表电影**：《教父》（眼睛藏在阴影中的权力感）、《沉默的羔羊》（审讯对峙心理压迫）、《七宗罪》（阴暗室内犯罪压迫感）、《蝙蝠侠：黑暗骑士》（审讯室反派对峙）

---

## 三、丁达尔光：史诗感 / 神圣感 / 空间立体感

也称体积光、光束、god rays。需要空气中的雾气、灰尘、水汽或烟尘，让光线变成可见的"光柱"。让空间变得宏大、神圣、神秘。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 史诗空间 | 地下神殿、古老遗迹废墟、巨型洞穴、远古祭坛 |
| 神圣空间 | 教堂/修道院/神殿大厅、森林深处阳光穿透树叶、人物第一次看到"奇迹" |
| 探索场景 | 考古队进入遗迹、探险者打开石门、末日幸存者走进废弃建筑、森林里突然出现光束 |

**代表电影**：《银翼杀手2049》（巨大空间雾气光束）、《降临》（神秘空间体积光）、《指环王》系列（神殿山谷森林史诗光影）、《普罗米修斯》（外星遗迹洞穴神秘光束）

---

## 四、底光：诡异感 / 恐怖感 / 疯狂感

从人物下方往上照，打破"光从上往下"的日常习惯，脸部阴影反常，产生恐怖、失控、怪异的感觉。黑色电影和恐怖片经常用底光制造威胁感和心理异常感。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 恐怖场景 | 黑暗房间、老宅、地铁车厢、地下室、停电后的走廊 |
| 人物黑化 | 原本正常的人突然露出诡异微笑、主角从善良变危险、反派第一次暴露真实面目、人物情绪失控崩溃 |
| 悬疑惊悚 | 手电筒从下方照脸、烛光从桌面往上照、手机屏幕光照亮人物、火光/地面灯/仪器灯照亮脸部 |

**代表电影**：《驱魔人》（恐怖异常宗教惊悚）、《小丑》（人物心理失控黑化）、《闪灵》（人物精神崩坏空间压迫）、《沉默的羔羊》（心理恐怖人物危险感）

---

## 五、侧光：冲突感 / 悬疑感 / 内心拉扯

从人物一侧打过来，让脸部出现"一半亮、一半暗"的效果。表现人物的矛盾、秘密、选择、危险和身份不确定。黑色电影中常用侧光暗示角色的双面性和道德暧昧。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 悬疑冲突 | 间谍站在火车连接处、杀手躲在门后、侦探审视嫌疑人、人物在暗巷里等待 |
| 内心选择 | 女人站在窗边看一封信、男人坐在车里做决定、主角面对背叛、人物在说谎前沉默 |
| 关系拉扯 | 夫妻争吵后沉默、朋友对峙、情侣分手前一刻、角色在说真话和继续隐瞒之间挣扎 |

**代表电影**：《第三人》（黑色电影阴影街道悬疑人物）、《银翼杀手》（人物脸部明暗分割未来noir气质）、《花样年华》（室内侧光暧昧关系情绪克制）、《教父》（人物隐藏动机光影中的权力）

---

## 六、硬光：力量感 / 攻击性 / 高压对峙

产生边缘清晰、对比强烈的阴影，画面更锋利、更有攻击性。适合表现战斗、暴力、压迫、热血、危险人物。典型特征：阴影边界清楚、明暗过渡突然。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 力量场景 | 拳击手上擂台、格斗训练、士兵进入战场、运动员爆发前一刻 |
| 对峙场景 | 两个人在仓库里对峙、黑帮谈判破裂、警察和嫌犯面对面、反派从阴影中走出来 |
| 危险人物 | 杀手清理武器、战士擦拭伤口、拳击手缠绷带、人物准备大干一场 |

**代表电影**：《公民凯恩》（强对比硬光戏剧化阴影）、《愤怒的公牛》（拳击汗水强烈黑白对比）、《蝙蝠侠：黑暗骑士》（犯罪片高压对峙）、《疾速追杀》系列（动作场景强对比硬边缘光影）

---

## 七、柔光：温柔感 / 治愈感 / 回忆感

扩散后的光，阴影边缘柔、明暗过渡自然，不会让脸部线条太硬。适合表达温暖、陪伴、爱、回忆、亲情和脆弱情绪。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 治愈场景 | 医院病房安慰、家人陪伴、雨后房间、清晨阳光照进卧室 |
| 温柔关系 | 告白、久别重逢、母亲给孩子讲故事、朋友安慰崩溃的人 |
| 回忆场景 | 童年回忆、老照片、夕阳房间、家庭饭桌 |

**代表电影**：《泰坦尼克号》（人物肖像浪漫情绪柔和光线）、《情书》（回忆感青春感清冷柔和情绪）、《海街日记》（家庭日常治愈氛围）、《爱乐之城》（浪漫关系柔和光线梦幻色彩）

---

## 八、蝴蝶光：精致感 / 贵气感 / 主角感

主光放在人物正前方偏上位置，让鼻子下方出现蝴蝶形小阴影。也叫Paramount lighting，与旧好莱坞明星肖像有强关联，适合塑造精致、贵气、被聚光灯选中的人物感。

**适用场景**：

| 类型 | 具体场景 |
|------|---------|
| 高级主角感 | 高端酒会、红毯、时尚晚宴、奢华酒店大厅、杂志封面肖像 |
| 女性精致感 | 礼服肖像、珠宝广告、香水广告、高级摄影棚、明星定妆照 |
| 人物被选中 | 主角走进大厅人群中只有她被聚光灯打亮、宴会中背景模糊只有主角清晰 |

**代表电影**：《日落大道》（旧好莱坞明星感戏剧化肖像光）、《蒂凡尼的早餐》（优雅女性主角精致时尚氛围）、《了不起的盖茨比》（宴会奢华主角被聚光灯选中）、《红磨坊》（舞台感聚光感华丽人物肖像）

## 九、三点布光：标准电影布光系统（v2.7 补充）

> **来源**：AI视频工作流完整版（第3类：光影与色彩词库）
> **用途**：为需要精确控制光影的场景提供标准布光参考

三点布光是电影摄影的基础布光系统，由主光、辅光、背光三个光源组成。

### 三点布光组成

| 光源 | 位置 | 作用 | 强度范围 |
|------|------|------|---------|
| **主光 (Key Light)** | 主要光源，通常在角色前方45°侧上方 | 塑造形体、建立明暗、决定画面基调 | 45-85% |
| **辅光 (Fill Light)** | 主光对侧，填充阴影 | 降低对比度、提亮暗部、柔化反差 | 30-60% |
| **背光 (Back/Rim Light)** | 从背后或侧后方照射 | 勾勒边缘、分离主体与背景、增加立体感 | 55-75% |

### 伦勃朗光（特殊主光位置）

**定义**：主光从45°侧上方照射，在面部阴影侧形成三角形光斑

**特征**：
- 面部一侧被照亮，另一侧大部分在阴影中
- 阴影侧的脸颊上有一个倒三角形光斑
- 强度范围：25-50%

**适用场景**：
- 经典人像、戏剧感场景
- 需要表现人物内心复杂性的场景
- 文艺片、传记片、心理戏

**嵌入描述示例**：
```
面部伦勃朗光 + 右侧脸颊形成三角形光斑强度35% + 左侧脸隐藏在柔和暗影里
```

### 自然光模拟

**天光 (Skylight)**：
- 柔和、无方向性的漫射光
- 适合日常场景、纪录片风格
- 色温：5000-6500K（偏冷）

**日光 (Sunlight)**：
- 强烈、有方向性的直射光
- 适合户外场景、黄昏逆光
- 色温：5500-6000K（暖橘金黄）

### 体积光（丁达尔光束）

**定义**：可见的光束，通过空气中的尘埃、雾气、烟雾形成

**强制描述要素**：
- 光源类型：阳光/月光/聚光
- 光束角度：锐角/钝角/散射
- 尘埃/雾气密度：稀薄/中等/浓厚
- 微粒运动状态：随机翻滚/缓慢飘移/急速旋转
- 微粒色彩：是否被特效染色

**嵌入描述示例**：
```
窗外阳光透过尘埃形成丁达尔光束 + 光束角度45°斜射 + 尘埃密度中等缓慢飘移 + 微粒在光束中随机翻滚
```

## 使用指南

### 如何选择光型

1. **先定情绪**：本镜头的核心情感是什么？
2. **查速查表**：从「总表速查」找到对应的光型
3. **确认场景**：该光型的适用场景是否匹配？
4. **嵌入描述**：将光型自然嵌入到 Seedance 的 `+` 串联描述中

### 嵌入格式示例

```
【镜头1：英雄登场】| 0:00-0:04
固定镜头 + 中景 + 英雄从远处走向镜头 + 夕阳从背后猛烈打过来形成强逆光 + 整个人笼罩在耀眼金边光晕里 + 发丝根根分明发光强度85% + 面部补光柔和 + 双眼折射出明亮亮斑 + 不大声 + NOT subtitles + NOT BGM
```

**光影要素已嵌入**：
- 光型：逆光（英雄感）
- 强度：85%
- 效果：金边光晕、发丝发光、眼部亮斑

## 第四部分：使用流程（LLM 必读）

### 标准流程

```
任何 Phase 启动
    │
    ▼
1. 读取本 INDEX.md（≤2 秒 · 找到本 Phase 的必读 references）
    │
    ▼
2. 按矩阵 B Phase × references 强触发表选择
    │
    ▼
3. 🔴 **必须 Read 选中文件的具体 § 章节**（不允许只读索引摘要）
    │
    ▼
4. 引用具体段落内容到 Layer 1
    │
    ▼
5. Layer 1 标注：
   [references 调用：path/to/file.md §具体章节锚点 ...]
```

### 🚫 禁止行为

- ❌ 只读 INDEX.md 摘要就直接生成 Layer 2 → reviewer 实读校验失败 = P1
- ❌ 引用未在 INDEX 中的文件（除非新增 references 已存在但 INDEX 未更新 · 此时应同步更新 INDEX）
- ❌ 用索引标签替代实际段落引用（如 Layer 1 写"使用反平庸案例库情境 1"但不读具体内容）

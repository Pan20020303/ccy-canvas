# 动作设计与武指体系参考库

> **来源**：AI视频工作流完整版（轴三：动作设计）
> **用途**：为武侠/仙侠/国漫/科幻/枪战/格斗场景提供动作逻辑、物理参数和武指体系参考

---

## 七种动作设计逻辑

### A1：武侠·写意飞天（程小东体系）

**动作逻辑**：
- 角色具有轻功能力，可长时间滞空、水上漂、借力飞行
- 动作姿态舒展优美，如同舞蹈
- 攻击强调剑气外放和轨迹美感，攻防逻辑相对弱化

**武指参考体系**：程小东体系（主导）
- 飞天遁地、舞蹈化、凌空蹈虚、各打各的、写意唯美

**招式库引用范围**：
- 剑法：撩、云、带、旋
- 掌法：排云、落英
- 轻功身法
- 优先选用带大范围移动和旋转的招式

**物理强度与速度阈值**：
- 程氏反重力系数：50%-80%（滞空时间 1-3 秒）
- 速度：10-50 m/s（超高速飞行）
- 击飞距离：5-30 米
- 冲击力：5-10 G（强烈）

---

### A2：武侠·硬桥硬马（袁和平体系）

**动作逻辑**：
- 强调地面战斗，拳拳到肉，关节技和短兵相接
- 每一招都有清晰的发力点和受力反馈，攻防逻辑严密
- 动作设计包含佯攻、格挡、拆招、反击

**武指参考体系**：袁和平体系（主导）
- 海纳百川、刚柔并济、强交互、虚实结合、行云流水

**招式库引用范围**：
- 拳法：崩、劈、钻、炮、横
- 刀法：劈、砍、斩、撩、格
- 短兵：匕首、分水刺
- 优先选用近距离、强对抗招式

**物理强度与速度阈值**：
- 袁氏力度评分：7-10
- 速度：3-10 m/s（极快冲刺）
- 击飞距离：1-5 米
- 冲击力：5-15 G（强烈至极端）
- 地面破坏：裂纹、坑洞

---

### A3：仙侠·爆气对波（袁和平+程小东混合）

**动作逻辑**：
- 角色可突破音障、瞬移、释放巨大能量波
- 战斗节奏在超高速移动与蓄力对波之间切换
- 强调毁灭性的冲击力和大规模环境破坏

**武指参考体系**：袁和平+程小东混合
- 强交互用于近身拆招，飞天遁地用于远距离移动
- 增加"爆气"、"领域展开"、"法宝对轰"等仙侠专属概念

**招式库引用范围**：
- 全部剑法、掌法、枪法、棍法中的远程气劲版本
- 专属大招：万剑诀、排山倒海、雷霆万钧

**物理强度与速度阈值**：
- 速度：≥343 m/s（超音速瞬移）
- 击飞距离：≥50 米，贯穿多栋建筑
- 冲击力：≥50 G（毁灭性）
- 环境破坏：地形改变、山体崩塌

---

### A4：国漫·夸张打击

**动作逻辑**：
- 参考《雾山五行》《一人之下》的打斗节奏
- 打击感通过极致的时停帧、屏幕震动、面部形变、超远击飞和蓄力特写来体现
- 动作可包含拉伸变形以增强冲击力

**武指参考体系**：国漫常用节奏体系
- 强调视觉冲击而非物理真实
- 大量使用慢动作卡点、抽帧、动态模糊拉伸、水墨或速度线特效

**招式库引用范围**：
- 棍法、拳法、腿法
- 原创的、带有强烈视觉风格的大招
- 招式命名需带有国漫中二感

**物理强度与速度阈值**：
- 时停帧：0.2-0.5 秒
- 击飞距离：50-200 米
- 速度：瞬移或亚音速
- 面部形变：允许轻微夸张
- 屏幕震动：幅度与打击点同步

---

### A5：科幻·战术射击（约翰·威克枪斗术）

**动作逻辑**：
- 基于掩体的枪战、战术换弹、CQB 近身格斗（枪械+匕首）
- 动作强调实用性和致命性，没有多余的花哨动作
- 走位逻辑符合真实战术规范

**武指参考体系**：
- 约翰·威克（John Wick）枪斗术
- 迈克尔·曼战术写实风

**招式库引用范围**：
- 枪械射击、匕首格斗、徒手锁喉、关节压制
- 禁用仙侠武侠招式库

**物理强度与速度阈值**：
- 子弹速度：参照真实枪械（手枪 300-500 m/s，步枪 700-900 m/s）
- 冲击力：子弹停止作用
- 战术动作时间：换弹 1-1.5 秒，切枪 0.5 秒

---

### A6：现代枪战·战术 CQB

**动作逻辑**：
- 基于掩体的移动、切角、战术换弹、双人协同掩护
- 车辆作为掩体时的子弹穿透逻辑
- 动作强调专业性和致命效率

**武指参考体系**：
- 军事/执法记录影像
- 好莱坞枪战（如《疾速追杀》系列）

**招式库引用范围**：
- 枪械射击（手枪/冲锋枪/步枪）
- 匕首格斗、徒手锁喉
- 利用环境（桌角/墙壁）进行打击

**物理强度与速度阈值**：
- 子弹速度：参照真实枪械（手枪 300-500 m/s，步枪 700-900 m/s）
- 战术动作时间：换弹 1-1.5 秒，切枪 0.5 秒
- 掩体穿透：木门可穿透，混凝土墙不可

---

### A7：港式格斗·凌厉短打（洪家班/袁家班现代分支）

**动作逻辑**：
- 近距离、高频率的拳脚膝肘组合，动作短促爆发，攻防转换极快
- 强调"见招拆招"和利用环境物品（折凳、酒瓶、栏杆）进行攻击
- 动作设计带有明显的洪金宝/甄子丹式实战风格

**武指参考体系**：
- 香港动作片黄金时代体系（洪家班/袁家班现代分支）

**招式库引用范围**：
- 拳法：冲拳、勾拳、肘击
- 腿法：低扫、膝撞、侧踹
- 摔技：过肩摔、抱腿摔
- 环境武器使用

**物理强度与速度阈值**：
- 速度：3-8 m/s（极快冲刺）
- 击打频率：3-5 次/秒
- 冲击力：5-12 G（强烈至极端）
- 击飞距离较短（1-3 米），强调"受力后的僵直"而非击飞

## 全局动作动态性强制规则（5条铁律）

> **适用范围**：全部 A1-A7 动作设计风格
> **作用**：消除站桩式回合制，强制全员动态响应

### 1. 禁止站桩式回合制

**绝对禁止**："A 出招 → B 原地格挡/受击 → B 出招 → A 原地格挡/受击"的回合制节奏

**强制要求**：
- 双方（或所有参与角色）在**同一时间切片内**必须均有主动的肢体位移或攻防意图
- 若镜头聚焦于角色 A 的蓄力或释放，角色 B **不得**静止等待

**角色 B 必须同时进行以下动作之一**：
- 横向/纵向位移：侧移绕后、后撤拉开距离、前压缩短身位
- 预判性闪避或格挡准备：重心下沉、兵刃变线、护体罡气凝聚
- 同步抢攻：利用 A 的蓄力间隙发动突袭

### 2. 技能释放期间的全员运动法则

**触发条件**：当任一角色释放长时程技能（如聚气、念咒、拔刀蓄力、枪械换弹）时

**敌对角色响应**（绝不可原地观望）：
- 冲刺打断
- 寻找掩体
- 以远程攻击压制
- 同样开始蓄力准备对波

**友方角色响应**（绝不可沦为背景）：
- 主动掩护（挡拆、布阵）
- 协同攻击（绕侧、夹击）
- 战术走位（拉开空间避免误伤）

### 3. 拉扯与身位博弈的持续性

**强制要求**：
- 打斗中必须存在**至少 3 次**明显的距离关系主动变化
- 例如：近身缠斗 → 一方后跃拉开 → 另一方追击 → 再次贴身的循环

**战术意图驱动**：
- 长兵优势距离
- 短兵切入死角
- 喘息调整
- 诱敌深入

### 4. 招式与特效的动作一体化联动

**核心原则**：特效不再是独立附加层，特效的生成、飞行、碰撞必须与角色的身体动态**强因果绑定**

**示例**：
- 挥剑产生剑气：角色挥剑的**腰胯拧转幅度**决定剑气的**飞行曲率与宽度**
- 角色**前冲的惯性**叠加在释放的暗器上，赋予暗器额外的初速度矢量
- 受击特效（如飙血、盔甲碎裂）必须立即触发受击者的**生理连锁反应姿态**（如踉跄后退、单膝卸力、侧滚消能），而非硬直后恢复站姿

### 5. 特写镜头下的并行叙事

**场景**：当镜头给到某一角色面部特写或手部细节特写时

**要求**：
- 若背景中存在其他战斗人员，**必须通过声音设计或画面边缘的虚化动态**暗示其持续运动

**交叉快切强制**：
- 若必须使用单人特写表现关键反应（如瞳孔收缩），该特写时长不得超过 **0.5-0.8 秒**
- 必须在下一个镜头中立即切换至对手的同步动态（如对手正高速逼近的身影），以打破时空停滞感

## 使用指南

### 如何选择动作设计类型

| 场景类型 | 推荐动作设计 | 关键特征 |
|---------|-------------|---------|
| 武侠飞天场景 | A1 写意飞天 | 轻功、滞空、舞蹈化 |
| 武侠地面打斗 | A2 硬桥硬马 | 拳拳到肉、强交互 |
| 仙侠大战 | A3 爆气对波 | 超音速、能量波、环境破坏 |
| 国漫风格 | A4 夸张打击 | 时停帧、屏幕震动、夸张击飞 |
| 科幻枪战 | A5 战术射击 | 枪斗术、战术换弹、CQB |
| 现代枪战 | A6 战术 CQB | 掩体、切角、协同掩护 |
| 港式格斗 | A7 凌厉短打 | 高频拳脚、环境武器、实战风格 |

### 嵌入到 Seedance 格式的示例

```
【镜头1：爆气对波】| 0:00-0:04
两人同时爆气 + 超音速瞬移速度>343 m/s + 空气产生音爆云和锥形冲击波 + 银白色剑气从双方手中迸发带有破空嘶鸣 + 碰撞瞬间产生巨大能量波冲击力>50 G + 地面龟裂直径5米深度0.5米 + 周围树木被冲击波击倒 + 尘埃暴起形成蘑菇云 + 两人同时后退卸力单膝跪地 + NOT subtitles + NOT BGM
```

**关键要素已嵌入**：
- 速度量化：>343 m/s（超音速）
- 冲击力量化：>50 G（毁灭性）
- 环境破坏：地面龟裂直径5米
- 生理反应：后退卸力单膝跪地（符合规则4）

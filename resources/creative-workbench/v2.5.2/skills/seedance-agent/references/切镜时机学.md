> **用途**：seedance-agent v3.1.2 大师层第六大引擎——**切镜时机学（Cut Timing）**。回答的问题不是「在哪里切」（这是 `镜头衔接与连续性参考库.md` 的范畴），而是「**在什么时机切**」——即同一个动作节点上，提前 0.3 秒切 / 同步切 / 延后 0.5 秒切 / 反向切，会带来完全不同的心理感受。
> **设计哲学**：大师导演的核心秘密之一——**切镜时机决定观众情感与画面的"时差"**。王家卫的"3 秒延后切"、Hitchcock 浴室杀人的精确帧数、Kubrick《闪灵》永远晚 0.5 秒——这些不是技术差，是导演的"心跳级时机选择"。
> **与 4-30s segment 约束的关系**：切镜时机是 **shot 内部切换时刻的偏移**——不影响 segment 时长边界（仍受 4-30s 约束）。本规则作用于 **每个 segment 内部 ≥2 个 shot 之间的衔接点**。

## 0. 核心理念（先读 30 秒）

**平庸做法**：在动作完成 50% 时切（同步切）——这是工业级"信息切镜"，逻辑正确但无心理张力。

**大师做法**：根据这场戏需要的情绪类型，选择「同步 / 延后 / 提前 / 反向」四种时机之一——让画面与观众心理同步、错位、抢拍或刻意拉远。

**4 类时机的本质**：
- **同步切**：画面切 = 观众心理切（默认/平庸）
- **延后切**：画面切晚于观众心理切（情绪积累）
- **提前切**：画面切早于观众心理切（信息抢拍）
- **反向切**：画面切在观众心理不预期切的时候（震惊 / 错位）

---

## 1. 四类切镜时机详解

### 1.1 同步切（Sync Cut）—— 默认 · 工业级

**定义**：在动作或情绪节点的 **40-60% 完成度** 切镜——观众心理预期切镜，画面也在此时切。

**心理效果**：流畅、清晰、不打断——观众无感（这正是优点也是局限）。

**适用场景**：
- 信息传递（讲事实 / 介绍 / 旁白）
- 流畅动作（追逐 / 走位 / 切换景别）
- 商业广告（高效信息密度）
- 短剧 / 下沉市场内容（绝大多数镜头）

**实现细节**：
- 动作切：切在动作 40-60% 完成度
- 视线切：切在主体视线转移 60% 完成度
- 对白切：切在台词最后一个字结束 + 0.2-0.4 秒

**示例**：
```
镜 N（A 推门走出）→ 同步切 → 镜 N+1（A 出现在门外）
```

---

### 1.2 延后切（Delayed Cut）—— 大师常用 · 情绪积累

**定义**：在动作或情绪节点 **完成后再停留 0.5-3 秒** 才切镜——画面比观众心理预期晚切。

**心理效果**：情绪积累 / 让观众与画面共同呼吸 / 强化"未说尽"的感觉。

**适用场景**：
- 离别 / 死亡 / 重大决定后的情绪余波
- 凝视长镜 / 文艺片 / 抒情段落
- 关键潜台词被说出之后
- 角色内心挣扎的临界点

**实现细节**：
- 动作完成后镜头仍停留 0.5-3 秒（具体看情绪强度）
- 不是"加空镜"——而是同一镜头继续运行，让主体的"后续微动"展现
- **延后秒数 = 情绪强度的量化**：0.5s 轻微 / 1s 中等 / 2-3s 强烈

**经典案例**：
| 影片 | 镜头 | 延后秒数 | 心理效果 |
|------|------|---------|---------|
| 《教父》| Vito 死后 Michael 看着 | 约 4 秒 | 父亲死亡的重量 |
| 《一代宗师》| 宫二说出"我心里有过你" | 约 2.5 秒（说完后镜头不切）| 14 年情感的余波 |
| 《断背山》| Ennis 摸 Jack 衬衫 | 约 3 秒 | 整段感情的浓缩 |
| 《海边的曼彻斯特》| Lee 听到弟弟死讯 | 约 5 秒 | 麻木与不接受 |
| 《花样年华》| 梁朝伟在吴哥窟说出秘密 | 约 6 秒 | 一生的秘密被"墙"吃掉 |

**输出格式**：
```
[切镜时机：类型=延后切 ; 偏移=+2.5s ; 心理目的=让情绪在主体的微动中余波]
```

---

### 1.3 提前切（Anticipatory Cut）—— 大师常用 · 信息抢拍

**定义**：在动作或情绪节点 **未完成时（10-30% 完成度）就切镜**——画面比观众心理预期早切。

**心理效果**：紧凑 / 抢拍 / 让观众脑补"被切走的部分"/ 增强节奏紧迫感。

**适用场景**：
- 高紧张段落（追逐 / 倒计时 / 撤离）
- 蒙太奇序列（信息密集传递）
- 反预期反转（让观众没看完就被切走）
- 武戏的招式连接

**实现细节**：
- 动作刚开始（10-30%）就切——让观众脑补结果
- 与"延后切"完全相反：不让镜头完整发酵
- 节奏感来自"信息密度 > 显示时间"

**经典案例**：
| 影片 | 场景 | 提前切方式 |
|------|------|----------|
| 《疯狂麦克斯：狂暴之路》| 追逐 | 每个动作镜头都在 20% 完成度切走 |
| 《盗梦空间》| 多层梦境同步崩塌 | 各层级动作在未完成时切到下一层 |
| 《敦刻尔克》| 战机俯冲 | 俯冲到 30% 切到地面士兵反应 |
| 《老男孩》| 武戏 | 出拳到 20% 切到对方反应 |

**输出格式**：
```
[切镜时机：类型=提前切 ; 偏移=-0.4s ; 心理目的=让观众脑补撞击瞬间，增强紧迫感]
```

---

### 1.4 反向切（Counter Cut）—— 大师秘密 · 震惊错位

**定义**：在观众**完全不预期切镜**的时候切——通常是某个"看似不重要"的瞬间。

**心理效果**：震惊 / 错位 / 强迫观众重新判断画面权重 / 暗示"刚才那个细节比你以为的重要"。

**适用场景**：
- 揭示秘密的瞬间（让观众发现自己漏看了关键信息）
- 反派/真凶身份的暗示
- 大反转之前的"种子镜头"
- 心理悬疑（《双瞳》《沉默羔羊》《利刃出鞘》）

**实现细节**：
- 切镜点不在动作节奏带上——而是在"非节奏点"
- 切到的下一镜往往是"非主体"的反应（道具、配角、空镜）
- 这种切法**违反一般连贯性**，必须有强叙事动机

**经典案例**：
| 影片 | 场景 | 反向切实施 |
|------|------|----------|
| 《双瞳》| 老板尸体场景 | 从尸体反向切到冷气机视角——观众发现"有什么在看着" |
| 《沉默羔羊》| Lecter 面试 Clarice | 对话中突然反向切到 Lecter 监狱外的飞蛾——暗示真凶身份 |
| 《利刃出鞘》| Marta 回忆药物事件 | 在 Marta 讲述时突然反向切到她口袋里的小药瓶 |
| 《老男孩》| 吴大秀第一次见女儿 | 对话中反向切到吴大秀的手——指间还有报复对象的血 |
| 《盗梦空间》| Cobb 看 Mal | 平静对话中反向切到陀螺——暗示这是梦 |

**输出格式**：
```
[切镜时机：类型=反向切 ; 偏移=非节奏点 ; 心理目的=让观众发现错过的关键信息]
```

## 2. 切镜时机决策表（按情绪类型 × 类型片）

### 2.1 情绪类型 → 推荐时机

| 情绪类型 | 推荐时机 | 实施细节 |
|---------|---------|---------|
| **信息密集** | 同步切 / 提前切 | 默认 40-60%，紧张时 10-30% |
| **情绪余波** | 延后切（+0.5-3s）| 完成后停留，让主体微动展开 |
| **离别 / 死亡** | 延后切（+2-5s）| 主体不动，只让光影/呼吸/环境继续 |
| **决定 / 顿悟** | 延后切（+0.5-1.5s）| 让决定的"重量"沉淀 |
| **追逐 / 紧迫** | 提前切（-0.3-0.8s）| 每个动作 20-30% 完成度切 |
| **倒计时 / 危机** | 提前切 + 渐进缩短 | 第 1 镜 -0.3s，第 2 镜 -0.5s，第 3 镜 -0.8s |
| **揭示秘密** | 反向切 | 在观众没预期的瞬间切到关键道具/细节 |
| **大反转预兆** | 反向切（种子镜头）| 提前 30-60 秒铺反向切的"种子" |
| **梦境/超现实** | 反向切 / 节奏跳跃 | 故意打破连贯性切镜 |
| **凝视长镜** | 不切 + 内部运动 | 单 segment 4-30s 内不切，靠画面内部运动 |

### 2.2 类型片 → 推荐时机分布

| 类型 | 同步切 | 延后切 | 提前切 | 反向切 |
|------|-------|-------|-------|-------|
| 现代动作 | 30% | 5% | 60% | 5% |
| 科幻悬疑 | 30% | 15% | 35% | 20% |
| 剧情文艺 | 25% | 45% | 15% | 15% |
| 爱情日常 | 30% | 50% | 10% | 10% |
| 恐怖 | 15% | 30% | 25% | 30% |
| 广告 | 60% | 5% | 30% | 5% |
| Wes Anderson | 70% | 10% | 15% | 5%（locked-off 风格化弱反向）|
| 纪录片 | 40% | 30% | 20% | 10% |
| 武侠古装 | 20% | 30% | 40% | 10% |
| 喜剧黑色幽默 | 30% | 20% | 30% | 20% |
| 战争史诗 | 25% | 25% | 35% | 15% |
| 文艺慢电影 | 15% | 70% | 5% | 10% |

> **使用说明**：以上是各类型片中**推荐的切镜时机分布**——不是死规则。具体场景由情绪驱动决定。

## 3. 与 4-30s segment 约束的协同（关键工程规则）

**核心**：切镜时机是 **segment 内部 shot 之间的衔接点设计**——不影响 segment 4-30s 边界。

### 3.1 单 segment 内部多 shot 时机分配

| 单 segment 时长 | 内部 shot 数 | 时机预算 |
|----------------|------------|---------|
| 4-6 秒 | 1-2 shot | 1 个切镜点（默认同步切 / 视情绪可改为提前/反向）|
| 7-10 秒 | 2-3 shot | 2-3 个切镜点（混用 2 类时机）|
| 11-15 秒 | 3-4 shot | 3-4 个切镜点（混用 ≥2 类时机，避免全同步）|
| 16-30 秒 | 4-6 shot | 4-6 个切镜点（混用 ≥3 类时机 · 长 segment 必须避免节奏单一）|

### 3.2 跨 segment 切镜时机的处理

| segment 边界类型 | 时机处理 |
|----------------|---------|
| **段间硬切**（不同场景）| 默认同步切，特殊场景可反向切（梦境/记忆/超现实跳跃）|
| **段间 J-cut / L-cut**（声音搭桥）| 与信条 11 声场曲线协同——声音提前 / 延后 0.5-2 秒 |
| **段间 Match cut**（视觉匹配）| 提前切——前一 segment 末镜未完成切到下一 segment |

### 3.3 伪长镜（≥2 segment 拼接）的时机一致性

- 伪长镜各 segment 内部用同一类时机倾向（如《1917》全程提前切 / 《老男孩》武戏全程提前切）
- 不允许伪长镜内部混用同步+延后+提前（破坏长镜统一感）

## 4. 大师案例深度解析

### 4.1 王家卫的「3 秒延后切」（《花样年华》《一代宗师》）

王家卫的标志性切镜——**让镜头停留比观众心理预期长 2-3 秒**：
- 《花样年华》梁朝伟讲秘密到吴哥窟石孔——讲完后镜头停留 6 秒不切
- 《一代宗师》宫二说"我心里有过你"——说完后镜头停留 2.5 秒不切
- 《重庆森林》梁朝伟买凤梨罐头——付完钱后镜头停留 3 秒不切

**心理效果**：观众与角色一起"消化"那一刻——情感不是被叙述，而是被"住进去"。

### 4.2 Hitchcock 浴室杀人的提前切（《精神病患者》）

- 78 个镜头 / 45 秒——平均 0.58 秒/镜
- 每个镜头都在动作 10-20% 完成度切走
- 观众从未看到完整的刀进入身体的画面——但通过快速提前切的累积感觉"被刺了 78 刀"

**心理效果**：提前切的累积 > 完整展示——观众的脑补永远比画面更恐怖。

### 4.3 Kubrick《闪灵》的反向切

- Danny 骑三轮车穿过走廊——突然反向切到 237 房间的门
- Jack 在打字机前——突然反向切到镜子里 Jack 的反射
- 大量"应该切走但没切"+"不该切但切了"的反向时机

**心理效果**：观众永远无法预测下一秒画面——心理始终处于"被监视"的不安。

### 4.4 朴赞郁《老男孩》走廊打斗的提前切伪长镜

- 单一长镜头表象（其实是多 segment 拼接）
- 每个出拳/格挡都在 20-30% 完成度切到下一动作
- 3 分钟内 ≥40 次提前切——给观众"一直被打没有喘息"的感觉

**心理效果**：观众在第 90 秒崩溃——这是切镜时机+长镜头心理临界点的双重作用。

## 5. 输出格式

### 5.1 默认情况（推荐启用 · 大师层激活时强制）

每个 shot 切镜点之后追加（可选标注）：

```
[切镜时机：类型=___ ; 偏移=___ ; 心理目的=___]
```

四个字段：
- **类型**：同步切 / 延后切 / 提前切 / 反向切
- **偏移**：+Ns（延后）/ -Ns（提前）/ 非节奏点（反向）/ 0s（同步）
- **心理目的**：为什么选这个时机

### 5.2 简化标注（短剧 / 商业广告 / 快消内容）

短剧 / 商业广告 / 快消内容默认全同步切——可跳过 [切镜时机] 标注，标注 `[切镜时机：默认同步切]` 即可。

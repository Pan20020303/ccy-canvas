# 机位情绪决策参考库

> **来源**：基于分镜设计知识库_十三讲.md 第3讲，扩展为情绪驱动的机位决策引擎
> **用途**：根据场景情绪自动选择最佳机位角度，避免"一直平视"的平淡问题

---

## 核心原则

**机位的高低、左右、远近，本质上是观众与主体的权力关系。**

- 俯拍让人物渺小
- 仰拍让人物高大
- 平视让观众与角色平等

**⚠️ 警告**：一直使用平视机位 = 没有戏剧张力 = 平淡无聊

---

## 情绪 → 机位决策表（强制查询）

### 使用规则

**每个镜头生成前，必须先查询本表**：
1. 确定本镜头的核心情绪
2. 查表找到对应的机位角度
3. 如果情绪不在表中，默认使用平视，但**连续3个镜头不能都是平视**

## 一、垂直机位决策（高度）

### 情绪 → 垂直机位映射表

| 情绪/场景 | 机位角度 | 效果 | 嵌入描述示例 |
|---------|---------|------|-------------|
| **渺小、孤独、失败** | 俯拍 | 压缩、渺小、被审视 | `俯拍 + 镜头从上方45度角俯视主体 + 主体在画面中显得渺小孤立` |
| **悲剧、宿命、绝望** | 俯拍 | 宿命感、无力感 | `俯拍 + 镜头从上方60度角俯视 + 主体被环境包围显得无助` |
| **被监视、被审判** | 顶拍 | 上帝视角、抽离 | `顶拍 + 镜头从正上方90度垂直俯视 + 主体在画面中心呈几何图案` |
| **权威、压迫、威胁** | 仰拍 | 高大、威严、压迫 | `仰拍 + 镜头从下方30度角仰视主体 + 主体显得高大威严具有压迫感` |
| **英雄、胜利、神性** | 仰拍 | 英雄感、崇高感 | `仰拍 + 镜头从下方45度角仰视 + 主体占据画面上方显得高大英勇` |
| **对话、平等、客观** | 平视 | 平等、客观 | `平视 + 镜头与主体眼睛同高 + 观众与角色处于平等位置` |
| **日常、自然、纪实** | 平视 | 自然、真实 | `平视 + 镜头与主体平行 + 营造自然真实的观察感` |

### 特殊垂直机位

| 机位 | 适用场景 | 效果 | 嵌入描述示例 |
|------|---------|------|-------------|
| **极低角度仰拍** | 反派登场、怪物视角 | 极度压迫、恐怖 | `极低角度仰拍 + 镜头几乎贴地从下方仰视 + 主体显得巨大恐怖` |
| **极高角度俯拍** | 死亡、终结、群像 | 上帝视角、宿命 | `极高角度俯拍 + 镜头从高空俯视 + 主体如蝼蚁般渺小` |
| **荷兰角（倾斜）** | 心理失衡、混乱 | 不安、失衡 | `荷兰角 + 画面倾斜15度 + 营造心理失衡感` |

## 四、机位切换规则（避免平淡）

### 强制规则

1. **连续3个镜头不能都是平视**
   - 如果前2个镜头都是平视，第3个镜头**必须**切换到俯拍或仰拍
   
2. **情绪转折点必须切换机位**
   - 从平静到紧张 → 从平视切到俯拍/仰拍
   - 从压抑到爆发 → 从俯拍切到仰拍
   - 从对峙到和解 → 从仰拍切到平视

3. **对话戏的机位节奏**
   - 开场：平视 3/4侧面（建立关系）
   - 冲突：切换到越肩（OTS）或正面对峙
   - 高潮：切换到俯拍（弱势方）+ 仰拍（强势方）
   - 和解：回到平视 3/4侧面

4. **动作戏的机位节奏**
   - 蓄力：俯拍（压抑）
   - 爆发：仰拍（英雄感）
   - 击中：俯拍（对手被压制）
   - 胜利：仰拍（英雄站立）

## 五、情绪强度 → 机位角度映射

### 角度强度递进

| 情绪强度 | 俯拍角度 | 仰拍角度 | 效果 |
|---------|---------|---------|------|
| **弱** | 15-30° | 15-30° | 轻微的情绪暗示 |
| **中** | 30-45° | 30-45° | 明显的情绪表达 |
| **强** | 45-60° | 45-60° | 强烈的情绪冲击 |
| **极强** | 60-90° | 贴地仰拍 | 极端的情绪表达 |

**使用原则**：
- 情绪越强，角度越极端
- 但不要一开始就用尽，要有递进

## 六、场景类型 → 机位决策

### 常见场景的机位选择

| 场景类型 | 推荐机位组合 | 避免机位 | 原因 |
|---------|-------------|---------|------|
| **英雄登场** | 仰拍 + 正面/背面 | 俯拍 | 俯拍会削弱英雄感 |
| **反派登场** | 仰拍 + 正面 + 低角度 | 俯拍 | 俯拍会削弱威胁感 |
| **失败场景** | 俯拍 + 背面/正面 | 仰拍 | 仰拍会给予力量感 |
| **孤独场景** | 俯拍 + 背面 + 远景 | 仰拍 | 仰拍会给予力量感 |
| **对话场景** | 平视 3/4 + 越肩 | 持续俯拍/仰拍 | 会破坏对话平等感 |
| **追逐场景** | 平视侧面 + 手持 | 俯拍 | 俯拍会削弱速度感 |
| **打斗场景** | 仰拍（英雄）+ 俯拍（对手）交替 | 持续平视 | 平视没有力量对比 |
| **死亡场景** | 俯拍 + 顶拍 | 仰拍 | 仰拍会给予尊严感 |
| **胜利场景** | 仰拍 + 正面/背面 | 俯拍 | 俯拍会削弱胜利感 |

## 八、实战案例

### 案例1：核弹爆炸场景

**情绪分析**：
- 镜头1前半：日常、平静 → **平视**
- 镜头1后半：震惊、渺小 → **俯拍**（从窗外看人）
- 镜头2：毁灭、终结 → **仰拍**（蘑菇云）

**优化前**（全平视）：
```
【镜头1】平视 + 男人打电话 + 摇镜到窗外核弹
【镜头2】平视 + 蘑菇云全貌
```
❌ 问题：全程平视，没有情绪递进

**优化后**（机位变化）：
```
【镜头1】平视 + 男人打电话 + 摇镜到窗外核弹 + 然后切换到俯拍从窗外看男人（渺小感）
【镜头2】仰拍 + 蘑菇云全貌从下方仰视（压迫感、毁灭感）
```
✅ 改进：平视 → 俯拍 → 仰拍，情绪递进清晰

---

### 案例2：英雄对决场景

**情绪分析**：
- 镜头1：英雄登场 → **仰拍**
- 镜头2：反派威胁 → **仰拍**
- 镜头3：对峙 → **平视正面**（双方平等）
- 镜头4：英雄蓄力 → **俯拍**（压抑）
- 镜头5：英雄爆发 → **仰拍**（力量）
- 镜头6：反派倒下 → **俯拍**（失败）

**机位节奏**：仰拍 → 仰拍 → 平视 → 俯拍 → 仰拍 → 俯拍
✅ 有节奏、有对比、有情绪递进

## 九、常见错误与修正

### 错误1：一直平视

**症状**：所有镜头都是平视，画面平淡无聊

**修正**：
- 检查前2个镜头，如果都是平视，第3个镜头强制切换
- 在情绪转折点切换机位

### 错误2：机位与情绪不匹配

**症状**：
- 英雄登场用俯拍（削弱英雄感）
- 失败场景用仰拍（给予力量感）

**修正**：
- 严格查询【情绪 → 机位映射表】
- 不要凭感觉选机位

### 错误3：机位切换过于频繁

**症状**：每个镜头都切换机位，观众眼花缭乱

**修正**：
- 同一场景内，保持2-3个镜头的机位稳定
- 只在情绪转折点切换机位

### 错误4：极端机位滥用

**症状**：
- 荷兰角用了5次以上（做作）
- 顶拍用在日常对话（过度）

**修正**：
- 荷兰角：全片不超过3次
- 顶拍：只用在死亡、宿命、群像场景

## 使用指南

### 强制流程

1. **生成镜头前**：确定核心情绪
2. **查询本表**：找到对应机位
3. **检查连续性**：前2个镜头是否都是平视？
4. **生成描述**：将机位嵌入到提示词中

### 嵌入格式

```
【镜头1：标题】| 0:00-0:04
{机位角度} + {运镜类型} + {景别} + {画面描述} + ...
```

**示例**：
```
【镜头1：英雄登场】| 0:00-0:04
仰拍 + 镜头从下方30度角仰视主体 + 固定镜头 + 远景 + 英雄从远处走来 + 主体显得高大威严 + ...
```

## 核心原则总结

1. **情绪驱动机位**：每个机位都为情绪服务
2. **避免连续平视**：连续3个镜头不能都是平视
3. **情绪转折切换**：情绪转折点必须切换机位
4. **强度递进**：情绪越强，角度越极端
5. **查表决策**：不凭感觉，严格查表

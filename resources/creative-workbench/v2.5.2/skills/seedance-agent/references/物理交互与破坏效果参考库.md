# 物理交互与破坏效果参考库

> **用途**：当镜头涉及物理破坏、液体飞溅、物体碎裂、结构崩塌、碰撞冲击时，Agent 必须在动作描述中嵌入精确的物理约束。模糊的物理描述 = AI 模型产生明显的视觉 bug。
>
> **与其他 reference 的关系**：本文档专注物理材质行为。冲击力数值参考 `速度与力量量化标准.md`，动作编排参考 `动作设计与武指体系参考库.md`，拍摄技法参考 `超详细运镜规格参考库.md`。

---

## 一、核心原则

**AI 视频模型对物理交互的五大默认失真倾向**：

| 失真倾向 | AI 默认行为 | 对抗原则 | 
|---------|-----------|---------|
| **对称化** | 裂纹、碎片、溅射趋向于均匀对称 | 明确写出不对称性、随机分布 |
| **慢放化** | 一切破坏趋向于慢动作 | 标注真实速度、帧级别时间线 |
| **完整化** | 碎片数量偏少、偏大、过于完整 | 指定碎片数量级、大小分布范围 |
| **漂浮化** | 碎片和尘埃趋向于漂浮 | 强制标注重力加速度9.8m/s² |
| **净化化** | 无粉尘/无碎屑/无次级破坏 | 强制要求二次碎片、粉末、飞溅微粒 |

## 二、材质破坏行为标准（10类完整展开）

### 1. 钢化玻璃/窗户玻璃

**物理特征**：钢化玻璃碎裂成钝角小颗粒（直径3-8mm），普通玻璃碎裂成尖锐片状。在应力超过约40MPa时瞬间崩溃。裂纹传播速度约1500m/s。

| 参数 | 错误（AI默认） | 正确（物理真实） | 嵌入关键词 |
|------|-------------|---------------|-----------|
| 裂纹形态 | 均匀蜘蛛网 | 从应力点放射状蔓延，裂纹密度随距离递减 | `放射状裂纹+中心密边缘疏+不规则分叉` |
| 碎片大小 | 大小相近 | 冲击点附近小而碎(1-3cm²)，远处大而完整(5-10cm²) | `碎片从中心到外围1-10cm²递增` |
| 碎片下落 | 漂浮缓慢 | 受重力快速坠落。大块先行（终端速度~5m/s），小块随后 | `碎片以9.8m/s²加速坠落+大块先行+小块飘落` |
| 碎片边缘 | 光滑锐利 | 微锯齿不规则，尖锐棱角，碎屑粘连在边缘 | `碎片边缘微锯齿+碎屑粘连+尖锐棱角反光` |
| 钢化玻璃特定 | 普通碎片 | 爆裂成数千颗3-8mm钝角颗粒，如瀑布倾泻 | `钢化玻璃爆裂成3-8mm钝角颗粒+瀑布倾泻状` |
| 残留 | — | 碎裂后仍有部分碎片粘连在窗框上，几帧后逐块脱落 | `窗框残留碎片+几帧后逐块脱落` |
| 声音 | — | 尖锐高频碎裂（峰值~4kHz）+碎片瀑布般落地沙沙声 | `高频碎裂attack+碎片瀑布落地沙沙声` |

**嵌入描述模板**：
```
钢化玻璃从被撞击点呈放射状裂纹向外蔓延+裂纹密度从中心向边缘递减+爆裂成数千颗3-8mm钝角颗粒呈瀑布状倾泻+碎片大小从中心(1-3cm²)向外围(5-10cm²)递增+碎片受重力以9.8m/s²加速坠落+窗框残留部分粘连碎片几帧后逐块脱落+碎片边缘微锯齿不规则+尖锐棱角反光+高频碎裂声峰值4kHz+碎片落地沙沙声
```

### 2. 陶瓷/瓷器/杯子

**物理特征**：陶瓷抗压不抗拉，受冲击时从触地点开始崩裂，裂纹沿应力线扩散。断裂韧性低（约3-5 MPa·m½），碎片边缘呈贝壳状断口。

| 参数 | 错误 | 正确 | 嵌入关键词 |
|------|------|------|-----------|
| 碎裂时序 | 直接整体爆碎 | ①触地点崩裂（0-0.05s）→②裂纹扩展分叉（0.05-0.15s）→③主碎片分离（0.15-0.3s）→④微碎片和粉末飞溅（0.3-0.5s） | `先崩裂→再扩展→再分离→最后粉末` |
| 碎片数量级 | 3-5块 | 主碎片5-8块(>2cm)+次级碎片15-20块(0.5-2cm)+微碎片30-50块(<0.5cm)+白色粉末 | `5-8主碎片+15-20次级碎片+30-50微碎片+粉末` |
| 断面形态 | 平整断面 | 贝壳状断口，内壁白亮外壁釉面，边缘锐利但微锯齿 | `贝壳状断口+内壁白亮+外壁釉面+微锯齿边缘` |
| 手把分离 | 与杯体同时碎裂 | 手把在连接处断裂，作为独立大碎片先脱落 | `手把连接处断裂+独立脱落+保留完整形状` |
| 碎片飞散方向 | 360°均匀 | 主要沿受力方向扇形飞散（约120°锥角），反方向碎片少 | `沿受力方向120°扇形飞散+反方向碎片少` |
| 碎片弹跳 | 不弹跳 | 较大碎片落地后弹跳1-3次（每次弹跳高度递减至前次的30-40%） | `大碎片落地弹跳2-3次+每次弹跳高度递减` |
| 粉末行为 | 无粉末 | 触地点产生白色细粉末云团，缓慢沉降持续0.5-1s | `触地点白色粉末云团+缓慢沉降0.5-1s` |

**嵌入描述模板**：
```
陶瓷杯从画面顶部以约1.5m/s自由落体下落+杯底最先触地+0-0.05s触地点崩裂产生白色粉末云团+0.05-0.15s裂纹从触地点向上分叉扩散+0.15-0.3s主碎片5-8块扇形120°飞散+手把在连接处断裂独立脱落+0.3-0.5s次级碎片15-20块和微碎片30-50块扩散+白色粉末缓慢沉降+大碎片落地弹跳2-3次每次弹跳高度递减+碎片断面呈贝壳状内壁白亮外壁釉面+边缘微锯齿+尖锐棱角反光
```

### 3. 混凝土/石材/地面

**物理特征**：混凝土抗压强度20-50MPa，抗拉强度仅2-5MPa（十分之一）。受压时局部粉碎，受拉时产生裂纹。裂纹沿最弱路径扩展，遇钢筋停止。

| 参数 | 错误 | 正确 |
|------|------|------|
| 裂纹形态 | 均匀对称蜘蛛网 | 不规则树枝状分叉，主裂纹(3-5条)宽1-3cm深3-10cm。次级裂纹从主裂纹分叉，宽度递减。裂纹路径受骨料（碎石）影响产生偏折 |
| 碎块形状 | — | 大撞击（>10G）产生 Voronoï 碎裂图案，碎块不规则多边形，边缘翘起角度10-30°。小块在中心，大块在外围 |
| 钢筋暴露 | — | 冲击力>20G时混凝土剥落暴露底层钢筋。钢筋弯曲变形，表面有混凝土残渣粘连 |
| 粉尘喷射 | 无或均匀 | 沿裂纹方向定向喷射。粗颗粒（直径1-5mm碎石）最先飞出，细粉尘（<0.1mm）形成持续数秒的灰色云雾 |
| 冲击坑 | 圆形规则坑 | 坑口不规则椭圆形（长轴沿受力方向）。坑壁粗糙，坑底有放射状微裂纹。坑深约为冲击体直径的2-4倍 |
| 分层剥落 | — | 混凝土表面薄层（1-3cm）先剥落，露出下层粗糙骨料面。剥落碎片呈不规则薄片状 |
| 声音 | — | 低频闷响（主频100-300Hz，岩石碎裂）+高频碎石弹跳+粉尘沙沙声 |

**嵌入描述模板**：
```
地面以冲击点为中心产生不规则树枝状裂纹+主裂纹3-5条宽1-3cm深3-10cm向外辐射+裂纹路径受骨料碎石影响产生偏折不对称+次级裂纹从主裂纹分叉宽度递减至<0.5cm+冲击中心产生不规则椭圆形坑深约冲击体3倍+坑壁粗糙坑底有放射状微裂纹+混凝土表面1-3cm薄层先剥落露出粗糙骨料面+碎块不规则多边形边缘翘起10-30°+沿裂纹方向定向喷射粗碎石(1-5mm)+细粉尘灰色云雾持续2-3s+没有完美对称的蜘蛛网+低频闷响100-300Hz+高频碎石弹跳声
```

### 4. 木材/木质结构

**物理特征**：木材是各向异性材料，顺纹方向易劈裂，横纹方向抗剪。断裂时沿纹理撕裂，产生长条木刺和片状碎屑。不同树种密度差异大（松木~0.5g/cm³，橡木~0.75g/cm³）。

| 参数 | 错误 | 正确 |
|------|------|------|
| 断面 | 光滑平整 | 粗糙撕裂状。顺纹理方向呈长条纤维拉丝，横纹理方向呈阶梯状断裂。纤维末端呈刷状散开 |
| 木刺 | 无 | 产生锋利长条木刺（长2-10cm，粗1-3mm），沿纹理方向排列。木刺尖端尖锐，根部仍连在木材主体上 |
| 碎片形态 | 块状碎屑 | 长条片状碎屑（沿纹理）+细小木粉+剥落的树皮/漆面薄片 |
| 颜色变化 | — | 断裂面颜色比表面浅（内部木材未氧化）。旧木材表面灰褐，内部浅黄白 |
| 声音 | — | 沉闷撕裂声（主频200-500Hz）+纤维断裂清脆"啪"+碎片弹跳低频 |
| 变形过程 | 瞬间断裂 | 先弯曲变形（弹性阶段）→出现裂纹（屈服点）→沿纹理撕裂（断裂）→纤维拉丝（残余） |

**嵌入描述模板**：
```
木板先弯曲变形0.1s+出现裂纹+沿纹理方向撕裂+断面粗糙呈阶梯状+产生锋利长条木刺2-10cm沿纹理排列+木刺尖端尖锐根部仍连主体+长条片状碎屑飞散+细小木粉飘落+表面灰褐色漆面薄片剥落+断裂面露出浅黄白内部木色+沉闷撕裂声200-500Hz+纤维断裂清脆啪声+碎片弹跳
```

### 5. 金属/合金

**物理特征**：金属具有延展性。软钢屈服强度~250MPa，延伸率可达20%以上。断裂前有明显塑性变形。高碳钢/铸铁延展性低，直接脆断。铝轻（密度2.7g/cm³）而软，钛轻而强。

**5.1 延性金属（软钢、铝、铜）**

| 参数 | 错误 | 正确 |
|------|------|------|
| 变形 | 均匀弯曲 | 局部凹陷+边缘隆起+应力白化线（Lüders bands）。凹陷处金属变薄，边缘因挤压增厚 |
| 断裂 | 整齐断面 | 颈缩→微孔聚集→韧窝断口（杯锥状）。断口呈暗灰色纤维状，无光泽 |
| 表面变化 | — | 变形区表面氧化层剥落、漆面龟裂呈网状细纹。裸金属表面因滑移带出现粗糙纹理 |
| 火花 | 均匀分布 | 沿摩擦/切割方向喷射。火花大小不规则（大粒5-10mm+细粒<1mm链路）。初始白亮（~1500°C）→0.3s冷却至暗红→0.5s消失 |

**5.2 脆性金属（铸铁、高碳钢）**

| 参数 | 错误 | 正确 |
|------|------|------|
| 断裂 | 弯曲后断 | 几乎无变形直接脆断。断面呈亮灰色结晶状，有放射纹 |
| 碎片 | 大块 | 碎片大小悬殊（大块>5cm+中等1-5cm+细小<1cm粉末）。碎片边缘锋利 |
| 声音 | — | 清脆金属断裂声（高频3-6kHz）+碎片弹跳余响 |

**嵌入描述模板（延性金属碰撞）**：
```
钢板受冲击局部凹陷深度2-5cm+凹陷边缘隆起+凹陷处金属变薄+应力白化线Lüders bands可见+表面漆面龟裂呈网状细纹+凹陷区裸金属表面因滑移带产生粗糙纹理+变形后未断裂（延性变形）+冲击点氧化层剥落飘散+伴随低频金属碰撞声100-300Hz+金属余响振动
```

### 6. 塑料/合成材料

**物理特征**：热塑性塑料（ABS、聚碳酸酯）延性高，应力发白后撕裂。热固性塑料（环氧、酚醛）脆性，直接碎裂。

| 参数 | 错误 | 正确 |
|------|------|------|
| ABS/聚碳酸酯破裂 | 直接碎裂 | 先应力发白（受力区变白半透明）→裂纹出现→沿应力方向撕裂。撕裂边缘粗糙有拉伸痕迹 |
| 碎片 | — | 撕裂状不规则碎片边��呈锯齿拉伸状。碎片具有柔韧性可弯曲 |
| 颜色变化 | — | 应力发白区呈半透明白色，与周围本色形成对比。裂纹尖端前方有白化"先导区" |

---

### 7. 布料/织物撕裂

**物理特征**：织物撕裂沿纱线方向。撕裂强度取决于纱线密度。撕裂前沿先出现单根纱线断裂，随后相邻纱线依次断裂。

| 参数 | 错误 | 正确 |
|------|------|------|
| 撕裂方向 | 任意方向 | 沿经线或纬线方向直线撕裂。偏离纱线方向需要更高力量且撕裂边缘不规则 |
| 撕裂边缘 | 平滑切口 | 边缘呈细微锯齿状（因纱线断裂位置不同）。可见断裂的纱线纤维卷曲回缩 |
| 撕裂速度 | — | 起初慢（需要初始撕裂力大），一旦起撕，沿纹理方向撕裂速度加快（传播撕裂力较小） |
| 碎片 | — | 脱落的纱线短纤维飘散。大面积撕裂时整块布料分离 |

---

### 8. 纸张/纸板

**物理特征**：纸是纤维网络，撕裂能量低。湿纸强度大幅下降。折叠处纤维损伤后易从此处撕裂。

| 参数 | 错误 | 正确 |
|------|------|------|
| 撕裂 | 整齐直线 | 不规则微锯齿撕裂线，沿纸张纹理方向更直，横纹理方向更曲折 |
| 揉皱 | — | 产生大量不规则折痕+体积缩小约50-70%+表面出现细密裂纹（纤维断裂痕迹） |
| 燃烧 | 均匀烧毁 | 边缘先卷曲焦黑→火苗沿边缘推进→纸张灰烬轻飘上升（受热气流影响路径曲折） |

---

### 9. 冰/冻结物体

**物理特征**：冰在0°C时脆性断裂，断裂韧性与温度相关（越冷越脆）。透明冰内部气泡使断裂面呈白色。

| 参数 | 错误 | 正确 |
|------|------|------|
| 断裂 | 均匀碎裂 | 沿晶体边界先裂→大块分离→小块碎片。透明冰碎裂后断面因微小气泡变为白色不透明 |
| 融化 | 均匀融化 | 边缘和尖端优先融化（比表面积大）。内部较大块最后融化。融化过程中表面始终有薄水膜反光 |
| 冰柱坠落 | 整体坠落 | 尖端先断→坠落后在空中旋转→触地碎裂为3-8块+细碎冰屑溅射 |

---

### 10. 人体/生物组织（受控描述）

> ⚠️ **内容安全**：以下为影视物理参考，不涉及真实伤害。仅描述可见的物理行为，不描述伤害程度。

| 参数 | 规范 |
|------|------|
| 受击反应 | 受力部位先向内凹陷（软组织压缩）→身体整体沿受力方向位移→四肢滞后于躯干（惯性） |
| 倒地 | 不是直接平躺。先臀部着地→躯干后倒→头部因惯性继续向后→头触地反弹（颈椎弹性） |
| 衣物在受击时 | 受力点衣物贴紧身体→周围衣物因气流鼓胀→随后恢复原状 |

## 三、液体行为标准（7种粘度级别）

### 1. 低粘度液体（水、酒精、清茶）

| 参数 | 规范 |
|------|------|
| 溅射速度 | 初速度与受力速度一致，方向定向（不是360°均匀） |
| 液滴大小分布 | 大滴少数(5-8滴，直径1-3cm)+中滴(15-20滴，0.3-1cm)+细喷雾(大量<0.3cm) |
| 空中形态 | 片状→表面张力使边缘收缩→破碎为液滴串→液滴在空气中保持球形（表面张力>空气阻力） |
| 落地反弹 | 大滴落地后反弹形成2-4个次级小液滴。小滴直接吸附表面 |
| 表面扩散 | 不规则指状边缘（受表面纹理和污渍影响）。扩散速度初始快（~5cm/s）→逐渐减慢 |
| 蒸发痕迹 | 水渍边缘有细微污渍环（水中杂质在边缘浓缩） |

**嵌入描述示例**：
```
水沿受力方向定向溅射+初始为片状+表面张力使边缘收缩+破碎为液滴串+大滴5-8滴直径1-3cm+中滴15-20滴+细喷雾弥漫+大滴落地反弹形成2-4个次级小液滴+液体在表面指状不规则扩散+扩散速度初始5cm/s逐渐减慢+水渍干燥后边缘留细微污渍环
```

### 2. 中粘度液体（咖啡、牛奶、汤）

| 参数 | 规范 |
|------|------|
| 溅射 | 比水更"粘稠"。片状溅射持续时间更长（不易破碎为液滴）。液滴形状不太圆（表面张力被粘度削弱） |
| 落地 | 溅射后液滴较粗大（直径>0.5cm），反弹弱或不反弹。表面扩散慢，边缘更厚 |
| 颜色层次 | 咖啡落地后颜色不均——中央深褐、边缘浅褐。牛奶纯白不透明 |

### 3. 高粘度液体（蜂蜜、机油、浓糖浆）

| 参数 | 规范 |
|------|------|
| 倾倒 | 连续柱状流下，不易断裂。断裂时形成细丝拉长后回弹 |
| 溅射 | 几乎不溅射。滴落后呈半球形堆在地面，缓慢塌陷扩散 |
| 表面 | 有光泽反光。扰动后表面缓慢恢复平整（粘度高，表面张力恢复慢） |

### 4. 血液（影视专用规范）

| 参数 | 规范 |
|------|------|
| **动脉喷射** | 与心跳同步的脉冲式喷射（约1Hz频率）。每次脉冲喷射距离递减。血液颜色鲜红（含氧） |
| **静脉流淌** | 连续缓慢流淌，颜色暗红。沿皮肤/物体表面纹理流动，受重力影响选择最低路径 |
| **滴落** | 初始为球形→接触地面瞬间变形为扁盘→边缘指状扩散→最终不规则圆形（直径约为滴落高度的1/3） |
| **飞溅形态** | 受击方向定向飞溅。飞溅距离与冲击力相关。血滴在空中保持球形（表面张力）。落地后形成放射状血点（拖尾指向来源方向） |
| **擦拭/涂抹** | 拖尾由湿→渐干。湿区边缘清晰→干区边缘模糊。色彩由鲜红→暗红→暗褐（氧化） |
| **稀释血** | 被水稀释的血呈粉红色半透明。流动性接近水，颜色均匀 |
| **干燥** | 边缘先干（薄）→中心后干（厚）。干血呈暗褐至黑色，表面有细微龟裂纹 |

### 5. 油漆/涂料

| 参数 | 规范 |
|------|------|
| 倾倒 | 高粘度连续流，颜色不透明，覆盖力强。表面有光泽反光。干燥后表面平整，厚度均匀 |
| 飞溅 | 大滴飞溅（粘度高）。落地后几乎维持原形，缓慢塌陷。干燥后呈泪滴状凸起 |

### 6. 泥浆/悬浊液

| 参数 | 规范 |
|------|------|
| 飞溅 | 不透明褐色溅射。水与固体颗粒分离——水飞得更远，泥块较近。干燥后固体颗粒残留成粉末 |

### 7. 泡沫/啤酒沫

| 参数 | 规范 |
|------|------|
| 溢出 | 白色泡沫迅速膨胀溢出容器口。泡沫由大量微小气泡组成，每个气泡反射光线呈白色。泡沫沿容器外壁缓慢下流+破裂消失（持续5-10秒） |

## 四、爆炸/冲击波完整行为模型

### 火球精确演化时间线

```
T+0.00-0.02s：引爆点产生直径<1m白热核心（色温>6000K，过曝）
T+0.02-0.10s：火球以约100-300m/s速度膨胀。表面温度~3000K（亮橙白）
T+0.10-0.30s：火球直径达到最大值（取决于炸药当量）。表面开始变暗至橙红(~2000K)
T+0.30-0.80s：外围暗红烟尘翻滚。火球内部出现黑灰色烟尘涡旋（燃烧不充分的碳颗粒）
T+0.80-2.00s：火球上升。底部扁平（受地面限制）。蘑菇云初步形成。顶部灰白、底部暗红黑
T+2.00s+：蘑菇云继续上升膨胀。顶部被高空风吹散呈扁平状。底部茎干拉长
```

**每帧的关键视觉变化**：
- 火球内部：不是均匀橙色，而是亮白热核+橙红外壳+暗红烟尘涡旋
- 烟尘层次：最深色黑（未燃烧碳）+灰（已燃烧灰烬）+棕（被卷起的泥土粉尘）+白（水蒸气冷凝）
- 地面反射：火球光照亮地面和附近建筑物，影子向外拉长→随火球上升影子缩短

### 冲击波三要素

**冲击波本身不可见，必须通过三种视觉线索间接表现**：

1. **空气折射变形**（最重要）：冲击波经过处的背景物体轮廓发生短暂扭曲（像透过热浪看东西但强烈得多）。持续时间约0.05-0.1s，之后恢复。必须明确写出"背景物体边缘短暂扭曲变形"

2. **地面/表面尘埃剥离**：冲击波到达时，地面松散尘埃被气压剥离形成"尘埃墙"向前推进。尘埃墙底部浓密顶部稀薄。尘墙后有持续几分钟的悬浮尘雾

3. **碎屑高速飞行**：轻质碎屑（纸张、树叶、小石块）被冲击波带动以超强风速向前飞行。碎屑的飞行速度应明显快于正常风速（>100km/h），且方向与冲击波一致

### 冲击波对建筑物的作用

```
0.00s：冲击波到达建筑正面
0.00-0.05s：玻璃窗向室内炸裂（不是向外——因为外部超压>内部气压）
0.05-0.15s：轻质结构（门、天花板、石膏板隔墙）碎裂向内坍塌
0.15-0.50s：建筑主体结构（梁柱）受正面压力。混凝土剥落、钢筋暴露
0.50-1.50s：建筑整体向远离爆心的方向倾斜→结构失效→整体坍塌
1.50s+：坍塌碎块堆成不规则山形。大量粉尘升空形成次级尘云
```

## 五、碰撞物理

### 车辆碰撞时间线

```
T-0.5s：紧急制动——轮胎抱死或ABS启动，轮胎与地面摩擦产生白烟
T-0.1s：车辆前部开始变形，保险杠首先接触。金属板金褶皱
T+0.0s：碰撞峰值——前部结构压溃。发动机舱向后位移。挡风玻璃从边缘碎裂
T+0.05-0.15s：乘客因惯性向前甩（安全带约束）。车内松散物品飞向车前
T+0.15-0.30s：车辆反弹/停止。后部因惯性翘起再落下。碎片继续向前飞出
T+0.30-1.00s：安全气囊展开（若配备）。蒸汽从破裂的散热器逸出。液体（冷却液/机油/燃油）从车底渗出
```

### 车辆翻滚

| 阶段 | 物理行为 |
|------|---------|
| 初翻 | 车辆侧面触地→车顶结构变形→车窗全碎 |
| 滚动 | 每次翻滚触地时金属板金继续压扁+玻璃碎片飞溅+零件脱落 |
| 停止 | 车顶朝下或侧面。车轮仍在空转（若无动力切断）。液体大量泄漏。车身不规则扭曲 |

## 六、自然破坏（环境类）

### 树木断裂

| 参数 | 正确 |
|------|------|
| 断裂方式 | 先从受力侧产生纵向裂纹→裂纹沿纹理扩散→木质纤维拉伸撕裂→树皮大片剥落→树木沿断裂方向倒下。断裂面木质纤维参差不齐呈刷状 |
| 倒下过程 | 先缓慢倾斜（根系还在拉扯）→加速倒下（根断裂）→触地弹跳1-2次→大量枝叶碎片飞散→尘土扬起 |
| 树叶反应 | 倒下过程中大量树叶因惯性先向前甩再被气流向后吹。触地瞬间树叶剧烈抖动 |

### 山体滑坡/泥石流

| 参数 | 正确 |
|------|------|
| 启动 | 先出现细小土石滑落→裂缝扩大→整块坡面剥离→向下加速滑动。大块岩石在前翻滚，细碎土石在后填缝 |
| 流动 | 呈舌状向前推进。前端有土石翻滚的"翻滚波"。后方有持续补充的土石流。速度约5-20m/s |
| 粉尘 | 滑坡过程中持续产生大量土黄色粉尘升空。粉尘在前端最浓密，形成可见的尘埃云前沿 |

### 地震/地面震动

| 参数 | 正确 |
|------|------|
| 视觉表现 | 不直接展示"地面摇晃"（相机也在摇晃所以不可见）。通过以下间接方式表现：吊灯摇摆幅度渐大、墙皮剥落、书架上物品掉落、窗户因结构变形而突然碎裂。最有力的视觉线索：地面突然出现裂缝并迅速扩展 |
| 裂缝扩展 | 裂缝从一处突然出现+以约10-30m/s速度沿地面扩展+裂缝边缘产生碎块+裂缝宽度不规则（窄处1-2cm宽处可>30cm） |

## 七、火焰与燃烧

### 火焰视觉层次

| 层次 | 温度 | 颜色 | 位置 |
|------|------|------|------|
| 焰心 | ~300-500°C | 暗区/蓝紫色（气体燃料）或不可见（固体燃料） | 火焰最底部 |
| 内焰 | ~500-1000°C | 亮黄色/橙色 | 包围焰心 |
| 外焰 | ~1000-1400°C | 淡蓝/紫色半透明（几乎不可见） | 火焰最外层边界 |

**火焰不是静止的**：火焰持续抖动、翻滚、拉长。扰动频率约5-15Hz。火焰形状不对称——受气流影响一侧被拉长。火焰边缘模糊过渡（不是硬边界）。

### 烟雾

| 参数 | 规范 |
|------|------|
| 上升 | 受热浮力上升，初始柱状→湍流扩散成锥形。上升速度约1-5m/s（随高度递减） |
| 颜色 | 白色/灰色（水蒸气/灰烬）→深灰/黑色（未燃烧碳颗粒）→棕色/黄色（化学烟雾）。颜色不均一，有深浅涡旋 |
| 形态 | 翻滚涡旋（湍流）+边缘模糊扩散。不是均匀锥形，不是静止的 |

## 八、粒子系统与尘埃行为

### 粉尘云

| 参数 | 规范 |
|------|------|
| 形成 | 撞击/破碎瞬间，从接触点喷射出粉尘云。初始速度高（>5m/s），快速减速（空气阻力）。粗颗粒先沉降（~1s），细颗粒悬浮（>5s） |
| 形态 | 翻滚湍流涡旋。边缘模糊扩散。密度从中心向边缘递减。受环境气流影响漂移 |
| 光照 | 光束穿过粉尘云时产生可见的丁达尔效应。粉尘云边缘在逆光下呈半透明暖色 |

### 碎片场

| 参数 | 规范 |
|------|------|
| 分布 | 大块飞得远（惯性大），小块飞得近（空气阻力减速快）。碎片落地位置不是均匀圆形——沿受力方向呈椭圆形分布 |
| 反弹 | 碎片落地后有2-5次弹跳。每次弹跳方向不完全一致（碎片不规则形状导致弹跳方向随机化）。旋转中的碎片以不规则方式弹跳 |
| 静止 | 大部分碎片在2-3秒内静止。少量细粉尘持续悬浮 |

## 九、关键 NOT 声明（已扩充 · 防止 AI 默认的物理失真）

```
=== 通用物理失真 ===
NOT perfectly symmetrical cracks NOT uniform debris distribution
NOT all fragments same size NOT smooth polished fracture surfaces
NOT slow-motion break without secondary fragments
NOT floating lightweight debris NOT zero-gravity behavior
NOT clean snap break NOT paper-like tearing

=== 玻璃 ===
NOT glass shattering without dust/powder NOT uniform spiderweb cracks from center

NOT tempered glass breaking into large shards NOT window breaking outward from explosion

=== 液体 ===
NOT liquid splashing uniformly in all directions NOT 360° symmetrical splash
NOT liquid without surface tension NOT all droplets same size spherical
NOT blood perfectly uniform color NOT blood spraying without pulse rhythm

=== 爆炸/火球 ===
NOT perfect sphere explosion NOT uniform orange fireball
NOT explosion without ground reflection lighting NOT smoke uniform gray color
NOT mushroom cloud perfectly symmetrical NOT fireball without internal turbulence

NOT sparks cooling instantly NOT sparks all following same trajectory

NOT flames static and smooth NOT fire without flicker 5-15Hz
```

## 十、物理交互 → 拍摄配合

| 破坏类型 | 最佳拍摄方案 | 原因 |
|---------|------------|------|
| **玻璃碎裂** | 硬切到碎裂特写+不需要全过程 | 全过程太复杂难以逼真，细节特写更有冲击力 |
| **陶瓷碎裂** | 固定+俯拍+保持1-2s静帧 | 裂纹和碎片分布需要稳定视角才看得清 |
| **液体溅射** | 机位不动+不跟飞溅 | 静态机位给观众对照，才能感受飞溅速度和方向 |
| **金属碰撞** | 先固定→碰撞瞬间微抖→恢复固定 | 对比产生冲击力。抖动幅度约5-10像素 |
| **爆炸** | 全景建立→硬切到近景细节→硬切回全景余波 | 全景给空间感、近景给冲击力、余波给释放 |
| **物体坠落** | 镜头不跟过坠落物 | 观众需要看到落点和坠落全貌。如果镜头跟过坠落物，观众失去空间参照 |
| **建筑倒塌** | 固定广角+硬切到人物反应+硬切回坍塌完成 | 不给全过程（太长），给关键阶段+人物反应 |
| **车辆碰撞** | 侧面机位→碰撞瞬间镜头微抖→硬切到车内 | 侧面最清晰展示变形。车内给主观冲击 |
| **冲击波** | 先固定→冲击波到达瞬间手持猛抖幅度>10px→恢复固定 | 对比=冲击力。固定部分与抖动部分各占1/2 |
| **慢动作破坏** | 仅用于关键节点（触地瞬间、碎片飞散峰值），不超过1s | 超过1s的慢动作=失去冲击力 |

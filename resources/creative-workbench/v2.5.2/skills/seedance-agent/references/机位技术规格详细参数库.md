## 一、俯拍（High Angle）技术规格

### 1. 轻度俯拍（15-30°）

**技术参数**：
- **垂直角度**：15-30°
- **镜头高度**：主体头顶上方 0.5-1 米
- **推荐焦距**：35mm-50mm（标准视角）
- **推荐光圈**：f/2.8-f/5.6
- **推荐距离**：2-4 米

**视觉效果**：
- 轻微压缩主体
- 保留面部表情
- 适度展示环境

**情绪表达**：
- 轻微的脆弱感
- 被观察感
- 日常叙事

**嵌入描述模板**：
```
轻度俯拍 + 镜头从主体头顶上方0.5米处以15度角俯视 + 35mm焦距 + f/2.8光圈 + 镜头距离主体3米 + 主体面部表情清晰可见 + 周围环境适度展示
```

---

## 核心原则总结

1. **角度决定情绪**：俯拍=渺小、仰拍=威严、平视=平等
2. **焦距决定透视**：广角=夸张、标准=自然、长焦=压缩
3. **光圈决定景深**：大光圈=虚化、小光圈=清晰
4. **距离决定景别**：近=特写、中=中景、远=全景
5. **详细参数=专业水准**：每个参数都要精确标注

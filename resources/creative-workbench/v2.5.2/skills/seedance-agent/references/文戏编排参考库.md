# 文戏编排参考库（Drama Scene Choreography）

> **本文件**：`references/文戏编排参考库.md` —— Seedance Agent v3.2.3+ 累积 · **文戏 3 件套之一**（与 `潜台词与言外之意设计参考库.md` + `静默时刻与留白设计参考库.md` 组成文戏 3 件套 · 对位武戏 3 件套）
>
> **定位**：解决"文戏拉跨"根本问题——agent 此前文戏处理资源仅占武戏的 1/4 · 缺少系统化工具链 · LLM 默认按"动作戏路径"生成文戏导致元素堆砌、克制失守。本库与对应 3 件套联合补足。
>
> **设计哲学**：
> - **文戏的灵魂不是"对白怎么念"** —— 现有 `对白情绪表达参考库.md` 只解决声音表面层
> - **文戏的灵魂是"对白时的微观渐变"** —— 潜台词 + 静默 + 微表情 + 物件 + 空间 + 节奏 6 维持续累积
> - **文戏的信息素 ≠ 元素堆叠** —— 是"微观渐变密度"而非"物件密度"
> - **大师参照**：是枝裕和 / 王家卫 / Coppola / Hitchcock 场景 A / 杨德昌 / 侯孝贤 / Cuarón 车内段 = 文戏 6 圣经
>
> **强触发条件**：
> - **当 segment 内对白镜头 ≥1 时** → 强触发本库 + 信条 8 对白戏镜头铁律
> - **当 segment 标签为"日常 / 求助 / 告别 / 谎言 / 表白 / 决断 / 死亡（克制版）/ 暧昧"等文戏情境时** → 强触发文戏 3 件套
> - **当 segment 节奏标记为"慢 / 极慢"且无武戏/动作元素时** → 强触发本库

## 一、文戏 7 阶段（Drama Scene 7-Stage Model）

类比武戏 5 阶段（发起 / 接招 / 反击 / 胶着 / 收招）· 文戏有自己的 7 阶段。

| 阶段 | 名称 | 物理参数 | 戏剧功能 | 大师案例 |
|-----|------|---------|---------|---------|
| **0** | **开场建立**（Establishment）| 0.5-2s · 空间建立 + 角色位置 + 静态秩序 | 让观众"读取空间"+ 角色关系初判断 | 是枝《小偷家族》围桌吃饭起手镜（榻榻米 + 6 人围矮桌）|
| **1** | **试探接触**（First Contact）| 1-3s · 微表情接触 + 物件接触 + 视线接触 | 角色之间"探边界"——能不能说真话 | Coppola《教父》Bonasera 开口"我相信美国"+ 教父抚摸猫 |
| **2** | **暗潮起步**（Subtext Surfaces）| 2-5s · 潜台词外泄 1-2 次 + 物件被微表情化使用 | 角色心想 ≠ 角色说话 · 观众开始读潜台词 | 王家卫《花样年华》楼道相遇 + 旗袍系列变化 |
| **3** | **关键转折**（Tipping Point）| 1-3s · 静默 ≥1s + 决断微表情（眼神聚焦 / 喉结上下 / 嘴角抿紧）| 角色心理状态从"试探"切换到"决断" | Coppola《教父》Michael 听 Sollozzo 30s 长 take 5 微表情渐变 |
| **4** | **情感峰值**（Emotional Peak）| 2-5s · 微表情峰值 + 静默峰值 + 物件释放（颤抖手 / 杯子摇晃 / 物件掉落） | 文戏的"情感最高点"——但绝不爆发 | Cuarón《人类之子》Theo 凝视死去的 Julian 8s + 空洞凝视 + 不哭不喊 |
| **5** | **收尾余韵**（Resolution Echo）| 1-3s · 微表情余震 + 视线收回 + 物件归位 | 让情感峰值的余震被观众"消化" | 是枝《小偷家族》阿初奶奶临终唇动"啊真好"|
| **6** | **空间空镜**（Space Echo · 可选）| 1-3s · 离开角色 + 拍空间 / 物件 / 远景 + 让观众"停留"在场景中 | 给观众"在场感"持续——这才是文戏的"余韵"| 是枝《小偷家族》全家走后空房间 / 王家卫《花样年华》空房间钟摆 |

**强制规则**：
- 任何 ≥18s 的文戏 segment **必须经过 ≥5 个阶段**（不能从 0 直接跳到 4）
- 关键转折阶段（#3）**必须有 ≥1s 静默**——这是文戏 vs 动作戏的最大区别
- 情感峰值阶段（#4）**必须保持克制 30-50%**——绝不允许大开大合 70-95%（除非高潮 / 死亡爆发）
- 空间空镜阶段（#6）在"日常诗意 / 静观电影 / 末世情感"项目类型下**强制启用**

## 二、文戏 5 维度系统（5-Dimension System）

类比武戏 5 维度（物理 / 心理 / 战局 / 节奏 / 兵器）· 文戏有自己的 5 维度。

### 维度 1：**潜台词维度（Subtext Dimension）**

详见 `潜台词与言外之意设计参考库.md` 全文。本库简述：

- **强制标注**：每镜文戏必填 `[潜台词：心想=___（角色心理）· 外泄=___（如何被画面读到）· 言外之意=___（观众理解）]`
- **物件化潜台词**：教父抚摸猫 = 权力的从容 / 花样年华旗袍系列 = 时间流逝 / 小偷家族递碗 = 拼凑家庭的真情
- **视线化潜台词**：不对视 = 隐瞒 / 假装看别处 = 试探 / 眼神下移 = 决断 / 眼神聚焦 = 顿悟
- **静默化潜台词**：长 take 静默 8s = 死亡余震 / 静默 3s = 决断 / 静默 0.5s = 思考

### 维度 2：**静默时刻维度（Silence Dimension）**

详见 `静默时刻与留白设计参考库.md` 全文。本库简述：

- **静默占比**：文戏全片至少 30% 时间无对白 · 关键 segment ≥40%
- **静默时长 vs 剧情功能映射**：0.5s 思考 / 1s 试探 / 3s 顿悟 / 5s 决断 / 8s 死亡余震 / 30s 命运凝视
- **静默 vs 配乐对位**：配乐进入前必有 ≥3s 静默 + 配乐淡入

### 维度 3：**微表情累积维度（Micro-Expression Accumulation）**

不是单个微表情 · 是**连续渐变累积**：

- **强制 ≥3 个连续微表情**（信条 17a.1 微表情 8 子原子之 ≥3）
- **示例**：眼神下移 → 鼻翼微张 → 嘴角抿紧 → 喉结上下 → 眼神聚焦（Coppola Michael 5 微表情渐变）
- **大师参照**：Coppola Bonasera 180s 长 take 8 微表情渐变 / Hitchcock Bonasera 80% 顶光遮眼洞下 5 微表情 / 是枝阿初奶奶临终 4 微表情
- **反 AI 陷阱**：AI 默认让角色"表现 1 个夸张表情"——必须用 `subtle continuous micro-expression gradient` 而不是 `expression`

### 维度 4：**物件细节维度（Object Detail Dimension）**

物件不是"装饰"——是"心理外化"：

- **物件 3 类**：
  - **接触物件**（角色手里 / 桌上 / 身边的物件 · 被微表情化使用）—— 教父雪茄 / 花样年华茶杯 / 小偷家族饭碗 / Bonasera 帽子
  - **背景物件**（空间中的物件 · 用于建立空间秩序 vs 混乱）—— 教父办公室书脊 / 花样年华壁纸 / 小偷家族杂物
  - **象征物件**（贯穿 segment 的视觉母题）—— Bong《寄生虫》石头 / 是枝相机 / 教父戒指
- **每镜文戏 ≥1 接触物件被微表情化使用**（不只是出现 · 是被角色微表情驱动）

### 维度 5：**空间几何维度（Spatial Geometry Dimension）**

文戏的空间是**情感几何**：

- **2 人对话戏 4 大空间几何**：
  - **正面相对**（最近距离 1m · 直接对峙）—— 教父 vs Bonasera
  - **侧面并坐**（距离 0.5m · 共谋 / 亲密）—— 王家卫《花样年华》男女主同坐沙发
  - **背对侧面**（距离 1.5m · 不直接面对 = 隐瞒 / 试探）—— Cuarón《人类之子》Theo 不直视
  - **跨空间对话**（角色不在同一画面 · 用 OTS / 反应镜 / 空间错位）—— 信条 8 b 双子律
- **3+ 人围坐戏的几何**：
  - 围矮桌（家庭温度）—— 是枝《小偷家族》
  - 围长桌（权力 + 等级）—— 教父家族会议
  - 围咖啡桌（社交 + 暗潮）—— 王家卫《花样年华》打麻将

## 三、文戏 8 子原子（8 Sub-Atoms · 类比微表情 8 子原子）

每镜文戏必须涉及 ≥5 个子原子（不能只靠"对白 + 表情"两件套）：

| # | 子原子 | 描述 | 必填强度 |
|---|--------|------|---------|
| **1** | **对白**（Dialogue）| 角色说什么 + 怎么说 + 在什么时候说 | 强制（但≤50% 时间）|
| **2** | **表情**（Facial）| 微表情 ≥3 个连续渐变 + 眼神 + 嘴角 + 眉头 + 鼻翼 + 喉结 + 下巴 + 太阳穴 | 强制 |
| **3** | **视线**（Gaze）| 看哪里 + 不看哪里 + 视线移动节奏 + 对视 vs 不对视 | 强制 |
| **4** | **动作**（Body）| 身体动作 ≤30% 幅度 + 微动作（颤抖手 / 深呼吸 / 重心微移 / 头部微转） | 强制 |
| **5** | **物件**（Object）| ≥1 接触物件被微表情化使用 + ≥1 背景物件建立空间 | 强制 |
| **6** | **空间**（Space）| 空间几何 + 角色站位 + 距离 + 摄影机态度（信条 30）| 强制 |
| **7** | **静默**（Silence）| ≥30% 时长无对白 + 静默时刻设计 + 配乐对位 | 强制 |
| **8** | **节奏**（Pacing）| 镜头时长 + 微表情节奏 + 静默节奏 + 对白节奏 + 物件接触节奏 | 强制 |

**强制规则**：
- 每镜文戏 Layer 1 必须标注 `[文戏 8 子原子：1=___ · 2=___ · 3=___ · 4=___ · 5=___ · 6=___ · 7=___ · 8=___]`
- 至少 5 个子原子有具体内容 · 全部为"无"= P1 文戏空洞

## 四、文戏 6 大情境模板（6 Contextual Templates）

为最常见的 6 种文戏情境提供"开箱即用"模板。

### 情境 1：**求助 / 恳求**（Plea / Supplication）

- **戏剧功能**：弱者向强者请求 + 权力不对等
- **节奏**：极慢（5-8s/镜）
- **默认表演分寸**：克制 30-50%
- **关键阶段**：开场建立 → 试探接触 → 暗潮起步 → 关键转折（强者表态）→ 情感峰值（弱者反应）→ 收尾余韵
- **必备元素**：弱者物件接触（教父 Bonasera 帽子放胸口）+ 强者物件接触（教父抚摸猫）+ 长 take ≥5s + 极缓推 0.02-0.05 m/s + 单顶光暗调摄影 + 静默 ≥3s（强者决断前）
- **大师参照**：⭐⭐⭐ Coppola《教父》场景 A Bonasera 求助 180s 极缓推大特写 + 8 微表情渐变 = 影史经典
- **反例**：弱者大哭 / 强者皱眉斥责 / 快剪短切 / 无静默 = 破坏求助美学

### 情境 2：**告别 / 离别**（Farewell / Departure）

- **戏剧功能**：永远的离开 / 暂时的离开 + 未说出口的话
- **节奏**：慢（3-6s/镜）
- **默认表演分寸**：克制 30-50% 或极致克制 ≤30%
- **关键阶段**：开场建立（空间秩序）→ 试探接触（眼神接触）→ 暗潮（不说出口）→ 静默峰值（≥5s）→ 收尾余韵（背影 / 空间空镜）
- **必备元素**：物件交换（围巾 / 信物 / 茶杯）+ 长 take 静默 ≥5s + 眼神不对视 vs 短暂对视 + 空间空镜 ≥1s + 自然光软散射
- **大师参照**：⭐⭐⭐ 王家卫《花样年华》楼道相遇 + 旗袍系列变化 / 是枝《小偷家族》海边远景告别
- **反例**：拥抱大哭 / 长篇对白 / 配乐推动情绪 = 破坏告别美学

### 情境 3：**谎言 / 隐瞒**（Lie / Concealment）

- **戏剧功能**：角色说谎 + 观众知道是谎言 vs 观众也被骗
- **节奏**：标准（3-5s/镜）
- **默认表演分寸**：极致克制 ≤30%（说谎者）+ 克制 30-50%（被骗者）
- **关键阶段**：开场建立 → 试探（说谎者眼神微颤）→ 暗潮（说谎者物件接触异常）→ 关键转折（被骗者是否察觉）→ 收尾
- **必备元素**：说谎者**眼神不对视** + 物件细微异常（手抖 0.5°/s + 杯子摇晃 + 喉结上下）+ 被骗者反应镜头 ≥40%（信条 8）+ 摄影机微微入侵 + 中景 50mm + 极少配乐
- **大师参照**：Cuarón《人类之子》Theo 沉默 / Hitchcock《迷魂记》Madeleine 假死前的对话 / Coppola Michael 在医院给父亲不存在的承诺
- **反例**：说谎者夸张表情 / 被骗者瞪眼 / 镜头强行特写说谎者嘴 = 破坏隐瞒美学

### 情境 4：**表白 / 暧昧**（Confession / Ambiguity）

- **戏剧功能**：感情被说出 vs 感情被悬置 + 礼仪压住欲望
- **节奏**：极慢（5-10s/镜）
- **默认表演分寸**：克制 30-50% 或极致克制 ≤30%
- **关键阶段**：开场建立 → 试探接触（不说出口的暗示）→ 暗潮（潜台词外泄）→ 关键转折（说出口 vs 悬置）→ 情感峰值（反应或不反应）→ 收尾余韵
- **必备元素**：物件中介（茶杯 / 香烟 / 雨伞 / 信件）+ 静默 ≥3s + 视线交错（短暂对视 + 立刻避开）+ 暖钨丝 3200K 暖色调 + 中景 50mm 浅景深 + Sound Bridge 配乐淡入
- **大师参照**：⭐⭐⭐ 王家卫《花样年华》楼道相遇 / Coppola《教父》Sollozzo 餐厅 Michael 沉默 / Hitchcock《迷魂记》Madeleine 镜中
- **反例**：大声告白 / 强吻 / 戏剧化拒绝 = 破坏暧昧美学

### 情境 5：**决断 / 顿悟**（Decision / Realization）

- **戏剧功能**：角色心理状态从"未定"切换到"已定" + 观众读到这个瞬间
- **节奏**：极慢（5-30s/镜）
- **默认表演分寸**：极致克制 ≤30%
- **关键阶段**：试探（信息接收）→ 暗潮（思考）→ 静默峰值（决断前停顿 ≥3s）→ 决断微表情（眼神聚焦 / 喉结上下 / 嘴角抿紧）→ 收尾
- **必备元素**：长 take ≥8s + 微表情 ≥5 个连续渐变 + 静默 ≥3s + 焦平面锁眼睛 + 75mm 长焦特写 + handheld 0.3°/s（紧张但克制）
- **大师参照**：⭐⭐⭐ Coppola《教父》Michael 听 Sollozzo 30s 5 微表情渐变（餐厅刺杀决断） / Hitchcock《迷魂记》Bonasera 跪下决断 / Villeneuve《降临》Louise 决定告诉 Ian
- **反例**：角色瞪眼 + 大喊"我决定了！" / 配乐爆发 / 快剪短切 = 破坏决断美学

### 情境 6：**死亡（克制版）**（Death · Restrained）

- **戏剧功能**：人物死亡 + 旁人凝视 + 没有戏剧化爆发
- **节奏**：极慢（5-10s/镜）
- **默认表演分寸**：克制 30-50%（死者）+ 极致克制 ≤30%（旁观者）
- **关键阶段**：开场（死者状态）→ 试探（旁观者发现）→ 静默峰值 ≥5s（死者气声 / 旁观者凝视）→ 死亡瞬间（信条 17a.1 微表情死亡 3 子）→ 收尾余韵（空间空镜）
- **必备元素**：升格 48-60 fps + 静默 ≥5s + 焦平面锁死者眼睛 + 微表情死亡 3 子（瞳孔涣散 + 嘴角微张 + 喉咙气声）+ 旁观者反应 ≥40% + 空间空镜 ≥2s
- **大师参照**：⭐⭐⭐ Cuarón《人类之子》Julian 中弹 + Theo 8s 凝视 / Spielberg《拯救大兵瑞恩》Miller 死 + 望天空 / 是枝阿初奶奶临终唇动
- **反例**：哭喊"不要走" / 配乐爆发 / 角色大喊"为什么" = 破坏克制死亡美学
- **与"死亡（爆发版）"区分**：恐怖片 / 暴力高潮 / Hitchcock 钟楼漩涡 → 大开大合 70-95% 是合法的 · 文戏死亡必须克制

## 五、文戏 4 大节奏模式（4 Pacing Modes · 反"元素堆叠"信息素阈值）

**核心：文戏的"信息素"≠ 物件密度 · 而是"微观渐变密度"**。

| 节奏模式 | 物理参数 | 微观渐变密度（元素/秒）| 物件密度 | 大师参照 | 适用情境 |
|---------|---------|---------------------|---------|---------|---------|
| **极慢**（Glacial）| 镜头时长 ≥8s · 极缓推 0.02-0.05 m/s | 0.2-0.5（微表情连续渐变 + 微动作 + 物件微变化）| **≤3 个物件**（避免元素堆叠）| Coppola《教父》Bonasera 180s · Cuarón《人类之子》Theo 凝视 8s · 是枝阿初奶奶临终 6s | 求助 · 告别 · 决断 · 死亡（克制） |
| **慢**（Slow）| 镜头时长 3-8s · dolly 0.05-0.1 m/s | 0.5-0.8 | ≤5 个物件 | 王家卫《花样年华》楼道相遇 · 是枝《小偷家族》围桌吃饭 · Villeneuve《降临》母女场景 | 暧昧 · 日常 · 师徒 · 怀旧 |
| **标准**（Standard）| 镜头时长 2-5s · handheld 0.3-0.5°/s 或 dolly 0.1-0.3 m/s | 0.8-1.2 | ≤7 个物件 | Hitchcock《迷魂记》跟踪戏 · Bong《寄生虫》前 1/3 喜剧段 · Coppola 餐厅 | 试探 · 谎言 · 跟踪 · 紧张对话 |
| **紧张**（Tense）| 镜头时长 1-3s · handheld 0.5-1.0°/s | 1.2-1.8（已接近动作戏门槛）| ≤9 个物件 | 教父办公室争执 · 寄生虫地下密室发现 | 高潮文戏 · 揭穿 · 摊牌 |

**⚠️ 反元素堆叠规则**：
- 文戏的信息素 ≠ 物件密度 + 动作密度 + 配乐
- 文戏的信息素 = **微观渐变密度**（微表情 / 静默累积 / 潜台词外泄 / 物件细微化 / 视线节奏）
- **如果一镜文戏物件 ≥10 个 + 微表情仅 1 个夸张 = 反向操作**——画面饱满 · 戏剧空洞
- **如果一镜文戏物件 ≤5 个 + 微表情 ≥3 个连续渐变 + 静默 ≥40% = 正向操作**——画面克制 · 戏剧饱满

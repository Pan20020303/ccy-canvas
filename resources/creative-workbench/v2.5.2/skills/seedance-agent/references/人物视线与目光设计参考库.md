# 人物视线与目光设计参考库

> **用途**：每个有人物的镜头，Agent 必须精确描述角色在看向什么方向、以什么情绪看、看多久。AI 视频模型对含糊的"看向某处"极不擅长——必须量化。
>
> **与调度/表演的关系**：视线是调度（头转向哪）和表演（眼神的情绪）的交汇点。头+眼的方向必须协调，且与身体朝向和走位一致。见 `角色调度与走位参考库.md` §〇 情绪统一驱动表。

---

## 一、视线的三维量化

AI 模型需要精确的方向数据，不是"看着远处"。

| 维度 | 量化方式 | 示例 |
|------|---------|------|
| 水平角 | 偏左/偏右度数，以角色正前方为0° | `视线偏右约30°` `视线正前0°` |
| 仰角 | 向上/向下度数，以水平面为0° | `仰视约15°` `俯视约20°` `平视0°` |
| 焦点距离 | 近(0.3-1m)/中(1-5m)/远(5m+)/无限远 | `焦点远距离>1km地平线` `焦点中距离约2m对面人脸` |
| 持续时间 | 秒数 | `持续3秒不眨眼` `扫视约0.5秒后收回` |

**嵌入格式**：
```
眼神方向=偏右30°+仰角15°+焦点远距离>1km+持续3秒不眨眼
```

## 二、视线的情绪语义

### 垂直方向（抬头/低头）

| 方向 | 情绪 | 典型场景 | 嵌入描述 |
|------|------|---------|---------|
| 仰视>30° | 敬畏、仰望、寻求、祈祷 | 看天空/高楼/神像/巨物 | `仰视约35°+瞳孔微缩+嘴唇轻启+呼吸放缓` |
| 仰视15-30° | 希望、憧憬、好奇 | 看远处天空/山巅/旗帜 | `仰视约20°+瞳孔映着光线+嘴角微扬` |
| 仰视<15° | "向上思考"、回忆 | 大脑运作时自然微仰 | `仰视约10°+眼神放空失焦+眉头微锁` |
| 平视0° | 对峙、坦诚、平等、日常 | 对话、日常行为 | `平视0°+眼神聚焦+自然眨眼` |
| 俯视<15° | 思考、回避、羞耻 | 低头走路、看着桌面 | `俯视约10°+目光落地+肩膀微缩` |
| 俯视15-30° | 悲伤、反思、愧疚 | 垂头、看着地面 | `俯视约20°+眼神空洞+嘴角下垂` |
| 俯视>30° | 屈服、崩溃、完全羞耻 | 跪地、瘫坐、匍匐 | `俯视约40°+面部几乎朝地+身体蜷缩` |

### 水平方向（偏左/偏右）

| 方向 | 情绪 | 叙事功能 |
|------|------|---------|
| 视线向左（角色面朝摄影机时） | 回忆过去、反思、内省 | 西方文化中左=过去，回忆镜头 |
| 视线向右（角色面朝摄影机时） | 思考未来、规划、前进 | 右=未来，建立目标或希望 |
| 视线偏离镜头 | 回避、不安、撒谎、被压制 | 不愿与对话者/观众对视 |
| 视线正直镜头（打破第四面墙） | 坦诚、挑衅、自知、倾诉 | 只用于关键情绪点 |

### 视线变化（动态视线最有表现力）

| 变化模式 | 语义 | 嵌入描述 |
|---------|------|---------|
| 放空→聚焦 | 注意到某物、从思绪中回来 | `原本眼神放空平视0°+瞳孔突然收缩+视线快速偏右30°仰角20°聚焦远处` |
| 聚焦→放空 | 沉浸思绪、震惊后的麻木 | `原本凝视正前方+瞳孔逐渐扩散+视线失焦+头部缓慢下垂俯视15°` |
| 扫视 | 搜寻、警觉、焦虑 | `视线快速从左到右扫视约120°角范围+每点停留0.2-0.3秒+瞳孔微动` |
| 回避→接触→回避 | 犹豫不决、被吸引但不该 | `视线偏离镜头→短暂视线接触约1秒→快速移开俯视10°` |
| 缓慢追踪 | 观察移动物、着迷 | `视线以被观察物的速度缓慢偏转+头部跟随转动+眼睛始终聚焦+持续5秒` |

## 三、视线揭示（Spielberg Face 的视线设计）

斯皮尔伯格式凝视的核心：**角色看到了什么——观众看不到——但观众从角色的眼神中"看"到了那个东西的重量**。

### 视线揭示的三段式

```
阶段1（缓冲1-2s）：角色正在进行日常动作，眼神正常、放松
阶段2（牵引0.5-1s）：视线被画面外某物"拽走"。头部不动，只有眼神移动和瞳孔变化
阶段3（凝视2-4s）：完全转向目标方向，面部表情逐渐冻结/展开——观众看不到目标但感受到冲击
```

**嵌入描述模板**：
```
0-1.5s: 角色正在低头写字俯视25°眼神放松+ 

1.5-2s: 眼角余光捕捉到窗外光线变化+眼神从纸面移开+头部未动但视线快速偏左40°仰角15°+瞳孔从放松状态开始收缩+ 

2-4s: 头部缓慢转向左侧面向窗外+视线偏左40°仰角15°焦点远距离地平线+瞳孔完全放大+嘴唇微启+面部肌肉从放松→冻结+ 

4-6s: 保持凝视不眨眼+瞳孔已经放大到最大+嘴唇开始轻颤+眼角有泪光反光+观众始终看不到角色在看什么——镜头不切
```

### 视线揭示的关键规则

1. **观众不能比角色先看到目标**——如果观众已经在画面中看到了核爆，再切到角色"震惊地看着核爆"就毫无冲击力。应该是先拍角色的反应，再揭示。
2. **目标的视觉信息通过角色的眼神传给观众**——瞳孔大小变化、眨眼频率、头部角度，都是在"描述"那个看不见的目标。
3. **揭示的时机**——角色凝视达到峰值时（通常2-4秒），镜头的画面张力达到顶点。此时如果切到目标画面=释放张力；如果继续不揭示=悬念继续累积。

## 四、对话中的视线调度

对话不仅是台词的交换，更是视线的舞蹈。

| 模式 | 视线行为 | 含义 |
|------|---------|------|
| **直视<30%** | 说话时偶尔看对方一眼然后移开 | 礼貌距离、日常对话、不太投入 |
| **直视30-60%** | 说话时一半时间看对方 | 正常对话、适度投入 |
| **直视>70%** | 几乎持续看对方 | 强烈投入/对峙/威胁/亲密 |
| **听者看>说者看** | 听的人看得多，说的人看得少 | 正常对话模式（听者通过视线表达"我在听"） |
| **说者看>听者看** | 说的人看得多，听的人回避 | 说的人在施加压力或追求认同，听的人在回避 |
| **双方互不看** | 都看向别处但继续对话 | 谈论尴尬/痛苦话题，或坐在同一方向（如并排坐在长椅上） |
| **视线抢夺** | A想建立眼神接触但B回避→A放弃→B反而看过来 | 权力关系的微妙博弈 |

### 对话视线的情感节奏

```
对话开始：目光接触→建立对话连接（0.5-1s）

对话进行：自然交替——说话者看对方25-60%时间，倾听者看对方60-80%时间。看的时候持续1-3秒，移开后1-2秒再看。

情绪升温：目光接触比例升高→持续时间延长→眨眼频率下降

冲突点：目光接触突然中断——一方低头或偏头=对话中某个话题触到了痛点

和解点：重新建立目光接触，但比以前更软——不再是confrontation的凝视，而是connection的注视
```

## 五、多人场景的视线网络

| 人数 | 视线策略 |
|------|---------|
| 2人 | 标准对话视线。关键是谁先移开——先移开者暂时失去权力 |
| 3人 | 三角形视线：A看B→B看C→C看A。眼神在这三人间流转。核心人物获得最多视线"入账" |
| 4-5人 | 核心1-2人之间的视线为主，其他人视线流向核心人物。角缘角色偶尔交换视线（暗示次要关系） |
| 6+人 | 只跟踪2-3条核心视线关系。其余人作为背景视线"噪声"。不能让每个观众都追踪到 |

**群像铁律**：不要让所有人同时看向同一个人——这会让画面看起来像排练过。总有人没在看（他们可能在低头、看向别处、或者在看着"看着核心人物"的人）。

## 六、视线与身体朝向的协调

身体朝向和视线方向不一致时，传达复杂的内心。

| 身体朝向 | 视线方向 | 含义 |
|---------|---------|------|
| ⬆正对 | ⬆正对 | 全神贯注、完全投入 |
| ⬆正对 | ➡偏右 | 身体在敷衍但注意力被吸引走了 |
| ⬆正对 | ⬇俯视 | 身体在但心理已退场 |
| ⬅侧向 | ⬆看向交谈者 | 半心半意地听、随时要走 |
| ⬅侧向 | ⬅同向远望 | 并肩陪伴，不需要看也不需要说 |
| ⬇背对 | ➡回头 | 要走但被牵住最后一秒 |
| ➡走向出口 | ⬅回头 | 离开但放不下 |

**关键**：身体朝向和视线方向不一致 = 内心冲突的视觉化。一致 = 内心与外在统一。

## 七、AI 模型视线常见 Bug 与修复

| Bug | 原因 | 修复嵌入描述 |
|-----|------|------------|
| 两人对视但方向不对 | 模型不懂"视线方向"的物理意义 | `A视线偏左15°看B+ B视线偏右15°回看A+ 两人视线在中间交汇` |
| 看着爆炸但视线偏低 | 模型将"看爆炸"理解为看远处而非看高处 | `视线偏左30°+仰角25°+焦点远距离地平线上方+头部明显仰起脖子后仰` |
| 视线空洞无焦点 | 没有指定焦点距离 | `视线聚焦+焦点中距离约1.5m对方双眼+眼神有明确焦点非空洞` |
| 多人看同方向但各看各的 | 没有指定共同焦点 | `三人视线方向一致偏右20°仰角15°+焦点远距离同一目标+视线汇聚于一点` |
| 看着画面外的物体但瞳孔无反应 | 缺少瞳孔/眼睛细节 | `瞳孔因好奇而收缩+虹膜反射窗外光线+眨眼频率降至每3秒1次` |

## 八、嵌入格式要求

每个有人物的镜头，必须嵌入视线描述：

```
视线 = 水平角 + 仰角 + 焦点距离 + 持续时间 + 瞳孔变化
```

完整示例：
```
眼神方向偏右30°仰角15°焦点远距离>1km地平线+瞳孔映着夕阳金光收缩+持续3秒不眨眼+嘴角微启+头部缓慢从正面转向右侧配合视线
```

## 九、视线自查

```
□ 镜头中每个角色都有明确的视线方向描述吗？
□ 视线方向是否与场景中的目标（人物/物体/事件）的物理位置一致？
□ 如果角色看到了震撼/惊人的画面，他的瞳孔和面部肌肉有反应吗？
□ 视线揭示（如有）的节奏是否正确——角色反应→揭示目标，而非相反？
□ 多人场景中，主要角色的视线关系是否清晰？
□ 是否检查了"视线撞墙"——角色看向的方向空间被裁切？
```

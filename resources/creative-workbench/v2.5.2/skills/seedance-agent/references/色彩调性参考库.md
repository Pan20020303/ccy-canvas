# 色彩调性参考库

本文档提供电影色彩设计的完整参考，供 Seedance 提示词的色彩方案生成使用。

---

## 一、配色方案类型（6种）

| 方案 | 色相关系 | 情绪意图 | 典型用法 |
|------|---------|---------|---------|
| **单色 (Monochromatic)** | 单一色相，通过明度/饱和度变化制造层次 | 极简、宁静、情绪高度聚焦 | 极简场景、单一情绪场面 |
| **类似色 (Analogous)** | 色轮上相邻 2-3 色 | 和谐、自然、舒适 | 自然环境、温馨日常、风景空镜 |
| **互补色 (Complementary)** | 色轮上对立两色（180°） | 强烈对比、张力、视觉冲击 | 冲突场面、对峙、关键瞬间 |
| **分裂互补 (Split-Complementary)** | 主色 + 互补色两侧（±30°） | 对比但比纯互补柔和 | 平衡的戏剧场面、复杂关系 |
| **三角色 (Triadic)** | 色轮等距 3 色（120°） | 活力、平衡、色彩丰富 | 群像、欢快场面 |
| **冷暖对立** | 冷色区 vs 暖色区分占画面 | 距离/隔阂/角色对立 | 对峙、关系张力 |

## 二、电影调色风格惯例（9种 · 可叠加于配色方案）

| 风格 | 视觉特征 | 情绪/题材适配 |
|------|---------|-------------|
| **青橙对比 (Teal & Orange)** | 阴影偏青蓝，高光/肤色偏橙 | 商业大片、动作、视觉惊艳 |
| **漂白旁路 (Bleach Bypass)** | 极低饱和，高对比，粗颗粒 | 战争、犯罪、写实粗砺 |
| **日光夜景 (Day-for-Night)** | 整体蓝调，压低曝光 | 夜景、神秘氛围 |
| **单色限定 (Limited Palette)** | 整片色彩限定在 2-3 色 | 风格化作者电影（王家卫、韦斯·安德森） |
| **高调 (High Key)** | 整体明亮、低对比、阴影柔和 | 喜剧、爱情、希望、童真 |
| **低调/黑色电影 (Low Key)** | 大量阴影、高对比、单光源 | 悬疑、犯罪、心理、恐怖 |
| **复古褪色 (Faded Vintage)** | 略黄调，饱和度降低，胶片颗粒 | 回忆、时代剧、怀旧 |
| **霓虹赛博 (Neon/Cyberpunk)** | 高饱和粉紫青，黑色基底 | 赛博朋克、未来都市、迷幻 |
| **古风国画 (Ink Wash)** | 低饱和墨色，留白，水墨晕染 | 古风、仙侠、东方意境 |

## 五、色彩实例化流程

按以下流程生成色彩方案并写入提示词：

1. **定情绪方向**：本镜头的核心情感是什么？查「三、情绪→配色映射速查」
2. **选配色方案**：从「一、配色方案类型」选一种
3. **可选叠加风格惯例**：从「二」选一种调色风格叠加（每组最多叠一种）
4. **定阴影/高光色偏**：从「四」选一组
5. **填具体色相与占比**：`主色调[N]% + 辅色调[N]% + 点缀色[N]%；阴影偏[X]，高光偏[Y]`
6. **校验**：情绪与配色对位？与同场景上一组配色连贯？

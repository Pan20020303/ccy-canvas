# 角色调度与走位参考库

> **用途**：确保每个镜头中的人物不是"站桩"。Agent 必须在镜头描述中嵌入角色的空间位移、身体朝向变化、角色间的相对位置移动。只有表情没有身体动作 = 站桩 = 非电影。
>
> **与其他 reference 的关系**：本文档专注人物在画面内的空间运动。机位选择见 `机位情绪决策参考库.md`，构图见 `构图设计参考库.md`，运镜见 `超详细运镜规格参考库.md`。**本文档与 `表演细节参考库.md` 是一体两面——情绪同时驱动宏观调度和微观表演，不可孤立使用。**

## 〇、调度与表演：情绪统一驱动表（v2.7 新增 · 绑定 `表演细节参考库.md`）

> **调度（宏观空间移动）和表演（微观身体细节）由同一个情绪驱动。Agent 在决定角色的空间走位后，必须同步调用表演细节库选取匹配的微表情和肢体动作。**

| 情绪 | 宏观调度（本文档） | 微观表演（见 `表演细节参考库.md`） | 调度+表演融合嵌入示例 |
|------|-----------------|----------------------------------|---------------------|
| **愤怒** | 大步快速移动、突然改变方向、侵入他人空间、推/踢物体 | 眼神凝视不眨眼+牙关紧咬+额头青筋+握拳关节发白+呼吸急促胸口起伏 | `大步快速穿过房间步速2.0m/s+经过垃圾桶时突然停住+右脚猛踢桶身+桶翻滚撞墙+同时牙关紧咬下颌紧绷+额头青筋暴起+握拳关节发白+呼吸急促胸口剧烈起伏+继续大步前行` |
| **焦虑** | 来回踱步、无法保持静止、频繁改变方向、动作重复 | 眼神游移不聚焦+嘴角抽动+手指反复敲击/摩挲+呼吸急促不规律+喉结频繁滚动 | `在2m范围内来回踱步每4-5步调头一次+手指反复在裤缝上摩挲+眼神不断扫视四周不聚焦+嘴角不自主抽动+喉结频繁滚动+步速时快时慢+偶尔停下1-2秒盯着地面手指在腿侧快速敲击+然后继续踱步` |
| **悲伤** | 缓慢移动、贴着墙/扶着物走、身体沉重、下沉（蹲/坐/靠） | 眼眶泛红+嘴角下垂+呼吸带哽咽+肩膀下沉+身体不自主颤抖 | `缓慢沿墙移动+手指轻轻划过墙面+步伐沉重每一步约1.5秒+低头+肩膀下沉+走到窗口停下+额头靠向窗玻璃+玻璃起雾+眼眶泛红+嘴角下垂+呼吸带哽咽不规律+肩膀微颤` |
| **恐惧** | 后退、躲藏、背靠掩体、身体压缩占据最小空间 | 瞳孔放大+嘴唇颤抖+呼吸颤抖吸气抖动+身体不自主颤抖+手指蜷缩+肌肉紧绷动作僵硬 | `背靠墙壁缓慢横向移动+手掌平贴墙面感知空间+身体尽量压缩占据最小空间+瞳孔放大+嘴唇不受控颤抖+呼吸颤抖吸气抖动+手指蜷缩成爪状+肌肉紧绷动作僵硬+移动到角落蹲下把自己缩成一团` |
| **决断** | 从静止突然移动、方向确定不犹豫、不回头 | 眼神凝视锁定目标+咬牙+呼吸平稳刻意控制+脊背挺直+握拳 | `原本静止站立约3秒+突然转身迈步方向确定不犹豫+步速1.5m/s恒定+脊背挺直+眼神凝视前方锁定目标+咬牙+握拳+不回头看+走到门前不停顿直接推门而出` |
| **亲密/温柔** | 靠近对方、缩小距离、蹲下与对方平视、并肩同行 | 眼神温暖聚焦+微笑（嘴角自然上扬）+呼吸平稳放松+手指轻触对方+身体放松前倾 | `走向坐着的B+距离缩至0.5m+弯腰蹲下与B平视+眼神温暖聚焦B的双眼+嘴角自然上扬+右手手指轻轻碰触B的手臂+停留2秒后收手+身体放松前倾` |
| **对峙/威胁** | 正面逼近、缩减距离、身体前倾增加压迫、挡在对方路径上 | 眼神凝视长时间不眨眼+面无表情冷脸+呼吸平稳刻意压低+身体僵硬+脊背挺直 | `A向B正面逼近+距离从2m缩至0.8m+身体前倾15°+脊背挺直+眼神凝视B不眨眼+面无表情冷脸+呼吸刻意压低平稳+挡住B的去路+B后退一步后A再逼近一步` |

**使用规则**：Agent 在确定角色的核心情绪后，必须同时从本文档选取调度模式，从 `表演细节参考库.md` 选取表演细节，两者融合嵌入同一镜头描述。不可只写调度不写表演，也不可只写表演不写调度。

## 一、核心原则

**站桩的三大根源**：
1. 只描述了表情和台词，没有描述身体在空间中的位移
2. 角色一直在画面同一位置不动
3. 角色间的距离/朝向始终不变

**对抗原则**：每个镜头中的每个角色，至少要有一个**空间变化**——位移、朝向变化、高度变化、或与其他角色的距离变化。至少一个。

## 二、单人调度模式（6种基础走位）

### 1. 直线行进（Walk Through）

**描述要素**：方向（左/右/前/后）+ 速度（步速m/s）+ 起止位置在画面中的占比变化。

| 走向 | 视觉含义 | 嵌入描述示例 |
|------|---------|-------------|
| 从左向右走 | 前进、未来、积极 | `角色从画面左侧入画+匀速步速1.2m/s向右行进+从占画面左1/5走到右1/3+背景从右向左流动` |
| 从右向左走 | 回归、过去、消极抵抗 | `角色从画面右侧入画+缓步步速0.8m/s向左行进+从占画面右1/4走到左1/3` |
| 向镜头走来 | 迎击、坦诚、对峙 | `角色从远景向镜头迎面走来+步速1.5m/s+从占画面竖向8%走到30%+面部从模糊到清晰` |
| 背向镜头远去 | 离别、放弃、孤独 | `角色背向镜头向画面深处走去+步速1.0m/s+从占画面竖向25%缩小到5%+身影渐小消融在远景中` |
| 对角线行进 | 动感、逃离、追寻 | `角色从画面左下向右上对角行进+步速2.0m/s+从占画面5%走到15%+身后扬起微尘` |

**关键**：不能只写"角色走过去"。必须标注起止位置、步速、画面占比变化。

### 2. 静止→运动（启动走位）

**描述要素**：静止姿态→启动瞬间的身体力学→行走建立。

```
角色原本静止站立+右脚先向后撤半步(启动预备)+身体重心前倾约10°+左脚迈出第一步+步速从0加速到1.2m/s用两步完成+手臂开始摆动配合步频+衣摆因加速度向后轻飘。行走从启动到匀速用2秒完成。
```

### 3. 运动→静止（停下走位）

**描述要素**：减速→最后一步的惯性处理→静止后的微调。

```
角色快步行走中步速1.5m/s+在预定位置前两步开始减速+最后一步右脚落地时身体因惯性轻微前倾约5°+随即重心回落至直立+双手因惯性继续向前摆动了约10cm才收回+停下后肩膀微微起伏(呼吸调整)+静止后的2秒内身体还有极细微的前后摇摆(人类站立的自然微调)
```

### 4. 转身

| 转身类型 | 身体力学 | 嵌入描述 |
|---------|---------|---------|
| 日常转身 | 先转头→肩跟随→腰旋转→脚调整 | `先向右侧转头约30°+右肩跟随旋转+腰部转动+左脚小步外旋调整站位+整个转身用1.5秒完成` |
| 警觉快速转身 | 头先猛转→身体几乎同时跟上→惯性使衣摆甩动 | `头部猛然向右旋转约60°用时0.3s+身体紧随旋转+衣摆因惯性向左侧甩出弧形轨迹+右脚后撤半步稳定重心` |
| 缓慢沉重转身 | 全身缓慢同步旋转+无分层 | `全身如厚重物体般缓慢向右旋转约45°+头与躯干几乎同速+用时3秒完成+旋转过程中肩膀始终下垂` |

### 5. 坐下/起身

| 动作 | 身体力学 |
|------|---------|
| 坐下 | 走近椅子→转身背对椅子→一手扶椅背/扶手(可选)→屈膝下蹲→臀部触椅面→身体重量从腿转移到椅面→上半身后靠+手从扶手上自然滑落到大腿。整个过程2-3秒 |
| 起身 | 身体前倾重心移到脚掌→双手按压扶手或大腿借力→腿部发力伸直→身体从屈曲到直立→站稳后微调整衣襟。整个过程1.5-2.5秒 |
| 坐下时的微动作 | 坐下后不会完全静止——挪动臀部调整位置1-2次、翘二郎腿或并膝、手从扶手移到桌面 |

### 6. 蹲下/弯腰

| 动作 | 身体力学 | 视觉重点 |
|------|---------|---------|
| 蹲下 | 双脚分开略宽于肩+屈膝下蹲+臀部向脚跟方向下降+一手可扶地面/膝盖保持平衡+蹲稳后身体微前倾 | 膝盖弯曲角度从180°→约45°→约20°。衣摆拖地。重心降低约60-80cm |
| 弯腰拾物 | 腰部折弯约90°+膝盖微屈(保护下背)+一手伸向目标物+另一手自然垂或扶膝+拾起后腰逐节伸直 | 衣物因弯腰在背部堆积褶皱。头发向前垂落 |

## 三、双人调度模式（7种关系走位）

### 1. 对话行进（Walk and Talk）

**描述要素**：两人的空间关系、步速同步、朝向关系、谁主导方向。

```
A和B并肩向画面右侧行进+A在左B在右+两人间距约0.6m+步速同步约1.0m/s+A略领先B半个身位(约0.3m)+B边走边转向A说话时身体转约30°面朝A+B转回前方后A转头看B约1秒后转回+B说话时手配合话语做小幅手势+A双手插兜+步速在B说话时微降至0.8m/s。不要两人始终平行+不要两人一直看前方不看对方+不要两人步伐完全同步像阅兵。
```

### 2. 对峙（Face Off）

**描述要素**：距离、朝向、身体姿态、距离的微小变化。

| 对峙阶段 | 走位 | 含义 |
|---------|------|------|
| 初始 | 两人面对面距离约2m+正面朝向彼此+身体姿态紧张(双肩微耸/手握拳) | 威胁在酝酿 |
| 升级 | A向前迈一步距离缩至约1.2m+B不退或微退半步+两人身体前倾角度增大 | A在推进，B在犹豫 |
| 爆发前 | 距离缩至约0.5m+面部几乎贴近+一人或两人身体微侧(准备动手/防御) | 暴力一触即发 |
| 化解 | 一人后退一步距离回到约1.5m+身体前倾角度减小+双手从握拳变为摊开 | 降级 |
| 突破 | 一人突然转身背对另一人走开+另一人原地不动2秒后追上去 | 打破对峙格局 |

**关键**：对峙的张力来自距离的微变化。不要两人始终距离2m面对面不动。每次距离变化都是一次信息释放。

### 3. 追随/带领

```
A在前B在后+间距约1.5-2m+A不看B只顾往前走+B的目光始终锁定A的后背+B的步伐跟随A的步伐但不完全同步(B会因观察A而偶有停顿)+A穿过门时B加速跟上+上下楼梯时间距缩小至约1m(安全本能)。不要在狭长通道两人始终平行+不要间距始终保持不变。
```

### 4. 擦肩而过（Passing）

**描述要素**：相对速度、眼神接触时机、距离最近点的微反应。

```
A从左向右行走+B从右向左行走+两人相向而行+在相距约3m时其中一人(或两人)抬头看对方一眼+相距约1m时一方微侧身让出空间+擦肩瞬间最近距离约0.3m+擦肩后A继续前行+B在擦肩后约1秒转头回看A的背影约0.5秒+然后转回去继续走。擦肩瞬间可用慢动作强调——不是整个镜头慢动作，仅擦肩那0.5秒减速。
```

### 5. 一方主动接近一方回避

```
A向B走去+B察觉到A靠近身体微向后倾+B的脚尖从朝向A转向朝外(准备逃离的信号)+A继续靠近到约1m时B后退一步+A停住+B也停住+两人之间的张力距离由B控制+A再靠近一步试探+B没有后退(关系转折点)。B的身体朝向从正面→侧面→背面是逐步逃离的视觉信号。
```

### 6. 协同动作（共同完成一件事）

**描述要素**：分工、时机、身体协调。

```
A和B一起抬起一张桌子+A站在桌左B站在桌右+两人同时屈膝下蹲+A喊"一、二、三"+第三声时两人同时发力站起+桌子离地瞬间B的一侧先翘起(发力不均)→B调整重心桌子回平+两人抬着桌子缓慢横向移动+步速约0.4m/s极慢+每走一步桌子轻微晃动+A走在前B跟在后转向通过门框时桌子倾斜约30°。协同动作的视觉真实感来自不完美——不要两人动作完全同步。
```

### 7. 权力距离的动态变化

这是"谁控制谁"的物理表达。

| 时间点 | A的行为 | B的行为 | 谁在控制 |
|--------|--------|--------|---------|
| 0s | 站在B面前距离1.5m | 坐在椅子上 | A（俯视优势） |
| 2s | 蹲下与B平视 | 仍然坐着 | 平等化 |
| 4s | 手放在B的椅子扶手上 | 身体向后靠 | A推进 |
| 6s | 站起来转身走开 | 站起来跟上去 | B失去控制权被迫追随 |

## 四、三人及群像调度

### 三角形走位（三人）

三角形是三人调度最稳定的基础形态。通过改变三角形的形状（正三角/倒三角/拉长/压扁）来表达三人关系。

| 三角形态 | 含义 | 走位方式 |
|---------|------|---------|
| 正三角（顶点在上） | 一人主导、两人平等 | 主导者站在三角顶点位置，另外两人各占底角。主导者发言时身体前倾，底角两人交换眼神 |
| 倒三角（顶点在下） | 一人被审视、两人同盟 | 被审视者站在下方顶点，同盟两人在上方两角。同盟两人不时交换眼神确认 |
| 旋转三角 | 权力在三人间轮转 | 三人缓慢绕圈踱步，每次停下来时面对的人不同。谁面对摄影机谁暂时掌权 |

### 群像分层站位

群像≠一堆人站在一起。需要制造视觉层次。

| 层次 | 站姿/位置 | 作用 |
|------|---------|------|
| 前景层 | 1-2人，坐或蹲，模糊或剪影 | 增加深度、暗示被排除在核心圈外的人 |
| 中景层（核心） | 主要角色，站姿，面向彼此或摄影机 | 观众的焦点 |
| 后景层 | 2-3人，站姿，半虚化 | 次要角色、权力旁观者 |
| 边缘层 | 靠墙/门框/窗边站的人 | 可随时介入或退出的角色 |

**关键**：群像中每个人的站姿朝向不能都一样。有人面向核心、有人面向外侧、有人半侧——用身体朝向表达谁是核心谁是边缘。

## 五、空间中的情绪走位

### 角色用空间表达情绪

| 情绪 | 空间行为 | 嵌入描述示例 |
|------|---------|-------------|
| 愤怒 | 大步快速移动、突然改变方向、踢/推沿途物体 | `大步快速穿过房间+步速2.0m/s+中途突然转向踢翻垃圾桶+脚尖碰翻桶后未停继续走+手臂大幅摆动+衣摆因速度甩起` |
| 焦虑 | 来回踱步、无法保持静止、动作重复、方向频繁改变 | `在2m范围内来回踱步+每4-5步调头一次+双手反复插兜又抽出+步速不稳时快时慢+目光不聚焦来回扫视+偶尔停下1-2秒看着地面然后继续踱步` |
| 悲伤 | 缓慢移动、身体沉重、贴着墙/扶着物体走 | `缓慢沿墙移动+手指轻轻划过墙面+步伐沉重每一步约1.5秒+低头+肩膀下垂+走到窗口停下+额头靠向窗玻璃+玻璃起雾` |
| 恐惧 | 后退、躲藏、快速扫视、身体紧贴掩体 | `背靠墙壁缓慢横向移动+手掌平贴墙面感知空间+每移动一步先探头快速扫视+移动到角落时身体尽量压缩占据最小空间+呼吸急促但尽量压低声音` |
| 决断 | 从静止到突然移动+位移方向坚定不犹豫 | `原本静止站立约3秒+突然转身迈步+方向确定不犹豫+步速1.5m/s恒定+不回头看+手部不做多余动作+走到门前不停顿直接推门而出` |
| 犹豫 | 走向目标→中途停住→退半步→再走向另一方向 | `走向书桌→距桌约1m时停住→脚尖转向另一个方向→退半步→又转回→最终没有走向任何一个方向而是站在原地` |

## 六、走位层级（垂直空间调度）

角色不仅可以在水平面移动，还可以通过高低差表现关系。

| 高低关系 | 视觉含义 | 调度方式 |
|---------|---------|---------|
| A站立+B坐/蹲 | A强势 | A走向坐着的B时弯腰或蹲下=平等化 |
| A在楼梯上方+B在下方 | A掌控 | B向上走拉近距离=挑战A |
| A躺在地上+B站立俯视 | B完全优势 | A视角中B的头顶和天花板 = 压迫感 |
| A在阳台/高处+B在地面 | A抽离/俯视/B渺小 | 两人隔空对话——距离用声音而非走位拉近 |
| 两人同时上楼梯 | 平等/同行 | A在前B在后、或并肩。谁在前谁掌控节奏 |

**关键**：走位不仅是水平面上的X/Y轴移动，Z轴（高度变化）是表达权力关系的强手段。

## 七、入画/出画的调度语义

入画和出画不只是"从画面边缘走进来/走出去"。方式决定含义。

| 入画方式 | 视觉 | 语义 |
|---------|------|------|
| 从左侧入画 | 角色从画面左边缘进入 | 进入、开始、"向前" |
| 从右侧入画 | 角色从画面右边缘进入 | 回归、打断、外来者 |
| 从下方入画（坐/蹲起身） | 角色原本在画框下缘之外（蹲/坐）→站起进入画面 | 突然出现、潜伏→行动、被低估→证明自己 |
| 从摄影机后方入画 | 角色从镜头后方走入画面 | 与观众同侧、同盟者、主角感 |
| 从后方深处入画 | 角色从远景模糊处走来 | 从过去走来、回忆、宿命 |
| 被遮挡后出现（遮挡揭示） | 角色被前景物体挡住→移动后露出 | 揭示、隐藏→曝光、悬念释放 |

| 出画方式 | 视觉 | 语义 |
|---------|------|------|
| 向右侧出画 | 角色走出画面右边缘 | 离去、结束、"向前走" |
| 向左侧出画 | 角色走出画面左边缘 | 回归、退场、被放逐 |
| 向画面深处走出 | 角色走向远景变小消失 | 永别、时间流逝、渺小化 |
| 被遮挡后消失 | 角色走进前景遮挡物后方不再出现 | 神秘消失、悬疑、不可知 |
| 向下方出画（蹲/跌倒） | 角色突然蹲下或跌倒出画 | 突发的弱势、被击倒 |

## 八、调度与摄影机的配合

| 调度类型 | 摄影机策略 | 效果 |
|---------|-----------|------|
| 角色向镜头走来 | 固定机位 or dolly 缓慢后退 | 保持角色在画面中的占比。固定机位=角色越来越大(压迫感)；dolly后退=保持中景(客观感) |
| 角色横向移动 | 斯坦尼康/手持跟拍+速度同步 | 背景流动、角色在画面中位置不变 |
| 角色环绕另一角色 | 固定机位 recording 两人的空间变化 | 最客观的记录方式，让调度本身说话 |
| 角色从A点走到B点 | 固定机位+深景深 | 观众看角色在整个空间中的位移全貌 |
| 角色做快速身体动作 | 手持微抖+跟住动作中心 | 临场感和紧张感 |

## 九、强制嵌入要求

**每个镜头中，每个有动作的角色描述必须包含**：

```
角色走位 = 位移方向 + 步速m/s + 起止位置(画面占比) + 身体朝向变化 + 与其他角色的距离变化(如有)
```

**单角色示例**：
```
角色从画面左侧入画+匀速步速1.2m/s向右行进+从占画面左1/5走到右1/3+身体正面向右略微前倾5°+背景从右向左流动+右手自然摆动+左手插兜+走了5步后速度微降至0.9m/s。
```

**双角色示例**：
```
A和B并肩向画面右侧行进+A在左B在右+间距0.6m+步速同步1.0m/s+A略领先B半个身位(0.3m)+B边走边转向A身体转约30°面朝A说话+B转回前方后A转头看B约1s+两人间距在B说话时自然拉近至0.4m(身体语言中的亲密)+B说完后间距回到0.6m。
```

**群像示例**：
```
前景虚化的一人蹲在画面右下角(占画面1/8)+中景三人呈三角形站立(核心角色居中偏左占画面1/5+左侧角色半侧面向核心+右侧角色正面朝向画外)+远景一人靠墙站(占画面1/15虚化)+核心角色向前迈一步距离左角色从1.5m缩至1.0m+左角色身体微向后倾+右角色交叉双臂。
```

## 十、站桩自查清单

生成每个镜头后，检查以下问题：

```
□ 镜头中每个角色是否有≥1种空间变化（位移/朝向变化/高度变化/与别人的距离变化）？
□ 如果有对话，角色是否只是面对面站着说而不移动？
□ 角色在镜头中是否始终在同一画面位置？如果是，情绪需要它静止吗？
□ 双人/多人的距离是否有变化？还是始终保持固定间距？
□ 入画和出画是否有语义内涵，还是仅仅因为需要进出？
□ 角色的步速是否被标注？是否匹配情绪？
```

**铁律**：如果以上任何一条答案为"否"且没有合理理由 → 这个镜头中的角色调度不合格，必须修正。

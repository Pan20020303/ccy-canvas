# 构图设计参考库 · 电影感构图法则

> **用途**：每个镜头生成前，Agent 必须为镜头确定具体的构图方式。仅说"中景"不够——要说清画面里的元素怎么排列、为什么这样排。
> 
> **与其他 reference 的关系**：本文档聚焦于"画面内元素的排列"（frame composition）。机位角度见 `机位情绪决策参考库.md`，景别梯度见 `分镜设计知识库_十三讲.md` §8，运镜见 `超详细运镜规格参考库.md`。

## 一、九类核心构图 + 适用场景 + 实战要点

| # | 构图类型 | 核心效果 | 导演级用法 | 禁忌与常见错误 |
|---|---------|---------|-----------|--------------|
| 1 | **三分法** | 自然、舒适、符合人眼视觉习惯 | 主体放在左/右1/3交点，双眼放在上1/3线 | 不要死守——每场景至少有一次故意打破它。人物对话始终放在同一侧 = 视觉单调 |
| 2 | **对称构图** | 庄严、仪式感、稳定、权力 | Wes Anderson式 absolute symmetry / Stanley Kubrick 式 single-point perspective | 过度使用 = 做作。连续两个对称镜头 = 视觉疲劳。必须搭配 locked-off 固定机位 |
| 3 | **框中框** | 聚焦、窥视感、隔阂、被限制 | 门框/窗框/镜子/栏杆/拱门后拍摄。多框嵌套 = 窥视感翻倍 | 框不能比主体更亮或更抢眼。多个框同时出现需区分主次 |
| 4 | **引导线** | 纵深、命运感、导向、旅程感 | 道路/铁轨/走廊/栏杆/河流/光线引向主体。线的终点必须有人或物 | 引导线终点空着 = 观众被"丢在路上"。线条从角落出发最有力量（左下→右上） |
| 5 | **负空间留白** | 孤独、未来感、渺小、自由 | 角色偏一侧（通常1/3处），大面积空白朝向视线方向 | 留白方向不对 = 角色被"推"出画面。空白面积超过60% = 极简美学需要配光 |
| 6 | **三角形构图** | 稳定、力量、群体关系 | 三人站位形成三角 / 建筑穹顶三角 / 单人四肢形成的三角（大尺度仰拍） | 倒三角 = 不稳定（用于表现失衡） |
| 7 | **对角线构图** | 动感、不安、速度 | 角色或关键元素沿画面对角线分布。加速感强烈 | 静态场景 + 对角线 = 不协调 |
| 8 | **中央构图** | 直接、对峙、孤立、仪式 | 主体精确居中，左右对称。适合情绪高峰/对峙/海报式定格 | 居中 + 静止 + 无仪式感 = 视觉死亡 |
| 9 | **开放构图** | 自由、走出画框、未完成 | 主体部分在画框外/走向画框外/视线通向画框外 | 需要前一个镜头建立空间关系，否则观众困惑 |

## 二、线条语言

线条是构图最基本的视觉语法，不同方向的线条自带情绪。

| 线条方向 | 情绪 | 实战应用 |
|---------|------|---------|
| **水平线** | 平静、稳定、广阔、死亡 | 海平面、地平线、躺卧的人。水平 + 低机位 = 大地感 |
| **垂直线** | 庄严、高大、力量、上升 | 柱子、站立的人、高楼。垂直 + 仰拍 = 英雄感/压迫感 |
| **对角线** | 动感、不安、速度、冲突 | 楼梯、倾斜的栏杆、奔跑的人。对角线从左上→右下 = 坠落感 |
| **曲线/S线** | 优雅、柔和、流动、神秘 | 河流、小路、人体曲线。S线引向主体 = 最优雅的引导线 |
| **锯齿线** | 紧张、冲突、破碎、危险 | 破碎的玻璃边缘、断裂的建筑物轮廓 |
| **汇聚线** | 纵深、集中、宿命 | 走廊尽头、隧道、铁轨。汇聚点放在画面中心 = 最强行进感 |

## 三、画幅比例与构图策略

不同画幅比例改变构图的"呼吸空间"。

| 画幅 | 比例 | 构图策略 | 代表影片 |
|------|------|---------|---------|
| **IMAX / 65mm** | 1.43:1 / 1.90:1 | 大画幅意味着更多的纵向空间——主体可以放在偏上或偏下，用大面积的天空或地面做情绪衬托 | Interstellar, Dunkirk |
| **变形宽银幕** | 2.39:1 | 横向空间充裕——适合双人对峙（各占一半）、大远景、水平移动。纵向紧凑——拍人物时注意头顶和脚下的呼吸空间 | Blade Runner 2049, Mad Max Fury Road |
| **标准宽银幕** | 1.85:1 | 经典电影比例——适合三分法构图 | Jurassic Park, The Shawshank Redemption |
| **16:9 / 电视** | 1.78:1 | 日常叙事比例——中心构图和三分法为主 | 绝大多数电视剧 |
| **4:3 / 学院比例** | 1.33:1 | 方形感强烈——对称构图和中央构图效果最佳。人物肖像感重 | The Grand Budapest Hotel, Ida |
| **9:16 / 竖屏** | 0.56:1 | 纵向空间充裕——适合全身人像、仰望、坠落。三分法纵向分割 | 手机短视频 |

## 四、深度层次（想拍出电影感，每一帧都要有三层空间）

| 层次 | 距摄影机 | 功能 | 实例 |
|------|---------|------|------|
| **前景 Foreground** | 0-1.5m | 制造窥视感、增加空间深度、引导视线 | 虚化门框、过肩的肩头、飘过的旗帜、栅栏、雨滴在玻璃上 |
| **中景 Midground** | 1.5-6m | 主体所在层——观众的焦点战场 | 角色本身 |
| **远景 Background** | 6m+ | 交代环境、时代、空间尺度；叙事注脚 | 窗外城市天际线、远处走过的路人、墙上的海报 |

**层次组合规则**：
- 人物特写：前景极致虚化（f/1.4-2.0）+ 中景面部 + 远景完全虚化
- 人物中景：前景轻虚化 + 中景人物 + 远景半虚化（可辨认内容）
- 全景：前景清晰（如有）+ 中景人物 + 远景清晰（深景深 f/8-11）
- 至少两层（远景可省略），三层最佳

## 五、权力关系构图（谁在上谁在下、谁大谁小）

画面内的空间分配就是权力分配。

| 权力关系 | 构图方式 | 示例 |
|---------|---------|------|
| **A 控制 B** | A 占据画面2/3，B 在1/3角落 | 老板训话 |
| **A 压倒 B** | A 在画面上方（仰拍），B 在下方（俯拍） | 英雄俯瞰反派 |
| **A 与 B 平等** | 各占画面一半，对称正反打 | 对手谈判 |
| **A 孤立于群体** | A 偏一侧，群体在另一侧，负空间隔开 | 被排挤的人 |
| **A 被环境压制** | A 极小在画面偏下，巨大建筑/自然占据80%+ | 人在废墟中 |
| **A 与 B 亲密** | 距离接近（头距<30cm），框内框在一起 | 情侣、家人 |

## 六、动感构图（镜头运动中的构图变化）

构图不是静态的——好的构图在镜头运动中会"演化"。

| 运动方式 | 构图变化 | 叙事意义 |
|---------|---------|---------|
| **Dolly 推进** | 从大环境 → 聚焦人物 → 极近特写 | 外部观察→窥视内心 |
| **Dolly 拉远** | 从人物→环境→人物渺小化 | 揭示真相、无力感 |
| **横向跟拍** | 人物保持画面1/3位置不变，背景流动 | 陪伴、旅程 |
| **摇镜（Pan）** | 从一个构图摇到另一个构图 | 揭示新的空间信息 |
| **斯坦尼康环绕** | 人物居中不变，360°展示环境 | 人物命运与空间的关系 |

**运动中的构图铁律**：
- 运动过程中主体的画面占比和位置尽量不变
- 运动起幅和落幅各定格至少 1 秒（让观众"着陆"）
- 运动轨迹必须有叙事动机，不为炫技而动

## 七、情绪→构图速查（按情绪维度）

| 情绪 | 最佳构图 | 辅助元素 | 禁用构图 |
|------|---------|---------|---------|
| **孤独/渺小** | 负空间 + 角色偏下1/3 + 远景 | 大面积天空/荒原 | 对称、特写 |
| **权力/威严** | 对称 + 仰拍 + 中央构图 | 低角度、深景深 | 负空间 |
| **亲密/温柔** | 三分法 + 3/4侧面 + 中近景 | 浅景深、暖光 | 对称、仰拍 |
| **紧张/不安** | 框中框 + 前景遮挡 + 荷兰角 | 大片阴影、不对称 | 开阔构图 |
| **自由/释放** | 开放构图 + 角色偏上 + 留白向外 | 天空、海面、门打开 | 框中框 |
| **困惑/迷失** | 引导线指向空处 + 角色偏下 | 雾、镜面反射、迷宫 | 对称 |
| **对峙/冲突** | 各占一半 + 中央分割线 + 正反打 | 冷暖色对撞 | 同侧三分法 |
| **恐惧/惊悚** | 前景大面积遮挡 + 角色在远景被窥视 | 暗角、浅景深、微光 | 开放开阔 |
| **庄严/神圣** | 对称 + 仰拍 + 低速摇镜 | 顶光/丁达尔光 | 手持晃动 |

## 八、前景遮挡参数表

| 遮挡类型 | 透明度 | 虚化程度 | 动态/静态 | 适用 |
|---------|--------|---------|----------|------|
| 门框/窗框 | 不透明 | 清晰 | 静态 | 偷窥、权力隔阂 |
| 虚化肩膀(OTS) | 不透明 | 70%虚化 f/2.8 | 静态 | 对话带入感 |
| 半透明玻璃/纱帘 | 60%透 | 浅景深虚焦 | 微动 | 浪漫/暧昧/隔阂 |
| 叶片/花草 | 40-60%透 | 中景深 f/5.6 | 随风微动 | 户外自然场景 |
| 车辆/人群 | 不透明 | 动态虚化 | 快速流动 | 城市街拍、追逐 |
| 雨滴/水珠 | 50-70%透 | 极度虚化 | 缓慢滑落 | 车内/窗后视角 |
| 铁栅栏/锁链 | 不透明 | 中度清晰 | 静态/微晃 | 囚禁、被限制 |
| 烟雾/雾气 | 30%透 | — | 缓慢翻滚 | 神秘、不安、迷幻 |

## 九、构图雷区（14 条反面教材 · 触之即死）

| # | 雷区 | 严重度 | 详细描述 |
|---|------|--------|---------|
| 1 | **头顶长物** | 🔴 | 灯柱/树枝/栏杆从角色头顶"长出来"。解决方法：移半步 |
| 2 | **割关节** | 🔴 | 画框边缘切在脖子/手腕/脚踝/膝盖。切在关节 = 截肢感 |
| 3 | **背景抢戏** | 🔴 | 霓虹灯/动态人群/高饱和色块在主体身后比主体更醒目 |
| 4 | **视线撞墙** | 🔴 | 人物看向画面外但那一侧没有留白——像被堵在墙角 |
| 5 | **死中央+静止** | 🟡 | 居中 + 无运动 + 无仪式感 = 画面死亡。要么动起来，要么给一个仪式感的理由 |
| 6 | **贴边** | 🟡 | 角色挤在画框边缘，离边缘不到画幅5%。需要至少10%安全距离 |
| 7 | **切发际线** | 🔴 | 特写时上缘切在发际线而非头顶上方5-10% |
| 8 | **缺鼻前空间** | 🔴 | 3/4角度/侧面拍摄时鼻子顶到画框边缘 |
| 9 | **水平线倾斜** | 🟡 | 地平线/海平面无缘无故倾斜。除非是荷兰角 |
| 10 | **一文字排开** | 🟡 | 多人对话所有人都面对摄影机排成一字。应分层站位 |
| 11 | **眼睛同高** | 🟡 | 群像戏所有人眼睛在同一水平线。应利用身高/站位制造视觉层次 |
| 12 | **留白方向错误** | 🟡 | 角色面右，右边却裁切更紧——观众感到"被推着走" |
| 13 | **切手/切脚** | 🟡 | 中景/全景切在手腕/脚踝。要么全手全脚，要么切在大臂/大腿 |
| 14 | **主体比背景暗** | 🔴 | 逆光不当——主体曝光不足而背景过曝。必须用补光或调整机位 |

## 十、嵌入格式要求

每个镜头的构图描述必须明确包含：

```
构图 = 主构图类型 + 主体在画面中的精确位置 + 前景遮挡（有/无+类型+占比） + 预留方向（视线/运动方向的留白占比） + 深度层次（几层空间）
```

完整示例：

```
【镜头1：父亲背影】| 0:00-0:05
负空间构图 + 父亲占据画面左下1/3交点 + 前景无遮挡 + 面朝右侧窗外留白占画面右半部55% + 中景人物层清晰+远景窗外田野层虚化 + dolly极慢推镜 + ...
```

```
【镜头2：对峙】| 0:05-0:08
中央分割线构图 + 两人各占画面左右各半 + 前景无遮挡 + 视线正面交锋无额外留白方向 + 中景双人层次清晰+远景墙壁深褐虚化 + ...
```

```
【镜头3：偷窥】| 0:08-0:11
框中框构图 + 通过门缝窥视室内 + 前景门框占据画面左右和上缘70%虚化 + 主体在框中偏左下 + 视线向右上留白20% + ...
```

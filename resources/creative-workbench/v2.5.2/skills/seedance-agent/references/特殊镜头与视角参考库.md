# 特殊镜头与视角参考库

> **来源**：影视制作中的特殊镜头语言和视角设计
> **用途**：为 Seedance 提示词提供特殊镜头和视角的技术规格描述

---

## 使用说明

本文档包含两大类特殊镜头：
1. **特殊镜头类型**：鱼眼镜头、变形镜头、微距镜头等
2. **特殊视角类型**：窥视视角、狙击视角、望远镜视角、监控视角等

## 一、特殊镜头类型

### 1. 鱼眼镜头（Fisheye Lens）

**视觉特征**：
- 极度广角（180°视野）
- 画面边缘严重畸变
- 直线变成弧线
- 中心相对清晰，边缘拉伸

**适用场景**：
- 极端空间感
- 幽闭恐惧
- 迷幻场景
- 极限运动

**技术规格模板**：
```
鱼眼镜头 + 180度超广角视野 + 画面边缘严重桶形畸变 + 直线弯曲成弧线 + 中心清晰边缘拉伸 + 极度夸张的空间透视 + {场景描述}
```

**嵌入描述示例**：
```
【镜头1：幽闭空间】| 0:00-0:04
鱼眼镜头 + 180度超广角视野 + 固定镜头 + 狭小房间 + 画面边缘严重桶形畸变 + 墙壁弯曲成弧线 + 人物在画面中心显得孤立 + 四周空间被极度拉伸 + 营造幽闭恐惧感 + NOT subtitles + NOT BGM
```

- 水平镜头光晕（horizontal flare）
- 浅景深
- 电影感强烈

**适用场景**：
- 电影级质感
- 史诗场景
- 预告片
- 高级感画面

- 主体在画面中心
- 偷窥感、不安感

- 悬疑片
- 惊悚片
- 偷窥场景
- 隐藏视角


## 四、使用指南

### 如何选择特殊镜头/视角

1. **根据场景需求**：
   - 需要极端空间感 → 鱼眼镜头
   - 需要电影感 → 变形镜头
   - 需要偷窥感 → 窥视视角
   - 需要紧张感 → 狙击视角

2. **根据情绪需求**：
   - 不安、失衡 → 荷兰角
   - 惊觉、恐惧 → 希区柯克变焦
   - 史诗、英雄 → 轨道环绕
   - 动感、快节奏 → 鞭摇镜

3. **根据叙事需求**：
   - 展示细节 → 微距镜头
   - 压缩空间 → 长焦镜头
   - 场景转换 → 鞭摇镜
   - 时间静止 → 子弹时间

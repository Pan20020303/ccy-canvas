# 智能體創作工作台 · 2.3

同一個包裡包含一個選單入口和五個可獨立使用的 Skill。

## 開始

安裝後說「打開創作工作台」，或使用 `$ai-film-workbench`，即可選擇：

1. 豪哥分鏡：原劇本 → 適合 AI 理解的劇本。
2. 鹹魚分鏡：AI 劇本／已有劇本 → 分鏡。
3. 豪哥導演：核對劇本與分鏡 → 規劃資產 → gpt製圖編寫提示詞。
4. gpt製圖：單獨寫／修改圖像提示詞。
5. 打鬥 Skill（SD-05 打鬥導演）：單獨創作或優化打鬥片段提示詞。
6. 完整流程：按 1 → 2 → 3 執行，第 3 步的資產提示詞由第 4 個工具完成，交回導演驗收。

直接說工具名便可單用，不必先開選單。選完整流程時各階段共用成品與狀態，不需要反覆貼同一份劇本。換對話時提供保存的狀態文件和成品即可恢復。

## 安裝與獨立使用

解壓後將 skills 下的六個資料夾放進你的 Skill 目錄。Codex 通常是 ~/.codex/skills；設有 CODEX_HOME 時使用該目錄下的 skills。已有同名 Skill 時先備份再決定是否替換。完整保留各資料夾內的參考庫與腳本。

單用時可只安裝所需工具資料夾。豪哥導演內附 gpt製圖規則，因此單裝也能按同一方法撰寫資產提示詞；同包裝有 gpt-image 時優先讀取它。工作台入口的完整流程需要原有四個工具一併安裝；打鬥選項需要 sd05-fight-director。整包包含全部六個資料夾。

| 工具 | 資料夾／呼叫名稱 |
|---|---|
| 工作台 | ai-film-workbench |
| 豪哥分鏡 | haoge-storyboard |
| 鹹魚分鏡 | seedance-agent |
| 豪哥導演 | haoge-film-director-flex |
| gpt製圖 | gpt-image |
| 打鬥 Skill／SD-05 打鬥導演 | sd05-fight-director |

打鬥選項使用既有 SD-05 打鬥導演，連同感覺映射、衝擊語言與逐段寫法參考庫完整收錄，可單獨安裝。直接說「打鬥 Skill，來一段快狠、有重量的對決」即可使用；需要接回分鏡時再指定場次。原有完整流程不增加必經打鬥步驟。

## 此版本的工作分工

豪哥分鏡預設整理場次級 AI 劇本；鹹魚負責分鏡，尚無資產圖也可先做；豪哥導演檢查劇情與連續性、沿用已完成分鏡和模型，再規劃角色、場景與關鍵道具。gpt製圖依資產任務單寫提示詞，保留身份、畫幅、設計板版式和參考素材职责。

未明確要求直接生圖時先交付資產提示詞。實際圖片／影片生成需要宿主或外部平台提供對應能力，本包不含模型、帳號或額度，也不承諾自動操作外部平台。

## v2.4.1 使用方式更正

自動接力僅為第6個可選選項，並非收到劇本的固定預設。沒有指定工具先給選單，明確選自動完整流程才連續跑完並判斷畫幅。

## v2.5 新增劇本醫生

第7項為「劇本醫生」，可獨立使用。第6項仍是可選自動完整流程，順序更新為劇本醫生→豪哥分鏡→鹹魚分鏡→豪哥導演→gpt製圖整套資產提示詞。劇本醫生使用包內screenwriter，先查平台適配、人物轉變、因果和短劇節奏，不強制改戲。

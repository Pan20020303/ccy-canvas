## 五大表演细节库

### 1. 眼神细节

| 细节 | 描述 | 适用情绪 | 嵌入示例 |
|------|------|---------|---------|
| **聚焦** | 眼神锁定某个目标，瞳孔收缩 | 专注、警觉、发现 | `眼神锁定目标瞳孔收缩` |
| **游移** | 眼神不断移动，无法集中 | 紧张、不安、撒谎 | `眼神游移不断移动` |
| **瞳孔缩放** | 瞳孔突然放大或缩小 | 惊恐、震惊、兴奋 | `瞳孔突然放大` |
| **血丝** | 眼白布满血丝 | 疲惫、愤怒、绝望 | `眼白布满血丝` |
| **泪光** | 眼眶泛红，泪水在眼眶打转 | 悲伤、感动、委屈 | `眼眶泛红泪水打转` |
| **空洞** | 眼神失焦，空洞无神 | 绝望、麻木、创伤 | `眼神失焦空洞无神` |
| **闪避** | 不敢直视，眼神闪躲 | 愧疚、害怕、撒谎 | `不敢直视眼神闪躲` |
| **凝视** | 长时间不眨眼地盯着 | 威胁、挑衅、深情 | `长时间不眨眼凝视` |

### 2. 面部细节

| 细节 | 描述 | 适用情绪 | 嵌入示例 |
|------|------|---------|---------|
| **皱眉** | 眉头紧锁，眉间出现皱纹 | 困惑、担忧、痛苦 | `眉头紧锁眉间皱纹` |
| **咬牙** | 牙关紧咬，下颌肌肉紧绷 | 愤怒、忍耐、决心 | `牙关紧咬下颌紧绷` |
| **嘴角抽动** | 嘴角不自主地抽搐 | 紧张、压抑、崩溃边缘 | `嘴角不自主抽搐` |
| **青筋** | 额头或太阳穴青筋暴起 | 极度愤怒、用力 | `额头青筋暴起` |
| **面无表情** | 完全冷漠，无任何表情 | 冷漠、麻木、杀手 | `完全面无表情冷脸` |
| **微笑崩塌** | 强撑的微笑逐渐消失 | 伪装被识破、绝望 | `强撑微笑逐渐消失` |
| **嘴唇颤抖** | 嘴唇不受控制地颤抖 | 恐惧、悲伤、寒冷 | `嘴唇不受控颤抖` |
| **鼻翼扇动** | 鼻翼快速扇动 | 愤怒、急促呼吸 | `鼻翼快速扇动` |

### 3. 呼吸细节

| 细节 | 描述 | 适用情绪 | 嵌入示例 |
|------|------|---------|---------|
| **急促** | 呼吸频率加快，胸口起伏明显 | 紧张、恐惧、奔跑后 | `呼吸急促胸口起伏` |
| **屏息** | 暂时停止呼吸 | 紧张、专注、躲藏 | `屏住呼吸` |
| **喘息** | 大口喘气，呼吸困难 | 疲惫、受伤、窒息 | `大口喘气呼吸困难` |
| **叹气** | 深深地叹一口气 | 无奈、放弃、释然 | `深深叹一口气` |
| **哽咽** | 呼吸带有哭腔，不规律 | 悲伤、委屈、崩溃 | `呼吸带哭腔不规律` |
| **平稳** | 刻意保持呼吸平稳 | 冷静、控制、伪装 | `刻意保持呼吸平稳` |
| **颤抖** | 呼吸颤抖，吸气时抖动 | 恐惧、寒冷、哭泣后 | `呼吸颤抖吸气抖动` |

## 高级技巧

### 1. 微表情时序

在同一镜头内，表演细节可以有时序变化：

```
【镜头1：情绪转变】| 0:00-0:05
固定镜头 + 特写 + 开始时眼神空洞面无表情 + 2秒后瞳孔突然收缩 + 3秒后眉头紧锁 + 4秒后牙关紧咬 + 5秒时握拳关节发白 + 情绪从麻木转为愤怒 + NOT subtitles + NOT BGM
```

### 2. 对比表演

在对话或对峙场景中，两个角色的表演细节形成对比：

```
【镜头1：对峙】| 0:00-0:03
过肩镜头 + 中近景 + 角色A眼神凝视咬牙握拳 + 角色B眼神闪避嘴唇颤抖身体后退 + 形成强弱对比 + NOT subtitles + NOT BGM
```

### 3. 表演细节与动作联动

表演细节可以与动作设计联动，增强真实感：

```
【镜头1：蓄力攻击】| 0:00-0:04
固定镜头 + 中景 + 角色蓄力 + 眼神凝视瞳孔收缩 + 咬牙青筋暴起 + 呼吸屏息 + 握拳关节发白 + 全身肌肉紧绷 + 蓄力完成瞬间爆发 + NOT subtitles + NOT BGM
```

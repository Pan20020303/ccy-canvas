# 镜头衔接与连续性参考库

> **用途**：确保同一个场景内的镜头之间流畅衔接。聚焦动作连续性、空间一致性、运动方向连贯——这是 AI 视频生成最容易出问题的环节。每个多镜头场景生成后必须用此库验收。
>
> **与其他 reference 的关系**：景别衔接（跳1-2级）见 `分镜设计知识库_十三讲.md` §8。本文档专注景别维度之外的衔接——动作、运动方向、空间位置、视线方向的跨镜连续性。

---

## 一、核心铁律

**没有衔接设计的切镜 = 视觉跳帧。同一个场景、同一个人物，上一镜和下一镜之间必须在至少一个维度上有连续的视觉锚点。**

衔接锚点可以是：
- 动作（切割在动作进行中，下一镜从动作继续）
- 方向（角色运动方向在画面中跨镜一致）
- 空间（角色在画面中的位置跨镜不跳）
- 视线（角色视线方向与下一镜揭示的对象方向一致）
- 声音（前镜声音延续到下一镜 J-cut）

**如果一个切镜在上述五个维度上都没有连续锚点 = 不合规的硬切 = 用户看到的 Homelander 问题。**

---

## 二、动作衔接（Cutting on Action）

### 核心原则

**切在动作进行中，下一镜从动作继续。不要切在两个独立动作的间隙。**

| 做法 | ❌ 错误 | ✅ 正确 |
|------|--------|--------|
| 切点 | 动作完成后切 | 动作进行到 40-70% 时切 |
| 镜1末 | 完整动作结束 | 动作开始但未完 |
| 镜2初 | 完全不同的新动作 | 镜1未完动作的延续 |

**嵌入描述格式**：

```
镜1末：角色开始转身约转45°用时0.3s + 动作未完（转身过程被切）

镜2初：角色继续转身完成剩余45° + 同时... + 接镜1的转身动势
```

### 常见动作衔接实例

| 动作类型 | 镜1末 | 切点 | 镜2初 |
|---------|-------|------|-------|
| 起身 | 双手扶扶手+身体前倾+臀部离椅面2cm | 切在离椅瞬间 | 继续向上站直+重心从腿转移到脚掌 |
| 开门 | 手触门把+转动门把+门开始向内移 | 切在门刚被推开1-2cm | 门继续向内打开+角色跨过门槛 |
| 挥拳 | 右拳后拉+身体转体+拳开始向前加速 | 切在拳加速到最高速的瞬间 | 拳继续向前+迎面击中/被挡住 |
| 坐下 | 走近椅子+转身+屈膝+臀部向椅面降落 | 切在臀部距椅面约5cm | 臀部触椅面+身体重量从腿转移到椅子 |
| 转头 | 头开始向右转约30°+眼神移动比头快 | 切在头转到30-40° | 头继续转完剩余角度+锁定新目标 |
| 飞行/跳跃 | 身体加速上升+衣摆/披风向上飘扬 | 切在上升速度峰值 | 从新角度继续上升+背景从下方流动 |

### 特殊动作的衔接规则

**飞行/悬浮 → 加速移动**（你的 Homelander 案例）：

```
❌ 镜1：悬浮在空中静止 + 镜2：超音速飞过 ← 跳切，没有衔接锚点

✅ 镜1末：身体开始前倾15°+披风向后飘起+面部肌肉开始绷紧+眼部红光亮起+身体周围空气开始扭曲（加速前兆）+动作未完
   切在加速前兆峰值

✅ 镜2初：身体从镜1未完的加速动作中继续+以超音速冲出+身后的音爆云正在形成+披风被速度拉直+背景急速模糊流动
   衔接锚点=加速这一动作本身跨镜连续
```

## 三、运动方向衔接

**同一个角色的运动方向在画面中跨镜不能突然反转。**

### 方向一致性规则

| 运动 | 规则 |
|------|------|
| 水平移动 | 镜1从左向右走 → 镜2不能突然从右向左走（除非看到角色因剧情需要掉头） |
| 垂直移动 | 镜1上升 → 镜2上升或悬浮。镜1上升→镜2突然下降=衔接断裂 |
| 深度移动 | 镜1向画面深处走 → 镜2从画面深处向前走（方向连续）。镜1往深处走→镜2往镜头方向来=方向反转 |

**跨镜方向锚定格式**：

```
镜1：角色从左向右行走+步速1.2m/s+背景从右向左流动

镜2：（机位改变但运动方向在画面中保持一致）角色继续向右行进+步速1.2m/s+从侧面新角度拍摄+背景流动方向与镜1一致
```

### 方向改变的合法性

只有以下情况方向改变是合法的：
- 我们看到角色转身/掉头（整个过程在镜头内完成或切在动作中）
- 角色碰到了障碍物被迫转向
- 剧情明确要求角色突然改变方向且给出了原因

## 四、空间位置衔接

**角色在画面中的位置和占屏比例跨镜不能跳。**

### 位置连续性

| 镜1 | 镜2 | 合规？ |
|-----|------|:--:|
| 角色在画面左1/3 | 角色在画面左1/3 | ✅ 位置一致 |
| 角色在画面左1/3 | 角色在画面中央 | ⚠️ 需要动作动机（如角色向前走改变了相对于摄影机的位置） |
| 角色在画面左1/3 | 角色在画面右1/3 | ❌ 除非角色在看到他在两个镜头之间横向移动或机位越过180°线 |
| 角色占画面竖向25% | 角色占画面竖向60%（景别自然变化） | ✅ 景别跳级是合法的 |

**关键**：空间位置跳变必须有"视觉证据"支持——要么角色自己在动，要么摄影机在动。凭空的位置跳变 = 观众感知到的"卡了一下"。

### 占屏比例连续性

同一景别级别的镜头之间，角色的占屏比例应相近。如果镜1中景占40%，跳近景突然占60%是合理的（景别变了）。但如果镜1中景占40%，镜2中景占20%——角色凭空缩小了一半 = 视觉跳帧。

## 五、视线衔接

已在 `人物视线与目光设计参考库.md` 详细展开。本文档仅附核心规则：

- 镜1：角色看画面右方 → 镜2（揭示）：揭示物应出现在画面左方（补足视线方向）
- 两人对话：A看左→B出现在右→B看左回望A→180°轴线不越界

## 六、声音搭桥（J-Cut / L-Cut）

声音是衔接镜头的最强工具——观众的耳朵比眼睛更容易接受连续性。

| 搭桥类型 | 操作 | 效果 |
|---------|------|------|
| **J-Cut** | 镜2的声音在镜1末尾就进入 | 观众还没看到新画面但耳朵已经"在场"了 |
| **L-Cut** | 镜1的声音延续到镜2开始 | 观众还在消化前一个场景的余韵 |
| **声音动作桥** | 一个动作的声音跨镜延续 | 脚步声从镜1到镜2不中断 |

**嵌入格式**：
```
镜1末：... + 伴随J-cut——镜2的人物对话声在镜1最后0.5秒进入
镜2初：... + 镜1的环境声延续0.3秒后淡出（L-cut）
```

## 七、合法跳切 vs 非法断裂

并非所有"跳跃"都是错误——需要区分。

| 类型 | 描述 | 合法性 |
|------|------|--------|
| **王家卫式抽帧** | 故意在动作中间抽掉几帧，产生跳跃感 | ✅ 合法，风格选择 |
| **时间省略** | 角色A点走到B点，省略中间过程 | ✅ 合法（但必须让观众知道省略了） |
| **情绪跳切** | 不同情绪状态间快速切换，中间过程省略 | ✅ 合法（用于惊吓/表情反差） |
| **动作断裂** | 同一场景同一人物，动作从A直接跳到B无过渡 | ❌ 非法断裂 |
| **方向反转** | 运动方向跨镜突然相反无动机 | ❌ 非法断裂 |
| **位置跳变** | 角色在画面中位置凭空跳变 | ❌ 非法断裂 |

**区分原则**：合法跳切是"省略了中间，但观众知道省略了什么"。非法断裂是"观众不知道中间发生了什么，感觉画面卡了一下"。

## 八、AI 模型衔接常见 Bug 与修复

| Bug | 原因 | 修复嵌入描述 |
|-----|------|------------|
| 同人同场景切镜后姿势不对 | AI不理解动作连续性 | `动作未完+继续镜1的动作+从镜1末的动作状态开始` |
| 运动方向反转 | AI没有方向记忆 | `运动方向与镜1一致+从左向右+背景流动方向与镜1相同` |
| 物体位置跳变 | AI不理解空间持续性 | `物体位置与镜1末保持一致+位于画面左1/3地面` |
| 人物突然消失/出现 | AI不理解人物持续性 | `同一人物从镜1进入镜2+服装/发型/体型与镜1严格一致` |
| 光影突然变化 | AI不理解光照连续性 | `光影与镜1一致+光源位置不变+仅因镜头距离增加暗部比例` |
| 衣物/道具位置突变 | AI不理解物体追踪 | `皮箱位置与镜1末一致+位于他右手旁的长椅上+铜锁扣朝向不变` |

## 九、衔接自查清单

生成多镜头场景后，逐对检查：

```
□ 【动作衔接】镜1末的动作是否在镜2初继续？切点是否在动作进行中（40-70%）而非完成后？
□ 【方向衔接】角色运动方向在镜1和镜2中是否一致？如果不一致，是否看到了方向改变的过程？
□ 【位置衔接】角色在画面中的位置和占屏比在镜1和镜2之间是否连续？跳变是否有动机？
□ 【视线衔接】角色的视线方向是否与下一镜的揭示物方向一致（或将在下一镜揭示方向）？
□ 【光影衔接】光源位置/光型/色温在镜1和镜2之间是否一致（除非场景时间有推进）？
□ 【声音衔接】是否需要J-cut或L-cut来加强连贯性？
□ 【物体衔接】画面中的道具/物体位置在跨镜时是否一致？
□ 【人物衔接】人物的服装/发型/年龄/体型/面部特征在跨镜时是否一致？
```

## 十、嵌入格式

每个切镜点必须在描述中明确标注衔接方式：

```
镜1末：
... + 动作未完（转身只完成了40%） + J-cut——镜2的脚步声在镜1最后0.3秒淡入

[硬切，衔接锚点=转身动作]

镜2初：
... + 接镜1的转身继续完成剩余60% + 动作连续+ 运动方向与镜1一致 + 空间位置与镜1末保持一致 + 光影与镜1一致（光源位置不变仅暗部比例增加）
```

**关键**：Agent 必须在镜1末和镜2初都用文字描述衔接锚点。只写镜1不写镜2初 = 衔接信息缺失 = AI 模型自行脑补 = 视觉跳帧。

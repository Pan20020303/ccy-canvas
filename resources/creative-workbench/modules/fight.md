## 第一層 戰鬥類型與機制

保留SD-05依類型選寫法的原則：

| 類型 | 優先刻畫 |
|---|---|
| 拳腳、近身武術 | 重心、步法、接觸部位、格擋承壓、呼吸、短距反擊 |
| 刀劍 | 刃口方向、攻擊弧、兵器接觸、反彈、攻守距離 |
| 棍杖、長槍 | 身體帶動長兵器、掃與刺的差別、握持和轉向、長短距切換 |
| 槍械影視戰 | 鏡頭中的後坐、掩體與移動、槍口光和環境命中；不提供現實傷人操作教學 |
| 街頭或絕境搏鬥 | 環境阻礙、失衡、笨拙恢復、疲勞、求生目的 |
| 幻想單人群戰 | 敵方阻截、技能功能、範圍、特效來源、群體受擊與地貌後果 |
| 幻想雙人對決 | 能力互相反制、距離與高低變化、優勢反轉、資源耗損 |

兩秒開場的功能是讓觀眾看懂誰打誰、距離和風格；可在第一個攻擊中完成，不必先站著介紹。使用者要慢壓迫時，可用對峙與威脅累積開場。

## 第二層 打擊力學與物理

- 一次關鍵攻擊寫出：支撐／發力 → 路徑 → 接觸或落空 → 目標／环境結果。直刺、橫掃、下砸不要寫成相同的揮手爆光。
- 金屬碰撞可有火花、彈開和手臂承壓；拳擊身體可有折身、呼吸中斷、重心後移；格擋成功也可能滑退。依材質選反應。
- 輕、中、重擊用不同後果表達。重擊的停滯、退步、跪地、飛出、撞牆有層次；不要每一下都核爆。
- 用腳犁溝、插劍制動、瓦片掀起、木梁折斷等痕跡證明力量。幻想借力可誇張，但位移仍應有可見起因。
- 命中重拍讀 [衝擊與白閃](references/impact-language.md)。保留「衝擊幀＋1幀白閃」「三級衝擊幀＋3幀白閃」「後彈＋徑向模糊」等寫法的差別，按鏡頭選擇，別概括掉。

## 第三層 對手運動與反應

沿用SD-05的準備、執行、接觸、反應、恢復五階段。原文秒數只作節奏例子，不把每次交手都卡成1秒，也不強制每秒三動作。

- 讓敵人主動改變主角的選擇：側襲逼轉身、遠攻封落點、格擋逼換角、抓扯逼解圍。
- 用借力、順勢、反手、落地即、卸力後等連接上一招與下一招；寫清實際姿勢與方向，不只堆連接詞。
- 每段改變至少一項有意義的狀態：優勢、距離、高度、立足點、武器狀態、疲勞、技能資源或敵群分布。
- 多人交手指定各方目標和間距，不讓背景敵人全部等待輪到自己。
- 已有劇本保留結果；純感覺創作則補出符合氣質的勝負或懸念。猶豫、呼吸、痛苦等表演放在會影響行動的節點。

## 第四層 武器與技能身份

- 保留SD-05的握持、刃口、角度調整、肩胯與腳步要求。長槍與槍械分清；不用來源中的不明譯詞。
- 每種武器或能力選一個能反覆辨認的視覺特徵，依動作變形：刺是前向集中，掃是橫弧，旋是環面，砸是向下傳力；依實際設定調整。
- 技能除外形外要有功能：聚怪、截路、破防、位移、防禦、延遲引爆、壓制或終結。先出現可見機制，再給結果。
- 戰鬥模式選定後讀 [逐段寫法庫](references/segment-library.md) 的相關章節。至少借鑑一個具體段落機制，不只是採用「高速、特效滿屏」。可組合兩種互補機制；不要整篇換名字換顏色照搬。
- 詳寫新技能的來源、形態、方向、作用對象和殘留。再次出現時以辨識詞延續，不重複整套設定。
- 保留武器和能力狀態：劍已化瓣需先聚回才能格擋；已收鞘不能直接拄地；已耗盡光翼不能下一鏡恢復滿能。

## 第五層 相機與視角

- 跟拍維持動作可讀；近景看接觸；遠景展示規模；甩鏡要有新目標；升降和俯衝呼應高低變化。
- 鏡頭時長依事件而變，不使用固定每1秒、2秒或3秒切一次的模板。細節插鏡可短至約0.3–0.8秒；完整發力、追逐、摔投或角力可保留約1.2–3秒。這些是選擇範圍，不是配額。
- 一次攻防可以拆成多個鏡頭：全景看發力路徑，近景看接觸，低位細節看腳下承壓，再回全景看退讓結果。也可以用一個較長鏡頭保留完整動作；由可讀性和重量決定。
- 切點必須由動作、注意力或環境結果觸發，例如抬爪切接觸、撞擊切腳下裂地、甩頭帶到反擊、煙塵覆鏡後換位。避免整齊按時間切鏡。
- 重型巨獸、重兵器或摔投不能全程碎切；最大接觸前至少保留一個能讀清加速方向與支撐的鏡頭，接觸後至少保留一個能讀清受力結果的鏡頭。
- 有意選擇敘述順序：需要強觀看位置時「運鏡→景別→交手→反饋」；需要清晰攻防時「威脅→動作→反應→運鏡」；劇情對決可用連續因果句。
- 確定真長鏡頭、遮擋接鏡或明確剪輯之一。若用偽一鏡到底，寫出遮擋物與遮擋後的位置；不要同時禁硬切又要求硬切黑。
- 角色／武器的出發點、接觸點和結果至少要能辨認；移動邊緣可模糊，不把所有細節糊成一團。背景地標保留足以理解移動的參照。
- 環境破壞可以迫使角色換站位：橋斷進墜落戰、柱倒成障礙、屋脊退到邊緣。讓破壞被後續鏡頭記住。

## 第六層 聲音與節奏

- 兵器碰撞、拳腳、踏地、碎裂、能量、呼吸各自有聲音；接觸與聲音同步，別只寫「震撼音效」。
- 以聚集／承壓、爆發、余波形成强弱變化。高速不等於全程均速；短暫角力、響指前收焦、懸劍等可加強後續爆發。
- 用配樂時依需求安排，不套固定BPM。無配樂時讓呼吸、腳步、武器與環境聲承擔節奏。
- 結尾選：最後一擊完成勝負；碰撞或危機接下一段；戰後疲憊與代價；短暫勝利後新威脅。服從使用者想要的感覺，不預設所有片段都清屏定格。

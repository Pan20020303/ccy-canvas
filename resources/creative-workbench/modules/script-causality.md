# 劇本方法論

以三條理論路線協助結構與診斷。

## 羅伯特・麥基：《故事》

### 主控思想（Controlling Idea）

用一句話表達：「當主角做出Y，生活就變成X，因為Z。」這是全片的核心命題，每場戲都應為它服務。

若無法說清楚，先找出故事的支柱。

### 場景價值（Scene Value）

每場戲開始到結束，都應發生正向到負向、或負向到正向的變化。沒有價值轉折的段落可能只是描述，還未構成戲。

動筆前問：

- 進場時的價值是什麼？例如信任。
- 起點處於什麼狀態？例如團隊互相信任。
- 結束時變成什麼？例如團隊開始懷疑主角。
- 哪個動作引發變化？

常見價值對照：控制／無助、信任／背叛、愛／佔有、生命／死亡、自由／囚禁、秩序／混亂、團隊／工具、希望／絕望、知識／無知。

### 激勵事件（Inciting Incident）

打破主角原本平衡的事件。按此方法，在全片前四分之一發生；90分鐘電影約在前22分鐘內。

要能區分事件發生前後，主角的生活究竟有何不同。

### 漸進複雜化（Progressive Complications）

後續衝突逐步加深，主角的期待與實際結果之間的落差擴大。

第三幕的衝突若比第一幕更弱，應檢查結構是否失衡。

### 危機 → 高潮 → 結局

- **危機（Crisis）：** 主角最後、最艱難的兩難，在互不相容的價值間選擇。
- **高潮（Climax）：** 用行動回答兩難，是最具體、最有衝擊力的時刻。
- **結局（Resolution）：** 簡短交代高潮之後的新狀態。

### 正負擺盪

主角不能始終順利，也不能始終失敗。正負結果交替，幅度逐漸放大。

墮落弧線中，正向是局部小勝，負向是整體崩塌；成長弧線則相反。

### 展示，不代為說明

用行動、物件替代內心獨白。

- 驗孕棒，代替「我懷孕了」。
- 撕碎的信，代替「我和她分手了」。
- 空椅子，代替「他只剩自己」。

## 約瑟夫・坎伯：《千面英雄》

把英雄旅程當作診斷工具，不當成硬套的規則。不是每個故事都適用完整英雄旅程；反英雄或悲劇可能形成相反的下降旅程，例如俄耳甫斯式的無法歸返。

### 十二階段

1. **日常世界：** 主角處於原本平衡中，先讓觀眾知道他有什麼可以失去。
2. **冒險召喚：** 某事件迫使主角離開舒適區。
3. **拒絕召喚：** 抗拒、恐懼或猶豫，呈現人的反應。
4. **遇見導師：** 得到工具、知識或方向；也可能遇上偽裝成導師的敵人。
5. **跨越門檻：** 進入新的世界。
6. **考驗、盟友、敵人：** 在新世界中尋找位置。
7. **逼近核心險境：** 為主要考驗作準備。
8. **重大考驗：** 面對死亡或自身陰影。
9. **獎賞：** 得到此行追求的東西。
10. **歸途：** 開始返回；悲劇也可能在此變得無法回頭。
11. **復甦：** 最後的試煉，主角經歷象徵性的死亡與新生。
12. **帶著解藥歸返：** 把新的事物帶回原本世界。

### 原型

| 原型 | 功能 |
|---|---|
| 英雄 | 主動推動故事。 |
| 陰影 | 對立角色，也是主角自身陰暗面的映照。 |
| 導師 | 給予工具。 |
| 門檻守衛 | 阻止主角跨出第一步。 |
| 信使 | 宣告召喚。 |
| 變形者 | 立場改變，使人難辨。 |
| 搗蛋者 | 打破規則與慣例。 |

反英雄悲劇中的導師可能同時是陰影：主角不知道引路人其實是敵人。

## 亞里斯多德：《詩學》

### 致命缺陷（Hamartia）

不是單指罪惡，而是引發悲劇或角色弧線的判斷失誤、性格弱點。有些特質在日常是優點，在極端情況下卻釀成災難。

例如愛得過深、政治鬥爭中過度信任、家族悲劇中無法寬恕。

缺陷應從早期便能看見，並在高潮產生決定性的後果。

### 突轉（Peripeteia）

原本追求X的行動，反而導致相反結果。

想救人，反而害死他；想保護，反而摧毀；想打開，反而永遠關閉。

有力的故事可安排2至3次逐步加劇的突轉。

### 發現／認知（Anagnorisis）

角色或觀眾發現先前隱藏的真相。

若發現恰好與突轉同時發生，就形成雙重打擊：主角理解真相，也看見自己的行動已朝相反方向發展。

### 情感淨化（Catharsis）

結局引發憐憫與恐懼：觀眾同情角色，也意識到自己可能遭逢同樣處境。

### 行動統一

所有事件應朝同一個結局匯聚，每個動作、物件和台詞都對此有所貢獻。

檢查方法：在腦中刪掉一場戲，電影是否改變？若不變，考慮刪除。

## 實際用法

每次寫場景前，回答：

1. 主控思想是什麼？
2. 進場與出場的價值各是什麼？
3. 適用時，它位於哪個英雄旅程階段？
4. 它如何推動角色的致命缺陷？
5. 它本身是突轉，還是在為突轉鋪墊？

若這些問題都沒有答案，先判斷場景是否必要，或是否應重新構思。
